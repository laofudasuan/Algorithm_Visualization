# 动态规划基础

动态规划是一种通过将复杂问题分解为子问题来求解的方法。

$$dp[i][j] = \max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])$$

# 经典问题：背包问题

背包问题是动态规划中的经典问题，包括0-1背包、完全背包等多种变体。
