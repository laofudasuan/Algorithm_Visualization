##### CF1784E Infinite Game

Alice 和 Bob 正在玩一个由若干局组成的无限游戏。每一局由若干轮组成，每一轮有一名玩家获胜。第一个赢得两轮的玩家将赢得该局。因此，每一局的最终比分总是 $2:0$ 或 $2:1$，胜者为 Alice 或 Bob。

我们称一个游戏场景为一个由字符 'a' 和 'b' 组成的有限字符串 $s$。考虑一个由 $s$ 无限重复拼接而成的无限字符串：$sss\ldots$。假设 Alice 和 Bob 按照这个无限字符串从左到右进行每一轮。如果当前字符为 'a'，则 Alice 赢得该轮；如果为 'b'，则 Bob 赢得该轮。当有一名玩家赢得两轮时，该局结束，下一局从下一个字符开始。

定义 $a_i$ 为 Alice 在前 $i$ 局中赢得的局数。定义 $r$ 为比值 $\frac{a_i}{i}$ 在 $i \rightarrow \infty$ 时的极限。如果 $r > \frac{1}{2}$，我们称场景 $s$ 对 Alice 有利；如果 $r = \frac{1}{2}$，称为平局；如果 $r < \frac{1}{2}$，称场景对 Bob 有利。

现在给定一个只包含 'a'、'b' 和 '?' 的字符串 $s$。请统计将所有 '?' 替换为 'a' 或 'b' 所有可能的方案中，有多少种方案使得场景对 Alice 有利，有多少种方案为平局，有多少种方案对 Bob 有利。请将这三个数对 $998\,244\,353$ 取模后输出。

<CollapsibleComponent title="做法">
考虑一步一步的走，那总共只有四种状态（没有字符，一个`a`，一个`b`，一个`a`和一个`b`），分别记为$0 \sim 3$，考虑从每种状态出发，走完一个$s$后走到的状态和分数的变化，则原问题相当于问从初始状态开始的环上的边权和$>0$的串有多少个。

根据上述分析，可以设$f(i, u_{0..3}, w_{0..3})$为考虑到前$i$个字符，初始状态为$j$时目前状态为$u_j$，分数变化量为$w_j$时的方案数。完成dp后，先枚举$u_j$并求出从初始状态开始走到的环，再对环上的$w_j$求和以得到环的边权和，时间复杂度$O(n^5)$。

考虑优化，注意到若有环，则每个状态在环上要么出现零次，要么出现一次，考虑枚举每个状态的出现次数，设$f(i, u_{0..3}, W)$进行dp，枚举$u_j$验证，通过$W$判断，则时间复杂度优化至$O(n^2)$。

</CollapsibleComponent>


##### AT_agc022_e [AGC022E] Median Replace

有个长度为 $N$（$N$ 为奇数）的 01 串 $s$，其中有若干位置是 ?。

一次操作可将 3 个连续的字符替换成这三个数的中位数。

求有多少将 ? 替换成 0 或 1 的方案使得进行 $\frac{N-1}{2}$ 次操作后的字符串可以是 1。

$N \le 3 \times 10^5$

<CollapsibleComponent title="做法"> 

三个数取中位数相当于是将最大值和最小值抵消

先考虑一个判定性问题：怎么判断一个字符串合不合法

为了让最后剩下1，我们需要让尽可能多的$0$和$0$抵消，尽量少的$1$和$1$抵消

从前往后贪心：
    
- 遇到连续三个$0$就直接删掉两个
- 遇到$01$，则我们只能抵消这个$01$，因为这个$1$会阻挡$0$和后面的$0$抵消
- 遇到$10$和$11$，先不急着动，动后面的

在这个过程中，还没有消掉的是一个单调递减的子序列，并且$0$不超过两个

同时，如果出现开头两个$1$，则一定合法

因此，接下来只需要处理剩下的部分$0$和$1$都不超过两个的情况，就可以DP了

##### T737486 中位数

给定长度为 $N$ 的 01 串 $S$，你可以做若干个操作，形如将长度为 3 的子串变成它们的中位数（注意是变成一个数字），问可以得到多少个不同的串。

答案对 $998244353$ 取模。

$N \le 5 \times 10^6$

<CollapsibleComponent title="做法"> 

假设最终剩余长度为k，就相当于把原序列分成k个奇数段，每一段内部保留一个数

重复来自于：不同的划分方式得到了相同的答案

$dp[i=1 \sim n][j=0/1][k]$表示考虑完了前$i$个数，当前正在做的这一段，目标是变成$j$，当前这一段已经做的部分，在自动机上走到了点$k$，方案数是多少

转移：枚举下一个数t是什么

```c++
for (t=0;t<=1;t++)
    if (在目标为j的自动机上，从k走t号边会到达能达成条件的点)
         dp[i][j][k] -> dp[i+1][0/1][空节点];
    else
         dp[i][j][k] -> dp[i+1][j][k走t号边会到达的点];
```
</CollapsibleComponent>
