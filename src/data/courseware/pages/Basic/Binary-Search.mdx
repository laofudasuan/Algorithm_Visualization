# 二分法

##### P16328 夜曲

给定长度为 $n$ 的两个字符串 $s, t$，下标从 $1$ 开始。

一次操作可以自由选择一个长度为 $n$、值域为 $[1, n]$ 的**不降**整数序列 $p$，满足 $|p_i-i|\le 1$。随后同时令所有 $s_i\gets s_{p_i}$。

求能把 $s$ 变为 $t$ 的最小操作次数，若无解输出 $-1$。

对于所有数据，保证 $1\le T \le 5\times 10^3$，$1\le n,\sum n\le 10^6$，字符串仅包含小写字母，$|s|=|t|$。

##### 有趣题
    
交互题

有一个整数$X(1 \le X \le 10^{18})$，你需要通过向交互库询问得出$X$的值

每次你可以问交互库一个区间$[l,r]$，交互库会告诉你$X$是否在这个区间中

**但是，交互库可能会撒一次谎**，而且你不知道它会在哪一次撒谎

你需要用尽可能少的次数确定$X$的值

###### 子任务：
- 30分：120次
- 50分：80次
- 80分-75次
- 100分-70次

<CollapsibleComponent title="做法">
如果不撒谎，最优解是$60$次，直接二分查找

$120$次：每次二分的时候问两遍来确定没有撒谎

如何优化？

可以多次二分做一次check
