# 倍增法

## 原理

倍增法（英语：binary lifting），顾名思义就是「成倍增长」。我们在进行递推时，如果状态空间很大，通常的线性递推无法满足时间与空间复杂度的要求，那么我们可以通过成倍增长的方式，只递推状态空间中在$𝑘$的整数次幂位置上的值作为代表。当需要其他位置上的值时，我们通过「任意整数可以表示成若干个$k$的次幂项的和」这一性质，使用之前求出的代表值拼成所需的值。所以使用倍增算法也要求我们递推的问题的状态空间关于$k$的次幂具有可划分性。通常情况下$k$取$2$。

算法过程：
- 对所有状态建立一个转移关系表
- 对每一个状态和$j = 0,1,\ldots,k$求出$2^j$步的信息
- 一个$2^j$步的信息可以由两个$2^{j-1}$步的信息合并得到

### 应用：ST表

ST表示区间信息维护的有力工具，用倍增算法的经典模型，$g[i][j]$表示从序列的位置i走长度为$2^j$的格子后这段区间的信息，对于一段区间的询问用ST表跳跃

如果要求解的问题满足，一个信息可以被重复统计而不影响答案，如区间最值查询，这类问题可以使用更巧妙的方法加以优化:

考虑当前询问区间$[l,r]$，长度二进制的最高位为$\log(r-l+1)$，但是我们可以重复计算某些信息来优化访问次数，另s为$r-l+1$二进制下的最后一位代表的数，那么我们可以把区间$[l,r]$拆分为$[l,l+s-1]$和$[r-s+1,r]$这两段区间，而这两段区间都是在预处理范围之内的

### 应用：树上LCA

对于一棵有根树，我们需要进行两个点$a,b$之间的路径信息统计，而最普遍的方式就是把两个点之间的路径分解为两条竖直的路径$a \to lca(a,b) + b \to lca(a,b)$，而竖直向上的路径信息是可以用倍增表进行预处理的。

用$f[i][j]$表示节点$i$沿父亲反向跳$2^j$步后到达的点，在求两个点之间的lca时，首先利用倍增表把$a$和$b$跳到同一深度的位置，如果此时$a$和$b$相同则说明其中一个元素为另一个元素的祖先，那么直接返回答案即可。

如果不相同那么我们接下来要考虑a和b同时跳跃若干步数到达的第一个公共祖先，但是这个问题无法直接判读，在倍增时如果发现了a和b的一个公共祖先k，我们无法确定在k下方是否还有其它公共祖先，所以我们把问题转化一下求a和b的深度最小的非公共祖先，这个问题是很明确的，如果跳某一步后a和b到达相同位置那就放弃这次操作，否则就不停地跳跃，然后再利用一个结论:深度最小的非公共祖先的父亲就是深度最大的公共祖先。

普通的倍增需要先跳到同一深度，再跳到lca。而我们不利用深度，而是利用dfs序。假设$dfn[a]<dfn[b]$，那么$a$和$b$的lca就是$b$的父亲中第一个dfs序$ \le dfn[a]$的结点。这样就只需要做一次倍增，常数更小。

##### ZJOI2012灾难

给一张食物网，里面$n$个节点表示$n$种动物，每条边表示一个捕食关系。

对于每种动物，询问，如果这种动物突然灭绝，那么有多少种动物会被饿死。

<CollapsibleComponent title="做法">

拓扑排序，对于每个点，把它直接挂到所有前驱的LCA的下方。

求LCA:倍增，支持末尾加入。
