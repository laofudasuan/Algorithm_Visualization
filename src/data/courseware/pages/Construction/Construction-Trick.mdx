# 构造题笔记

> 构造题表面上题型很散，真正反复出现的核心却很有限：不变量、染色、拓扑瓶颈、延迟决策、逆向构造，以及在交互或黑盒条件下的信息提取。本文尝试把这些线索串成一条连续主线，从基础观察出发，逐步推进到群论、网络流、博弈、随机化和高阶交互。

后半部分会穿插代表题。重点不是堆结论，而是说明一类题为什么会落到某个构造模型上，以及这些模型最后如何压成可提交的实现。


## 第一章：数学本质与构造思维

在解决构造题时，最致命的错误是盲目尝试和随机化猜测。严谨的构造算法必须建立在坚实的数学基础之上。我们首先探讨支撑整个构造体系的四大"思维原语"。

### 1.1 存在性与构造性的对立统一

在现代数学中，证明某个对象存在有两种根本路径：**非构造性证明**（如概率方法、鸽巢原理）与**构造性证明**。但在算法语境下，纯粹的存在性证明往往是不够的。

例如，著名的 Erdős 概率方法可以轻松证明：当 $\binom{n}{k} 2^{1 - \binom{k}{2}} < 1$ 时，存在一个 $n$ 个顶点的图，其最大团与最大独立集的大小严格小于 $k$。然而，**找到**这样一个图却是一个 NP-Hard 级别的挑战。

因此，我们的核心任务是将非构造性定理转化为可降维、可迭代的生成过程。这就引出了**微调策略**与**归纳增量法**。

### 1.2 不变量与半不变量（Invariants & Monovariants）

在序列操作、网格变换或博弈论构造中，系统的状态空间极其庞大。此时，寻找状态转移过程中的"不变量"或单调递增/递减的"半不变量"是破局的关键。

设 $\Sigma$ 为所有可能状态的集合，$\rightarrow$ 表示合法的操作转移。我们需要寻找一个映射 $I: \Sigma \rightarrow \mathbb{R}$，使得：

$$
S \rightarrow S' \Rightarrow I(S) = I(S')
$$

或者

$$
S \rightarrow S' \Rightarrow I(S) < I(S')
$$

最典型的不变量就是**奇偶性**与**模运算同余类**。在构造要求"经过一系列操作达到目标状态"时，第一步永远是计算初态与终态的不变量。如果不变量不一致，则可立即判定无解；如果一致，则不变量往往指明了具体的构造路径。

### 1.3 对称性与映射（Symmetry & Mapping）

对称性是降低构造复杂度的利器。当约束条件表现出高度对称时，目标结构往往也允许对称的解法。通过建立双射关系，我们可以将复杂的条件映射到已被解决的平凡模型上。如将树上的节点分配问题映射为二分图的染色问题，将序列的逆序对问题映射为排列的逆序置换。


## 第二章：代数与位运算的构造艺术

在序列构造中，基于位运算（特别是异或 $\oplus$）的问题占据了半壁江山。这类问题的核心在于理解位运算的线性无关性与二进制拆分的正交性。

### 2.1 异或体系的线性空间视角

异或运算本质上是定义在有限域 $GF(2)$ 上的无进位加法。任意一个整数可以视为 $GF(2)$ 上的一个多项式或高维向量。这种视角赋予了我们强大的分析工具。

异或与算术加法的最基本联系由以下恒等式给出：

$$
a + b = (a \oplus b) + 2(a \wedge b)
$$

这一公式揭示了加法与异或的区别仅在于"进位"部分 $2(a \wedge b)$。这一底层逻辑是解决一系列加法与异或混合构造题的基础。


## 典型实例分析：CF1325D

### 题意概括：

给定两个非负整数 $u$ 和 $v$。构造一个**最短**的数组，使得数组内所有元素的异或和等于 $u$，且所有元素的算术和等于 $v$。如果不存在这样的数组，输出 $-1$。

### 理论推导：

设我们需要构造的数组为 $a_1, a_2, \ldots, a_k$。

已知：

1. $\bigoplus_{i=1}^{k} a_i = u$
2. $\sum_{i=1}^{k} a_i = v$

根据 $a + b \equiv a \oplus b \pmod{2}$ 的推广，多个数相加的奇偶性与其异或和的奇偶性必定相同。因此：

$$
\sum a_i \equiv \oplus a_i \pmod{2} \Rightarrow v \equiv u \pmod{2}
$$

这引出了无解的两个必要条件：

1. 若 $v < u$，无解（因为任意一组非负整数的算术和必然大于等于其异或和）。
2. 若 $(v - u) \bmod 2 \neq 0$，无解。

排除上述情况后，设 $h = \frac{v - u}{2}$。由于 $u \oplus h \oplus h = u$ 且 $u + h + h = u + 2h = v$，我们立刻得到一个**长度最大为 3** 的万能构造方案：$[u, h, h]$。

接下来的问题是：能否用更短的数组实现？

- 长度为 0：当且仅当 $u = 0$ 且 $v = 0$
- 长度为 1：当且仅当 $u = v$
- 长度为 2：设两个数为 $a, b$，需满足 $a \oplus b = u$ 且 $a + b = v$

代入前文的恒等式 $v = u + 2(a \wedge b)$，可得 $a \wedge b = h$。现在我们需要找到两个数，满足 $a \oplus b = u$ 且 $a \wedge b = h$。

由于异或为 1 的位，两个数必然是一个 0 一个 1；而按位与为 1 的位，两个数必然都是 1。这就要求**同一比特位上不能同时满足"异或结果为 1"且"按位与结果为 1"**。即必要充分条件为 $u \wedge h = 0$。若满足 $u \wedge h = 0$，我们可以直接令 $a = u + h$（其实也就是 $u \oplus h$），$b = h$，从而给出长度为 2 的构造。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

void slv() {
    ll u, v;
    cin >> u >> v;

    // 判定无解的情况：异或和大于算术和，或两者奇偶性不同
    if (u > v || (v - u) % 2 != 0) {
        cout << -1 << "\n";
        return;
    }

    // 长度为 0 或 1 的情况
    if (u == v) {
        if (u == 0) cout << 0 << "\n";
        else cout << 1 << "\n" << u << "\n";
        return;
    }

    ll h = (v - u) / 2;

    // 尝试压缩为长度 2，条件为 u 与 h 在二进制下没有交集
    if ((u & h) == 0) {
        cout << 2 << "\n" << (u + h) << " " << h << "\n";
    } else {
        // 否则必定可以使用长度为 3 的通用构造
        cout << 3 << "\n" << u << " " << h << " " << h << "\n";
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    slv();
    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1325/D

### 复杂度分析：

- 时间复杂度：$O(1)$，纯粹的位运算和条件判断。
- 空间复杂度：$O(1)$，仅使用了几个标量变量。

### 2.2 大数占位与二进制正交法

当题目要求构造一个包含 $N$ 个互不相同元素的序列，且满足某种全局异或属性时，"大数占位法"是一种很好用的技巧。由于高位的二进制比特对低位没有任何影响（这就是 $GF(2)$ 空间的独立性），我们可以将序列的最后几个数分配到极高的二进制位上，从而保证元素的互异性，并吸收掉前面任意生成的异或和。


## 典型实例分析：CF1722G

### 题意概括：

给定整数 $n$（$n \geq 3$）。构造一个由 $n$ 个互不相同的非负整数（每个数严格小于 $2^{31}$）组成的数组，使得所有偶数索引元素的异或和等于所有奇数索引元素的异或和。

### 理论推导：

令偶数索引的异或和为 $E$，奇数索引的异或和为 $O$。题目要求 $E = O$，这等价于 $E \oplus O = 0$。即，整个数组所有 $n$ 个元素的异或和必须为 0。

我们需要选出 $n$ 个互不相同的数 $a_1, a_2, \ldots, a_n$，满足 $\bigoplus_{i=1}^{n} a_i = 0$。

我们可以极其自由地生成前 $n - 3$ 个数：直接令 $a_i = i$（对于 $1 \leq i \leq n - 3$）。这保证了前 $n - 3$ 个数互不相同。

设这前 $n - 3$ 个数的异或和为 $X$：

$$
X = \bigoplus_{i=1}^{n - 3} i
$$

为了使总体异或和为 0，剩余三个数 $p, q, r$ 必须满足：

$$
p \oplus q \oplus r = X \implies r = X \oplus p \oplus q
$$

为了保证 $p, q, r$ 互不相同，且不与前面的 $1 \ldots n - 3$ 发生碰撞，我们可以利用尚未被使用的高位二进制位：

取 $p = 2^{29}$，取 $q = 2^{30}$。由于 $X \leq n - 3 < 2 \times 10^5 \ll 2^{29}$，故 $X$ 在第 29 位和第 30 位必然为 0。

此时计算出的 $r = X \oplus 2^{29} \oplus 2^{30}$。

分析这三个数：

- $p$ 只有第 29 位为 1
- $q$ 只有第 30 位为 1
- $r$ 的第 29 位和第 30 位均为 1，且低位等同于 $X$

这三个数的高位特征互不相同，且高位均含有 1，必然远大于前面生成的 $1 \ldots n - 3$。因此这 $n$ 个数绝对互不相同。总体异或和显然为 $X \oplus p \oplus q \oplus r = X \oplus X \oplus p \oplus q \oplus p \oplus q = 0$。完美满足所有条件。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

void slv() {
    int n;
    cin >> n;
    int x = 0;
    vector<int> a(n);

    // 自由生成前 n-3 个互不相同的数字，并计算异或和
    for (int i = 0; i < n - 3; ++i) {
        a[i] = i + 1;
        x ^= a[i];
    }

    // 利用二进制高位正交性构造最后三个数
    int p = 1 << 29;
    int q = 1 << 30;
    int r = x ^ p ^ q;

    a[n - 3] = p;
    a[n - 2] = q;
    a[n - 1] = r;

    // 输出结果
    for (int i = 0; i < n; ++i) {
        cout << a[i] << (i == n - 1 ? "" : " ");
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t;
    cin >> t;
    while (t--) {
        slv();
    }
    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1722/G

### 复杂度分析：

- 时间复杂度：$O(n)$，仅需遍历一次数组生成数值并打印。
- 空间复杂度：$O(n)$，用于存储结果数组。


## 第三章：鸽巢原理与染色模型的网格映射

当构造问题发生在二维网格矩阵上时，常常伴随有对局部结构（如行、列、对角线、L型区域或特定长度的连通块）的约束。这时候，染色理论与鸽巢原理是建立等价类并进行全局调控的标准数学手段。

### 3.1 鸽巢原理的极值映射

在纯粹组合学中，鸽巢原理表述为：将 $N$ 个物体放入 $K$ 个抽屉中，必然存在一个抽屉至少包含 $\lceil N / K \rceil$ 个物体，也必然存在一个抽屉**至多**包含 $\lfloor N / K \rfloor$ 个物体。

在网格构造中，我们可以通过巧妙的"模 $K$ 同余染色"，将网格划分为 $K$ 个等价类。此时整个矩阵的待修改元素也被划分到这 $K$ 个类中。根据鸽巢原理，必然存在一个类，其待修改元素的数量**小于等于**总数的 $1/K$。将该类内的元素作为修改目标，即可满足操作次数不超过总数 $1/K$ 的限制。

### 3.2 矩阵同态染色

对于规避"连续 $K$ 个相同元素"的约束，最经典的染色映射是使得所有距离为 $K$ 的连通点落在不同的颜色等价类中。具体来说，对于坐标 $(i, j)$，我们定义颜色函数为：

$$
C(i, j) = (i + j) \bmod K
$$

在这种染色下，任何水平或垂直方向连续的 $K$ 个格子，必然恰好涵盖了从 0 到 $K - 1$ 的每一种颜色。


## 典型实例分析：CF1450C1

### 题意概括：

给定一个 $n \times n$ 的网格，部分格子填有字符 `'X'`，其余为空（`'.'`）。规则是不允许存在任意水平或垂直方向上连续的 3 个 `'X'`（即连成一条线，类似井字棋的获胜条件）。你可以将某些 `'X'` 修改为 `'O'`。要求修改的次数不能超过初始状态下 `'X'` 总数的 $\lfloor k / 3 \rfloor$（$k$ 为初始 `'X'` 的数量）。请输出修改后的网格。

### 理论推导：

目标是破坏所有长度为 3 的连续 `'X'`。我们引入同余染色映射：对于网格上的每一个坐标 $(i, j)$，赋予颜色 $C(i, j) = (i + j) \bmod 3$。这会将整个网格划分为三种颜色类 0, 1, 2。

观察任意一个由连续 3 个格子组成的线段（无论是横向的 $(i, j), (i, j+1), (i, j+2)$ 还是纵向的 $(i, j), (i+1, j), (i+2, j)$），这 3 个格子在函数 $C$ 下的值必然分别是 0, 1, 2 的一个排列。

这意味着，如果我们**强行禁止某一种颜色类上出现 `'X'`**，那么任何连续的 3 个格子中必然有一个格子不是 `'X'`（因为它被禁止了，被我们修改成了 `'O'`），从而从根本上杜绝了长度为 3 的连续 `'X'`。

为了满足修改次数 $\leq \lfloor k / 3 \rfloor$ 的严格约束，我们统计当前网格中所有 `'X'` 在颜色类 0, 1, 2 中的分布数量，记为 $cnt[0], cnt[1], cnt[2]$。

显然有：

$$
cnt[0] + cnt[1] + cnt[2] = k
$$

根据鸽巢原理，这三个非负整数中，**至少存在一个数**满足：

$$
cnt[m] \leq \lfloor k / 3 \rfloor
$$

我们只需找到这个数量最少的颜色类 $m$，将该颜色类上所有的 `'X'` 改为 `'O'`，即可在满足操作次数限制的前提下，彻底打破所有的连续三子棋结构。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

void slv() {
    int n;
    cin >> n;
    vector<string> s(n);
    int c[3] = {0, 0, 0};

    // 读取网格并统计每种颜色下 'X' 的数量
    for (int i = 0; i < n; ++i) {
        cin >> s[i];
        for (int j = 0; j < n; ++j) {
            if (s[i][j] == 'X') {
                c[(i + j) % 3]++;
            }
        }
    }

    // 依据鸽巢原理，找出包含 'X' 最少的颜色类 m
    int m = 0;
    if (c[1] < c[m]) m = 1;
    if (c[2] < c[m]) m = 2;

    // 将该颜色类上的所有 'X' 修改为 'O'
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            if (s[i][j] == 'X' && (i + j) % 3 == m) {
                s[i][j] = 'O';
            }
        }
        cout << s[i] << "\n";
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t;
    cin >> t;
    while (t--) {
        slv();
    }
    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1450/C1

### 复杂度分析：

- 时间复杂度：$O(n^2)$。只需遍历常数次矩阵即可完成统计与修改，每个测试用例时间线性依赖于矩阵元素总数。
- 空间复杂度：$O(n^2)$。用于存储 $n \times n$ 的字符串网格数据。

> **注**：该题还有一个 Hard Version，允许矩阵中同时存在 `'X'` 和 `'O'` 并进行相互修改，核心思路仍是考察三种颜色的 $(C_X, C_O)$ 二元排列对，并利用鸽巢原理在 6 种搭配中选取修改成本最小的，思想一脉相承。


## 第四章：图论拓扑与极值逼近

在图论领域的构造题中，常见要求是针对无向图或树结构设定特定的边权、点权，以达到诸如最短路约束、连通性极值、或者是某种拓扑不变量（如直径、MEX 值等）的最优化。这要求深入理解树的拓扑性质，尤其是度数序列特征与路径形态的极端情况。

### 4.1 拓扑中心与星型结构映射

图论构造的一大核心法则：如果约束条件涉及到图上所有路径的最值，**优先寻找图的拓扑瓶颈**。拓扑瓶颈可能是一个度数极大的节点（星型结构的中心），也可能是树的直径重心。通过在这些瓶颈位置放置极值元素（如最小的非负整数），能够最大程度地"封锁"路径的上限。

MEX（Minimum Excluded Value）是图论与序列构造中非常常见的算子。一条路径的 MEX 定义为：没有出现在该路径上的最小非负整数。针对求"全局路径 MEX 最大值的最小值"这类 Min-Max 构造问题，极值逼近是标准思路。


## 典型实例分析：CF1325C

### 题意概括：

给定一棵包含 $n$ 个节点的树。你需要为这棵树的 $n - 1$ 条边分配权值，权值必须是从 0 到 $n - 2$ 的所有整数，且每条边权值互不相同。

定义 $MEX(u, v)$ 为节点 $u$ 到节点 $v$ 简单路径上未出现的最小非负整数。

请构造一种分配方案，使得树上**所有叶子节点（度数为 1 的节点）之间的 MEX 的最大值尽可能小**。

### 理论推导：

由于权值是从 0 开始的排列，我们希望路径的 MEX 尽可能小。为了让一条路径的 MEX 等于 $k$，这条路径上必须包含权值 $0, 1, \ldots, k - 1$。这意味着如果一条路径缺少 $0, 1, 2$ 中的任何一个，它的 MEX 就绝不会超过 2。

考虑整个树的结构拓扑，分两种极端情况：

#### 1. 树是一条链（Path Graph）

此时树仅有两个叶子节点，全图只有唯一的一条连接两个叶子的路径。这条路径包含了整棵树所有的 $n - 1$ 条边。无论我们如何分配权值，这条包含所有边的路径必定囊括了 $0, \ldots, n - 2$ 的所有数字，它的 MEX 只能是 $n - 1$。因此，如果是一条链，权值可以任意分配。

#### 2. 树存在分支（存在至少一个节点的度数 $\geq 3$）

此时，必定存在一个核心节点 $rt$，其度数 $d \geq 3$。它向外至少发散出三条不重合的边。为了"封锁"所有连接两两叶子节点的路径，我们可以将最小的三个数 $0, 1, 2$ 分配给与 $rt$ 直接相连的三条边上！

**为什么这样做可以达到最优？**

在树结构中，任意两个叶子节点之间的简单路径，**最多只能经过 $rt$ 节点一次**。因此，这条路径最多只会包含与 $rt$ 直接相连的 $d$ 条边中的两条。

既然最小的三个数 $0, 1, 2$ 都分布在 $rt$ 的辐射边上，任何一条路径最多只能包含其中的两个数。**必定会遗漏 $0, 1, 2$ 中的至少一个！**

因此，任何两个叶子节点之间的路径的 MEX 值最多只可能是 2。

而其他剩余的边，无论怎么分配剩下的 $3 \ldots n - 2$，都不会再影响这一结论的正确性，直接任意分配即可。

这就是一种极其优雅的极值逼近法：利用图的局部极大拓扑结构（度数 $\geq 3$ 的星型局部），集中放置危险元素（小的非负整数），使得全局的路径必然无法完整收集这些危险元素。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 100005;

struct Edg {
    int v;
    int i;
};

vector<Edg> g[N];
int ans[N];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n;
    cin >> n;

    for (int i = 0; i < n - 1; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back({v, i});
        g[v].push_back({u, i});
    }

    // 找到第一个度数 >= 3 的节点
    int rt = -1;
    for (int i = 1; i <= n; ++i) {
        if ((int)g[i].size() >= 3) {
            rt = i;
            break;
        }
    }

    // 情况1：没有度数 >= 3 的节点（即为链），任意分配
    if (rt == -1) {
        for (int i = 0; i < n - 1; ++i) {
            cout << i << "\n";
        }
        return 0;
    }

    // 情况2：存在分支节点
    int cur = 0;
    // 将 0, 1, 2 分配给与 rt 相连的前三条边
    for (int i = 0; i < (int)g[rt].size(); ++i) {
        ans[g[rt][i].i] = cur++;
    }

    // 剩余边任意分配
    for (int i = 0; i < n - 1; ++i) {
        if (ans[i] == 0 && cur < n - 1) {
            ans[i] = cur++;
        }
    }

    for (int i = 0; i < n - 1; ++i) {
        cout << ans[i] << "\n";
    }

    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1325/C

### 复杂度分析：

- 时间复杂度：$O(n)$。读取树结构、扫描计算度数以及两次遍历对边权赋值的操作均只需线性时间。
- 空间复杂度：$O(n)$。需要维护邻接表、度数数组及答案数组，消耗线性级别的内存。


以上四章主要是在搭一套"先看什么、再想什么"的观察框架：不变量、染色、拓扑中心，以及通过局部强约束去逼出全局结构。接下来几章继续沿着这条线往下走，把延迟决策、逆向构造和交互中的信息提取也纳入同一套视角；后文则会把这些方法继续推进到更高阶的模型和更完整的实战题解。


## 第五章：数学归纳法与增量构造模型

在计算机科学中，数学归纳法不仅仅是一种证明工具，它本身就是递归与动态规划的算法原型。当一个规模为 $N$ 的构造问题看似毫无头绪时，将其降维到 $N - 1$ 并寻找状态转移的增量，是打破僵局的最有效手段。

### 5.1 增量构造与延迟决策

构造性归纳法的核心在于回答一个问题：假设我们已经得到了规模为 $N - 1$ 的合法解，加入第 $N$ 个元素时，会引发哪些冲突？如何通过局部微调（或预留冗余）来化解这些冲突？

在序列生成问题中，特别是涉及 MEX 或前缀极值的构造，常常会出现"当前决策受到未来约束"的局面。此时，我们需要引入**延迟决策**的思维模式：对于当前并不受到严格限制的位置，先将其放入一个候选池（如栈或队列），待到未来某个时刻约束条件明确时，再从池中取出进行精确赋值。


## 典型实例分析：CF1364C

### 题意概括：

给定一个长度为 $n$ 的非递减非负整数数组 $a_1, a_2, \ldots, a_n$，且满足 $a_i \leq i$。你需要构造一个长度为 $n$ 的非负整数数组 $b_1, b_2, \ldots, b_n$，使得对于任意 $i \in [1, n]$，数组 $b$ 的前缀 $b_1 \ldots b_i$ 的 MEX 值恰好等于 $a_i$。

### 理论推导：

前缀 MEX 是一个极具单调性的算子。由于 $a_i$ 是非递减的，这意味着前缀 MEX 随着 $i$ 的增加只能保持不变或增大。

我们考察增量阶段：从前缀 $i - 1$ 转移到前缀 $i$ 时，MEX 发生了什么变化？

**情况一：$a_i = a_{i - 1}$**

此时 MEX 没有发生变化。说明第 $i$ 个位置填入的数 $b_i$ **不能**是 $a_i$（否则 MEX 就会越过 $a_i$ 发生改变）。在没有任何其他强制约束下，此时的 $b_i$ 拥有极大的自由度。我们将其视为"冗余位置"，将其索引 $i$ 压入一个候选栈中，暂不决定它的最终值。

**情况二：$a_i > a_{i - 1}$**

MEX 发生了跳跃！这意味着什么？MEX 从 $a_{i - 1}$ 变成了 $a_i$，说明在加入了 $b_i$ 之后，原来缺失的数字 $a_{i - 1}$ **必定被补齐了**。因此，我们面临一个极其严格的强制性约束：$b_i$ **必须等于** $a_{i - 1}$。

但这还不够。如果 $a_i$ 比 $a_{i - 1}$ 大了不止 1，即区间 $(a_{i - 1}, a_i)$ 内还有其他的数字（如 $x$）尚未出现，那么为了让 MEX 顺利到达 $a_i$，这些缺失的数字 $x$ 也必须在此时被补齐！去哪里补齐？显然只能去前面那些"延迟决策"的冗余位置中去填补。我们将候选栈中的索引依次弹出，填入这些缺失的数字 $x$。

由于题目保证了 $a_i \leq i$，这在数学上等价于"累积的空余位置数量始终大于等于缺失数字的数量"，因此栈绝不会出现下溢，解必然存在。

最后，当整个数组遍历完成后，栈中可能还会残留一些未被赋值的冗余位置。由于它们已经不需要为任何前缀 MEX 贡献特定的值了，为了防止它们干扰前缀 MEX，我们只需填入一个绝对安全的极大值（如 $10^6$）即可。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAX = 1000000;

void slv() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    vector<int> b(n + 1, -1);
    vector<int> stk;  // 延迟决策的冗余位置栈

    a[0] = 0;
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    // 增量构造：逐一处理前缀
    for (int i = 1; i <= n; ++i) {
        if (a[i] != a[i - 1]) {
            // MEX 发生跳跃，当前位置必须是前一个 MEX 值
            b[i] = a[i - 1];

            // 填补中间跳过的其他必定缺失的数字
            for (int x = a[i - 1] + 1; x < a[i]; ++x) {
                int pos = stk.back();
                stk.pop_back();
                b[pos] = x;
            }
        } else {
            // MEX 未跳跃，当前位为冗余位置，压入栈中延迟决策
            stk.push_back(i);
        }
    }

    // 处理剩余的冗余位置，填入安全极大值
    for (int i = 1; i <= n; ++i) {
        if (b[i] == -1) {
            b[i] = MAX;
        }
        cout << b[i] << (i == n ? "" : " ");
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    slv();
    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1364/C

### 复杂度分析：

- 时间复杂度：$O(n)$。每个位置最多入栈一次，出栈一次，内层循环的执行总次数被限制在 $n$ 以内，整体时间完全线性。
- 空间复杂度：$O(n)$。需要维护答案数组与一个辅助栈。


## 第六章：逆向思维与代数同余映射

正向构造往往面临庞大的状态分支，这会导致算法逻辑极其臃肿且极易出错。当题目给定的操作具备可逆性，或者最终的约束方程具有强烈的对称性时，**逆向推导**能够将发散的状态树收敛为单调的路径。

在数论与代数构造题中，这种思想体现为寻找一个极其精巧的"同余桥梁"。

### 6.1 同余方程的几何意义与代数坍缩

考虑这样一类问题：我们需要找到一个变量满足某些模运算的等式。模运算 $a \bmod b$ 在欧几里得空间中可以表示为 $a - b \lfloor a/b \rfloor$。它本质上是将一维数轴卷曲成了一个周长为 $b$ 的圆，而 $a \bmod b$ 则是圆上的坐标。

如果我们遇到多元的模运算嵌套，常规的迭代枚举必定超时。正确的做法是**通过代数坍缩，构造一个中间量**，使得它在不同的模块中恰好呈现我们预期的余数。


## 典型实例分析：CF1603B

### 题意概括：

给定两个偶数整数 $x$ 和 $y$（$2 \leq x, y \leq 10^9$）。你需要构造一个整数 $n$（$1 \leq n \leq 2 \cdot 10^{18}$），使得以下同余等式成立：

$$
n \bmod x = y \bmod n
$$

输出任意一个合法的 $n$ 即可。

### 理论推导：

这道题的关键在于：变量 $n$ 同时出现在"被模数"和"模数"的位置上，正向枚举完全不可行。更稳妥的做法是按 $x$ 与 $y$ 的大小关系分类，直接反推一个能让两边落到同一条数上的位置。

我们通过分类讨论来切分状态空间：

**1. 若 $x > y$**

当 $x$ 大于 $y$ 时，我们希望找到一个 $n$。注意到等式右侧 $y \bmod n$。如果让 $n > y$，那么右侧自然就等于 $y$。

此时等式要求 $n \bmod x = y$。

既然 $x > y$，最直接的构造就是令 $n = x + y$。

验证：
- 左边：$(x + y) \bmod x = y \bmod x = y$（因为 $y < x$）
- 右边：$y \bmod (x + y) = y$（因为 $y < x + y$）

左右相等。

**2. 若 $x = y$**

这就非常平凡了，令 $n = x$ 即可。此时两边都等于 0。

**3. 若 $x < y$（核心难点）**

当 $x < y$ 时，$y \bmod n$ 不再平凡。我们需要在数轴上寻找 $n$ 的位置。

既然 $n$ 在模 $x$ 意义下产生一个余数，在模 $y$ 的逆向意义下也产生同一个余数，这意味着 $n$ 应该位于 $x$ 的某个倍数与 $y$ 之间的中点。

具体来说，令 $y$ 在模 $x$ 意义下的余数为 $r$，即 $r = y \bmod x$。

根据带余除法，有 $y = k \cdot x + r$（其中 $k = \lfloor y / x \rfloor$）。

这里出现了两个关键基准点：$k \cdot x$（不大于 $y$ 的 $x$ 的最大倍数）和 $y$ 本身。它们之间的距离恰好是 $r$。

我们取这两点的**中点**作为 $n$！

即令 $n = y - r / 2$。

**数学验证：**

因为 $x$ 和 $y$ 都是偶数，所以 $r = y \bmod x$ 必定也是偶数，从而 $r / 2$ 是一个精确的整数。

我们将其代入：

$$
n = k \cdot x + r - r/2 = k \cdot x + r/2
$$

计算左边：
$n \bmod x = (k \cdot x + r/2) \bmod x = r/2$（因为 $r < x \Rightarrow r/2 < x$）

计算右边：
$y \bmod n = y - n = y - (y - r/2) = r/2$（因为 $n = y - r/2$，且 $n > y/2$，所以 $y$ 除以 $n$ 的商必定为 1）

左右两边均等于 $r/2$，等式成立。

这道题最值得记住的地方，不是公式本身，而是这种"先按大小关系拆分，再把余数压到同一个中点"的处理方式。它把一个看似别扭的同余方程，改写成了数轴上的直接构造。

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

void slv() {
    ll x, y;
    cin >> x >> y;

    if (x > y) {
        cout << x + y << "\n";
    } else if (x == y) {
        cout << x << "\n";
    } else {
        ll r = y % x;
        ll n = y - r / 2;
        cout << n << "\n";
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t;
    cin >> t;
    while (t--) {
        slv();
    }
    return 0;
}
```

> 题目链接：https://codeforces.com/problemset/problem/1603/B

### 复杂度分析：

- 时间复杂度：$O(1)$。没有任何循环，纯整的四则运算，达到了理论的极限。
- 空间复杂度：$O(1)$。仅占用常数级别的标量存储空间。


## 第七章：交互式构造体系下的信息论界限

交互题是近年来顶级算法竞赛中最具挑战性的题型之一。在这类问题中，底层结构是一个黑盒，系统仅允许你通过调用特定的 API 提问。我们需要利用**最少的查询次数**，如同通过少量的投影切片来重建高维多面体一样，重构出原有的数据结构。

这里主导一切的法则不再是普通的算法复杂度，而是**信息熵**与**线性正交基底**。

### 7.1 信息比特的提取与相对坐标系

每次查询本质上都在提取未知系统的信息比特。如果要求在 $N$ 次操作内还原 $N$ 个元素，这强烈暗示我们必须将前 $N - 1$ 次操作用于建立一个"相对坐标系"，而用最后的一次操作去寻找这个系统的"绝对原点"。在 $GF(2)$（二元域）上，异或 $\oplus$ 运算就是建立相对坐标系的完美工具。


## 典型实例分析：CF1451E

### 题意概括：

系统隐藏了一个长度为 $n$（$n$ 是 2 的幂次，且 $n \geq 4$）的数组 $a_1, a_2, \ldots, a_n$，其中的元素均为区间 $[0, n - 1]$ 内的整数。你可以进行最多 $n + 1$ 次询问，每次询问允许你输入两个下标 $i$ 和 $j$，并选择一种位运算操作（AND、OR、XOR），系统会返回 $a_i$ OP $a_j$ 的结果。请在限定的询问次数内，猜出整个数组 $a$。

### 理论推导：

这是一个经典的信息论构造模型。题目给出的询问次数为 $n + 1$，而我们需要确定 $n$ 个数。我们将构造过程分为两步：构建相对网络与寻找绝对原点。

**第一步：构建相对网络（消耗 $n - 1$ 次询问）**

我们固定下标 1 作为枢纽点，对所有 $i \in [2, n]$，发出询问：

$q_i = a_i \oplus a_1$

我们用一个数组 $X$ 记录结果，即 $X_i = q_i$。为了方便，我们视 $X_1 = 0$。

异或具有完美的线性性质，一旦我们知道了每个元素与 $a_1$ 的相对差值（在 $GF(2)$ 下），只要我们能求出 $a_1$ 的真实值（绝对原点），整个数组即可通过 $a_i = X_i \oplus a_1$ 瞬间解锁。此时，我们还剩下 $(n + 1) - (n - 1) = 2$ 次询问机会。用 2 次询问求出 $a_1$！

**第二步：寻找绝对原点 $a_1$（消耗 1~2 次询问）**

我们面临的情况有两种，由鸽巢原理可推导出必然的分支：

**分支 A：数组中存在至少一对相同的元素**

这等价于在我们的相对数组 $X$ 中，存在两个不同的下标 $i, j$ 使得 $X_i = X_j$。或者存在某个 $i$ 使得 $X_i = 0$（这意味着 $a_i = a_1$）。

如果找到 $X_i = X_j$（此时 $a_i = a_j$），我们可以花费 1 次询问查出 $a_i \wedge a_j$ 的结果。由于 $a_i$ 和 $a_j$ 是同一个数，它们的 AND 操作结果就是它们本身！即 $a_i = a_i \wedge a_j$。知道 $a_i$ 后，立刻通过 $a_1 = a_i \oplus X_i$ 解出 $a_1$。总查询次数：$(n - 1) + 1 = n$ 次，完美符合限制。

**分支 B：数组中所有元素互不相同**

因为元素取值都在 $[0, n - 1]$，且有 $n$ 个互不相同的元素，这说明数组恰好是 0 到 $n - 1$ 的一个排列。这意味着我们的相对数组 $X_1, \ldots, X_n$ 也必定涵盖了 0 到 $n - 1$ 的所有数字。既然数字全覆盖，我们必然能在 $X$ 数组中找到两个特殊的下标 $u$ 和 $v$，满足：

- $X_u = 1$（即 $a_u \oplus a_1 = 1$，说明 $a_u$ 与 $a_1$ 仅在最低位，即第 0 个比特位不同）
- $X_v = 2$（即 $a_v \oplus a_1 = 2$，说明 $a_v$ 与 $a_1$ 仅在第 1 个比特位不同）

我们耗费 2 次询问：

- 查出 $A = a_1 \wedge a_u$。因为它们只在第 0 位不同（一个是 0 一个是 1），它们的 AND 结果会在第 0 位强制清零，但保留了 $a_1$ 除第 0 位之外的所有高位信息。
- 查出 $B = a_1 \wedge a_v$。因为它们只在第 1 位不同，所以它们的 AND 结果必定保留了 $a_1$ 的第 0 位信息！

因此，我们可以将两个信息拼接：

- 对于除最低位外的所有位，直接取 $A$ 的对应位
- 对于最低位，直接取 $B$ 的最低位（即 $B \wedge 1$）

公式化表示就是：$a_1 = A + (B \wedge 1)$。或者 $a_1 = A \mid (B \wedge 1)$。

总查询次数：$(n - 1) + 2 = n + 1$ 次，达到了查询次数的理论极限！

### 核心代码实现：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int qry(string op, int i, int j) {
    cout << op << " " << i << " " << j << "\n";
    cout.flush();
    int res;
    cin >> res;
    return res;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n;
    cin >> n;

    vector<int> X(n + 1, 0);

    // 构建相对坐标系
    for (int i = 2; i <= n; ++i) {
        X[i] = qry("XOR", 1, i);
    }

    // 寻找重复的 X 值
    vector<int> pos(n, -1);
    int dup1 = -1, dup2 = -1;

    for (int i = 1; i <= n; ++i) {
        if (pos[X[i]] != -1) {
            dup1 = pos[X[i]];
            dup2 = i;
            break;
        }
        pos[X[i]] = i;
    }

    int a1;

    if (dup1 != -1) {
        // 分支 A：存在重复元素
        int and_val = qry("AND", dup1, dup2);
        a1 = and_val ^ X[dup1];
    } else {
        // 分支 B：所有元素互不相同，即 0..n-1 的排列
        int u = -1, v = -1;
        for (int i = 1; i <= n; ++i) {
            if (X[i] == 1) u = i;
            if (X[i] == 2) v = i;
        }

        int A = qry("AND", 1, u);
        int B = qry("AND", 1, v);
        a1 = A + (B & 1);
    }

    // 还原整个数组
    vector<int> ans(n + 1);
    ans[1] = a1;
    for (int i = 2; i <= n; ++i) {
        ans[i] = X[i] ^ a1;
    }

    cout << "!";
    for (int i = 1; i <= n; ++i) {
        cout << " " << ans[i];
    }
    cout << "\n";

    return 0;
}
```

## 第八章：常见错误规避与套路总结

无论是在平时训练还是比赛环境下，处理构造题时都很容易陷入思维定势。作为总结，这里把几个高频框架和最常见的陷阱统一收一下。

### 8.1 严防死守的几大误区

**1. 拒绝回溯搜索（No Backtracking）**

如果你在写一道构造题时，试图用 DFS 去深搜寻找可行解，那么 $99\%$ 的情况下你走远了。构造题的核心在于**确定性的逻辑演进**，其推导必须是一条单行道。如果发现状态多到需要剪枝回溯，立刻停下，去重新寻找不变量或奇偶映射。

**2. 谨慎使用浮点数（Avoid Floating-Points）**

很多看似涉及几何或均值分配的构造题，最后必定能转化为代数同余或整数格点模型。引入 `double` 或 `eps` 只会带来精度坍塌。

**3. 不要被大规模吓倒（Think Small, Scale Big）**

面对 $N = 10^5$ 的构造要求，永远先在草稿纸上把 $N = 1, 2, 3, 4$ 的情况手推到极致。绝大多数的归纳增量或模 $K$ 周期性，都是在 $N \leq 4$ 的图谱中暴露无遗的。

### 8.2 一个实用的总览框架：把复杂对象映射到简单模型

构造算法的本质，就是在进行一次高维到低维的同态映射。每当你拿到一道新题时，请在脑海中快速遍历以下武器库：

- 对于数值限制极其严苛的数列：**大数占位法**，将不确定的扰动转移到高位或两端。
- 对于图论路径最值：**拓扑中心逼近法**，找菊花图中心或度数最大的割点，集中分配极端权重。
- 对于矩阵局部形状约束（如无连续三格）：**按坐标和模 $K$ 染色法**，配合鸽巢原理，将整体修改转化为等价类打击。
- 对于未知图的连通或重构：**构建生成树或利用 $\oplus$ 运算建立相对坐标系**，最后单点爆破原点。
- 对于复杂的双向序列操作：**从目标状态逆向操作**，寻找与原初状态连接的代数桥梁。


## 第九章：群论与代数构造

前八章主要解决"看到什么现象，该优先往哪一类构造上想"的问题。接下来这几章把视角推进到更高阶的模型：群论、网络流、欧拉结构、博弈、随机化和高阶交互。重点不是再堆更多术语，而是说明什么时候该把原题改写成这些标准模型，以及改写之后哪些量才是真正需要维护的。

在序列操作与矩阵重排的构造题中，任何可逆的局部操作都必然生成一个**置换群**。构造的核心，在于寻找该操作群生成的**轨道**，并判断目标状态是否与初始状态同属一个等价类。

### 9.1 离散微积分与对换操作的群同构

当题目给定的操作是对序列的局部元素进行非线性变换时，我们的首要任务是寻找一个映射，使得在该映射空间下，非线性变换退化为最基础的代数操作（如相邻对换或符号翻转）。这种思想在本质上属于**离散微积分**的应用。

考虑一种经典变换：对于序列 $A$，选中元素 $A_i$，将其替换为 $A_{i-1} + A_{i+1} - A_i$。直接在原序列上追踪这种变换是极其困难的，因为数值的绝对大小和相对大小都在剧烈波动。然而，如果我们考察其**一阶前向差分空间** $\Delta A$，其中 $\Delta A_i = A_{i+1} - A_i$。

对 $A_i$ 执行上述操作后，新的元素变为 $A_i' = A_{i-1} + A_{i+1} - A_i$。

此时计算新的差分序列：

$$
\Delta A_{i-1}' = A_i' - A_{i-1} = A_{i-1} + A_{i+1} - A_i - A_{i-1} = A_{i+1} - A_i = \Delta A_i
$$

$$
\Delta A_i' = A_{i+1} - A_i' = A_{i+1} - (A_{i-1} + A_{i+1} - A_i) = A_i - A_{i-1} = \Delta A_{i-1}
$$

在差分空间中，这种复杂的数值组合操作完美同构于对称群 $G_{n-1}$ 中的一个**相邻对换** $\tau = (i-1, i)$。由于所有的相邻对换可以生成整个对称群 $G_{n-1}$，这意味着只要差分序列的元素集合相同，且首尾边界固定，序列之间就可以相互转化。


### 核心问题数学刻画

给定长度为 $n$ 的初始序列 $C$ 与目标序列 $T$。每次操作可选取 $2 \leq i \leq n - 1$，令 $C_i \leftarrow C_{i-1} + C_{i+1} - C_i$。判定 $C$ 能否转化为 $T$。

### 算法与复杂度

构建差分序列 $D$ 与 $E$，判断 $C_1 = T_1$ 且 $C_n = T_n$。若满足，且 $D$ 与 $E$ 在排序后完全一致，则可达。时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int n;
vector<ll> c, t, d, e;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    cin >> n;

    c.resize(n);
    for (int i = 0; i < n; ++i) cin >> c[i];

    t.resize(n);
    for (int i = 0; i < n; ++i) cin >> t[i];

    // 验证离散微积分的边界不变量
    if (c[0] != t[0] || c[n - 1] != t[n - 1]) {
        cout << "No\n";
        return 0;
    }

    d.resize(n - 1);
    e.resize(n - 1);

    for (int i = 0; i < n - 1; ++i) {
        d[i] = c[i + 1] - c[i];
        e[i] = t[i + 1] - t[i];
    }

    // 对换操作在差分空间同构于对称群生成，排序验证等价类
    sort(d.begin(), d.end());
    sort(e.begin(), e.end());

    for (int i = 0; i < n - 1; ++i) {
        if (d[i] != e[i]) {
            cout << "No\n";
            return 0;
        }
    }

    cout << "Yes\n";
    return 0;
}
```

### 9.2 多项式理想与有限域操作的核

当操作涉及特定步长的区间翻转或状态切换时，图论视角的连通性往往不再直观。此时，借助于有限域 $GF(2)$ 上的多项式环 $GF(2)[x]$，我们可以深刻揭示状态转移的本质特征。

设长度为 $n$ 的序列，其元素为正负整数。我们可以选择长度为 $B_j$ 的连续子区间，将其内部所有元素的符号翻转。允许任意次数的操作，要求最大化最终序列的元素之和。

首先，符号的翻转本质上是在 $GF(2)$ 上进行异或操作（或者在 $\mathbb{Z}_2$ 上进行加法）。每一次对长度为 $B_j$ 的翻转，等价于在序列上异或一个连续的 $B_j$ 个 1。

将序列的状态表示为多项式 $S(x) = \sum s_i x^i$，其中 $s_i \in \{0, 1\}$ 表示符号是否被翻转。一次操作相当于加上多项式 $x^k \sum_{i=0}^{B_j - 1} x^i$。

考虑到操作的可平移性，我们可以将其与多项式乘法联系起来。为了消除连续 1 的繁琐形式，我们利用差分思想（在 $GF(2)$ 中相当于乘以 $1 - x$ 也就是 $1 + x$）。

翻转长度 $B_j$ 的区间，其差分表现为在位置 $i$ 和 $i + B_j$ 处发生翻转。因此，单次操作在差分多项式上可以表示为加上 $x^k (1 + x^{B_j})$。

这些操作能生成的差分状态张成的空间，本质上是由多项式 $\{1 + x^{B_1}, 1 + x^{B_2}, \ldots\}$ 生成的理想在特定截断下的子模。根据裴蜀定理在多项式环中的推广：

$$
\gcd(1 + x^{B_1}, 1 + x^{B_2}, \ldots) = 1 + x^{\gcd(B_1, B_2, \ldots)}
$$

这意味着，无论给定的 $B_j$ 有多复杂，这一系列操作的效果完全等价于**仅仅允许翻转长度为 $g = \gcd(B_1, B_2, \ldots, B_k)$ 的区间**。

由于操作步长退化为 $g$，我们可以将整个序列按照下标对 $g$ 取模进行剩余类划分。一共划分为 $g$ 个独立的子序列。在每个子序列中，每次操作必然同时翻转该子序列中的一个元素（或者在端点处退化）。通过进一步的代数推导，任何对长度为 $g$ 的区间的翻转，会导致每一个模 $g$ 的剩余类中恰好有一个元素发生符号翻转。

由此得出核心不变量：**所有剩余类中，被翻转的负号数量的奇偶性必须完全一致**（要么所有剩余类翻转了奇数次，要么全部翻转了偶数次）。


### 核心问题数学刻画

给定长为 $n$ 的整数序列 $A$ 和集合 $\{B_j\}$。每次可将 $A$ 中任意长度为 $B_j$ 的连续子段符号取反。求可达状态中序列元素之和的最大值。

### 算法与复杂度

计算 $g = \gcd(B_j)$。将原序列依下标 mod $g$ 划分为 $g$ 个等价类。

分为两类全局状态进行动态规划：
- 状态 0：所有等价类均翻转偶数个负数
- 状态 1：所有等价类均翻转奇数个负数

对于每一类，贪心选取使得和最大化的翻转策略。时间复杂度 $O(n)$，空间复杂度 $O(n)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int t;
int n, m;
vector<ll> a;
vector<int> b;

int gcd_int(int x, int y) {
    while (y) {
        x %= y;
        swap(x, y);
    }
    return x;
}

void slv() {
    cin >> n >> m;

    a.resize(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    b.resize(m);
    int g = 0;
    for (int i = 0; i < m; ++i) {
        cin >> b[i];
        g = gcd_int(g, b[i]);
    }

    ll s0 = 0, s1 = 0;

    // 依据模 g 的等价类进行轨的遍历
    for (int i = 0; i < g; ++i) {
        ll p0 = 0, p1 = -1e18;
        // p0: 偶数次翻转的最大增益，p1: 奇数次翻转的最大增益
        for (int j = i; j < n; j += g) {
            ll v = a[j];
            ll n0 = max(p0 + v, p1 - v);
            ll n1 = max(p1 + v, p0 - v);
            p0 = n0;
            p1 = n1;
        }
        s0 += p0;
        s1 += p1;
    }

    // 全局不变性要求等价类的奇偶一致
    cout << max(s0, s1) << "\n";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    cin >> t;
    while (t--) slv();
    return 0;
}
```

## 第十章：高级图论与网络流映射

当构造问题从线性序列跃升至复杂的网格、二分图或自由拓扑结构时，简单的代数不变量往往不足以刻画问题的全貌。此时，网络流理论（尤其是霍尔定理、最大流最小割定理、带上下界网络流）以及欧拉回路的拓扑特征，就会成为把抽象约束改写成标准模型的主要工具。

### 10.1 流量网络中的上下界平衡与霍尔映射

在图论构造中，我们常遇到对某些节点入度与出度差值的严格约束。此类问题直接构造往往陷入局部最优的死胡同。网络流框架的强大之处在于，它通过霍夫曼循环定理和最小费用最大流，将离散的度数要求连续化，并在多项式时间内找到满足所有守恒律的全局解。

考虑一类经典的染色构造：给定一个图，部分节点预设了颜色（红色或蓝色），未着色节点可自由染色。同时需要为每条边定向。要求最终图中：
- 红色节点的出度必须严格大于入度
- 蓝色节点的入度必须严格大于出度
- 边的方向可任意指定，也可以为边赋予特定的权值代价

要求在满足度数条件下的最小代价。

若直接针对节点建立状态，会发现不同节点的连边产生了极强的后效性（一条边的定向同时改变两个端点的度差）。利用带上下界网络流进行映射：

将"出度严格大于入度"转化为数学表达。设度数为 $d_v$，出度为 $out_v$，入度为 $in_v$。则有 $out_v + in_v = d_v$。

条件 $out_v > in_v$ 等价于 $out_v > d_v - out_v$，即 $out_v \geq \lfloor d_v / 2 \rfloor + 1$。

同理，蓝色节点 $in_v > out_v$ 等价于 $out_v \leq \lceil d_v / 2 \rceil - 1$。

通过将无向图的边初始任意定向（例如全设为正向），若将边反向，相当于正向流量减 1。这样，我们将"边定向"完全转化为了流网络中边的"流量分配"问题。边的正反向转化为 0 和 1 的流量。由于对节点的流量收支有了明确的上下界约束，这完美契合了带上下界的可行流模型。


### 核心问题数学刻画

给定无向图，顶点带红/蓝/无色三种状态。红点出度需大于入度，蓝点入度需大于出度。部分边有方向且可通过支付代价改变方向。构造合法的有向图并最小化总代价。为简化，将其抽象为具有流网络上下界约束的最小费用最大流模型。

### 算法与复杂度

构建源点 $S$ 与汇点 $T$。对于原图每条边 $(u, v)$，容量为 1，费用为修改方向的代价。对于节点的度数要求，转化为对源点汇点的连边，设定流量上下界。使用增广路算法或连续最短路解决带上下界最小费用最大流。时间复杂度 $O(V \cdot E \cdot SPFA)$，但在单位网络且费用极小时，可退化至多项式可解。空间复杂度 $O(V + E)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAX = 505;
const int INF = 1e9;

int v, e;
int s, t, ss, tt;
int nd;

int hd[MAX], nx[MAX * 10], to[MAX * 10], ec = 1;
int cp[MAX * 10], cs[MAX * 10], fl[MAX * 10];

int d[MAX];
int dt[MAX], p[MAX], pe[MAX];
bool iq[MAX];

void add(int u, int w, int c, int w_cs) {
    to[++ec] = w;
    cp[ec] = c;
    cs[ec] = w_cs;
    fl[ec] = 0;
    nx[ec] = hd[u];
    hd[u] = ec;

    to[++ec] = u;
    cp[ec] = 0;
    cs[ec] = -w_cs;
    fl[ec] = 0;
    nx[ec] = hd[w];
    hd[w] = ec;
}

void add_b(int u, int w, int lb, int ub, int w_cs) {
    d[u] -= lb;
    d[w] += lb;
    add(u, w, ub - lb, w_cs);
}

bool spfa() {
    for (int i = 0; i <= nd; ++i) {
        dt[i] = INF;
        iq[i] = false;
    }

    queue<int> q;
    q.push(ss);
    dt[ss] = 0;
    iq[ss] = true;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        iq[u] = false;

        for (int i = hd[u]; i; i = nx[i]) {
            int w = to[i];
            if (cp[i] > fl[i] && dt[w] > dt[u] + cs[i]) {
                dt[w] = dt[u] + cs[i];
                p[w] = u;
                pe[w] = i;
                if (!iq[w]) {
                    iq[w] = true;
                    q.push(w);
                }
            }
        }
    }

    return dt[tt] != INF;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    // 这里以抽象输入为例
    // 实际中根据题目颜色状态设定 lb 与 ub
    cin >> v >> e;

    s = v + 1;
    t = v + 2;
    ss = v + 3;
    tt = v + 4;
    nd = tt;

    // ... 图构建逻辑（省略具体繁杂的上下界分类以突出核心流图）

    add(t, s, INF, 0);  // 将有源汇转为无源汇循环流

    // 平衡度数
    for (int i = 1; i <= t; ++i) {
        if (d[i] > 0) add(ss, i, d[i], 0);
        else if (d[i] < 0) add(i, tt, -d[i], 0);
    }

    int cst = 0;
    while (spfa()) {
        int a = INF;
        for (int u = tt; u != ss; u = p[u]) {
            int idx = pe[u];
            a = min(a, cp[idx] - fl[idx]);
        }

        for (int u = tt; u != ss; u = p[u]) {
            int idx = pe[u];
            fl[idx] += a;
            fl[idx ^ 1] -= a;
            cst += a * cs[idx];
        }
    }

    // 检查所有超级源点的边是否满流，判断合法性
    for (int i = hd[ss]; i; i = nx[i]) {
        if (cp[i] > fl[i]) {
            cout << -1 << "\n";
            return 0;
        }
    }

    cout << cst << "\n";
    return 0;
}
```

### 10.2 欧拉回路的拓扑分解与奇偶度匹配

在处理带有权重的图论结构，并被要求对边进行定向以满足某种局部度数平衡时，欧拉回路是最优雅且深刻的构造结构。根据维布伦定理，任何一个连通且所有节点度数均为偶数的图，均可被分解为若干个边不相交的回路集合。

如果在图中跑一条欧拉回路并为其指定方向，那么由于回路上每一条边都是首尾相接的，对于回路上的任意一个节点，每次回路进入该节点，必然紧接着离开该节点。这保证了一个极强的局部不变量：**在欧拉回路所指定的有向图中，每一个节点的入度严格等于出度**。

考察更为复杂的问题：图中边带有两种权重 $w \in \{1, 2\}$。我们需要为每条边指定方向，使得尽可能多的节点满足其绝对差值限制：$|\sum w_{out} - \sum w_{in}| = 1$。注意到权值的奇偶性导致了一个天然的代数屏障：如果一个节点相连的权重为 1 的边总数为偶数，无论如何分配方向，其总和的绝对差必为偶数，永远不可能等于 1。因此，可能达到目标条件的节点，其连接的 1-边的度数必须为奇数。

我们可以利用欧拉回路来"吸收"多余的度数波动：

首先，将图中权重为 1 的边和权重为 2 的边剥离开来。

在权重为 1 的子图中，找到所有奇度数节点。根据握手定理，奇度数节点必然有偶数个。我们引入一个虚拟节点或将它们两两匹配，连上虚拟的 1-边。此时子图中所有节点度数均为偶数，必然存在欧拉回路。

由于虚拟边连接了两个奇度数节点，在欧拉回路定向后删去这些虚拟边，这两个节点在 1-边子图中的入度与出度之差恰好为 1 或 -1。

同理，对权重为 2 的子图执行类似操作。巧妙的是，即便我们将 1-边和 2-边的未闭合端点连通，只需将两张图统一为一张大图跑欧拉路径，所有权重的代数和均会自动在奇偶性交替的循环中达到最优平衡。


### 核心问题数学刻画

给定 $n$ 点 $m$ 边的无向图，边权 $w_i \in \{1, 2\}$。为每条边定向，最大化满足 $|\sum w_{out} - \sum w_{in}| = 1$ 的节点数，并输出定向方案。

### 算法与复杂度

构建两个邻接表分别存储 1-边和 2-边。对于 1-边的奇度数点，两两之间连虚拟边。对 2-边的奇度数点同样处理。最后对剩余的未平衡节点在 1 和 2 之间跨层连虚拟边。在增强后的图上运行 Hierholzer 算法寻找欧拉路径。时间复杂度 $O(n + m)$，空间复杂度 $O(n + m)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 3e5 + 5;
const int MAXM = 6e5 + 5;

int n, m;
int hd[3][MAXN], to[3][MAXM], nx[3][MAXM], id[3][MAXM];
int we[MAXM], pt[3];
int d[3][MAXN];
bool vs[MAXM];
int as[MAXM];

void add(int t, int u, int v, int idx) {
    to[t][++pt[t]] = v;
    id[t][pt[t]] = idx;
    nx[t][pt[t]] = hd[t][u];
    hd[t][u] = pt[t];

    to[t][++pt[t]] = u;
    id[t][pt[t]] = -idx;
    nx[t][pt[t]] = hd[t][v];
    hd[t][v] = pt[t];

    d[t][u]++;
    d[t][v]++;
}

void dfs(int t, int u) {
    for (int &i = hd[t][u]; i; i = nx[t][i]) {
        if (vs[abs(id[t][i])]) continue;
        int idx = id[t][i];
        int v = to[t][i];
        vs[abs(idx)] = true;
        as[abs(idx)] = (idx > 0 ? 1 : 2);  // 1为正向，2为反向
        dfs(t, v);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    cin >> n >> m;

    pt[1] = pt[2] = 1;

    for (int i = 1; i <= m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        add(w, u, v, i);
        we[i] = w;
    }

    int c1 = 0;
    for (int i = 1; i <= n; ++i) {
        if (d[1][i] % 2 != 0) c1++;
    }

    // 利用 Dummy Vertex (节点 0) 吸收奇度数节点，保证欧拉回路的必然存在
    int e = m;

    for (int t = 1; t <= 2; ++t) {
        int l = 0;
        for (int i = 1; i <= n; ++i) {
            if (d[t][i] % 2 != 0) {
                if (l) {
                    add(t, l, i, ++e);
                    l = 0;
                } else {
                    l = i;
                }
            }
        }
        if (l) add(t, l, 0, ++e);
    }

    // 多层图联合 DFS 生成拓扑回路
    for (int t = 1; t <= 2; ++t) {
        for (int i = 1; i <= n; ++i) dfs(t, i);
        dfs(t, 0);
    }

    cout << c1 << "\n";
    for (int i = 1; i <= m; ++i) cout << as[i];
    cout << "\n";

    return 0;
}
```

## 第十一章：博弈论与状态空间

当构造问题引入对抗性交互，单向的状态转换便跃升为博弈论中的状态空间遍历。在这类进阶构造中，我们面临的挑战是：不仅要证明目标状态的存在性，更要为己方构建一条能够绝对收敛至胜利状态的动态决策轨，同时封死对手的所有逃逸路线。

此时，传统的状态压缩动态规划将受制于指数级爆炸的空间维度。破局的核心，在于提取状态图中的**同构映射**与**代数零化子**，通过对称性与 SG 泛函完成无限空间向有限代数结构的降维。

### 11.1 组合游戏中的同构映射与对称性构造

在无偏博弈中，如果状态空间本身具有拓扑对称性或可以通过某次前置操作划分出两个同构的子空间，那么寻找必胜策略就等价于寻找一个**对合自同构映射** $\phi: S \to S$，使得 $\phi(\phi(x)) = x$ 且对于任意合法转移 $x \to y$，均存在对称转移 $\phi(x) \to \phi(y)$。

这种对称性构造的本质，是迫使对手在两个同构的子状态图之间进行受迫振荡。己方只需作为"镜像复读机"，即可将任何极高复杂度的博弈过程，化归为 $O(1)$ 的同构跟随。

在网格、环形或树形结构的博弈构造中，若起手状态不对称，第一步操作的绝对使命就是**重塑对称性**。无论是取走中心节点、切割环为链，还是将图剖分为两张完全一致的子图，均服务于这一代数目标。

### 11.2 尼姆积、SG 泛函与自动机状态合并

当游戏不存在直观拓扑对称性时，我们需要利用 Sprague-Grundy 定理，将任何有向无环图上的无偏博弈映射为一维的 Nim 游戏。

对于状态 $x$，其 SG 泛函定义为：

$$
g(x) = \operatorname{mex}\{g(y) \mid x \to y\}
$$

而在复合游戏中，全局状态 $G = (x_1, x_2, \ldots, x_k)$ 的等价评估值为各子状态的 Nim-Sum（尼姆异或和）：

$$
\mathcal{G}(G) = \bigoplus_{i=1}^{k} g(x_i)
$$

在构造题中，题目往往要求我们对给定的初始结构进行赋值或切分，使得其对应的 $\mathcal{G}(G) = 0$（必败态，用于限制对手）或 $\mathcal{G}(G) \neq 0$（必胜态，用于己方获胜）。这里的核心难点在于，如何在非线性的网格或树上剥离出相互独立的子游戏。

考虑一个二维矩阵空间的博弈：给定 $n \times m$ 的数字矩阵，每次操作可选择一个非零元素 $A_{r,c}$ 将其减小，随后可以任意修改所有满足 $i \geq r, j \geq c$ 且 $(i,j) \neq (r,c)$ 的元素 $A_{i,j}$。不能操作者败。

表面上看，这种"任意修改"带来了不可预测的后效性，破坏了子游戏的独立性。但若运用线性代数的特征子空间进行等价类划分，提取副对角线族作为不变量：

令 $D_k = \{(i,j) \mid i + j = k\}$。一次以 $(r,c)$ 为主元的操作，必然会严格减小 $D_{r+c}$ 上的某个元素，并且只能影响 $k > r + c$ 的对角线 $D_k$ 上的元素。

如果我们定义每条副对角线的一维代数特征为：

$$
L_k = \bigoplus_{(i,j) \in D_k} A_{i,j}
$$

由于操作者严格改变了 $D_{r+c}$ 中的一个元素，他必然打破了 $L_{r+c}$ 原有的值。同时，他可以利用后续的"任意修改"权限，强行调整所有更深层对角线 $L_k$（$k > r + c$）的异或和。

这一连续降维操作完美同构于拥有 $n + m - 1$ 堆石子的标准 Nim 游戏！我们通过对角线投影，将二维矩阵的后效性操作，转化为一维独立的独立博弈。


### 核心问题数学刻画

判定初始矩阵是否为先手必胜态。必胜态等价于存在某一对角线异或和 $L_k \neq 0$；必败态等价于所有 $L_k = 0$。

### 算法与复杂度

对于每次询问，线性遍历矩阵，统计每条副对角线的异或和。验证是否全为 0。时间复杂度 $O(nm)$，空间复杂度 $O(n + m)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int t;
int n, m;
int a[55][55];
int s[110];

void slv() {
    cin >> n >> m;

    for (int i = 0; i < n + m; ++i) s[i] = 0;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> a[i][j];
            // 将二维空间映射到副对角线族，构建 Nim-Sum 不变量
            s[i + j] ^= a[i][j];
        }
    }

    // 寻找代数零化子：若所有堆的异或和皆为 0，则为必败态
    bool w = false;
    for (int i = 0; i < n + m - 1; ++i) {
        if (s[i] != 0) {
            w = true;
            break;
        }
    }

    if (w) cout << "Jeel\n";
    else cout << "Ashishgup\n";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    cin >> t;
    while (t--) slv();
    return 0;
}
```

## 第十二章：概率方法与随机化构造

当构造性约束从局部弱耦合演变为全局强耦合（如高维图论的极大独立集、强约束下的多元同余方程组）时，传统的确定性贪心算法往往会触碰 NP-Hard 的边界。此时，引入概率论与测度论，利用高维空间中"合法解占比足够大"的性质，往往会更自然。

### 12.1 概率论边界与 Las Vegas 范式

在许多高阶序列或数论构造中，我们被要求找到一个使得某种全局性质最优的参数。如果正向推演的搜索树极其庞大，但最优解在整个可能的状态空间中具有明确的密度下界，那么 Las Vegas 随机化算法将是唯一的破局之道。Las Vegas 范式的精髓在于：**结果绝对正确，运行时间是概率变量，但在期望意义下极小**。

考虑一个经典问题：给定数组 $A_1, \ldots, A_n$，每次操作可将某个元素加 1 或减 1，代价为 1。要求用最少操作次数，使得所有元素的极大公约数 $g > 1$。

因为将所有奇数加 1 变为偶数最多只需 $n$ 次操作（此时 $g = 2$），所以全局最小操作次数的理论上界严格为 $n$。

根据马尔可夫不等式的离散推广，在最优决策方案中，必然存在**至少一半的元素**，其自身的操作次数不超过 1（即取值只能是原值 $x$，$x-1$ 或 $x+1$）。这意味着，如果我们从序列中均匀随机抽取一个元素 $x$，它恰好属于这"保守的一半"的概率至少为 $1/2$。只要我们抽取了这个正确的锚点，最优的全局质因数 $g$ 必定包含在 $x-1, x, x+1$ 的质因数集合中。

通过进行 $K$ 次独立均匀重采样，未能命中任何有效锚点的概率呈指数衰减：

$$
\Pr(\text{Failure}) \leq \left(\frac{1}{2}\right)^K
$$

当 $K = 30$ 时，失败概率已低于 $10^{-9}$，在计算理论中等价于必然事件。这允许我们将一个复杂的全局非线性规划问题，完全降阶为常数规模的质因数分解与线性扫描。


### 核心问题数学刻画

给定 $A_1, \ldots, A_n$，求 $\min \sum |A_i - B_i|$ 使得 $\gcd(B_1, \ldots, B_n) > 1$。

### 算法与复杂度

维护全局最小代价。随机抽取序列中约 30 个元素。对每个元素 $x$，将其 $x-1, x, x+1$ 进行质因数分解。对于得到的所有素数候选者 $p$，线性扫描全序列计算代价，并更新答案。时间复杂度 $O(K \cdot n)$，空间复杂度 $O(n)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int n;
vector<ll> a;
ll ans;
mt19937_64 rnd(19937);

void chk(ll p) {
    ll c = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] < p) {
            c += p - a[i];
        } else {
            ll r = a[i] % p;
            c += min(r, p - r);
        }
        if (c >= ans) return;  // 最优性剪枝
    }
    ans = min(ans, c);
}

void ext(ll v) {
    if (v <= 1) return;
    for (ll i = 2; i * i <= v; ++i) {
        if (v % i == 0) {
            chk(i);
            while (v % i == 0) v /= i;
        }
    }
    if (v > 1) chk(v);
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    cin >> n;

    a.resize(n);
    ans = n;  // 全局平移至偶数的理论上界

    for (int i = 0; i < n; ++i) cin >> a[i];

    // 依均匀分布采样以极化概率下界
    for (int k = 0; k < 30; ++k) {
        int i = rnd() % n;
        ext(a[i] - 1);
        ext(a[i]);
        ext(a[i] + 1);
    }

    cout << ans << "\n";
    return 0;
}
```

### 12.2 局部依赖与构造性 Lovász 局部引理

当构造条件的坏事件发生概率不再趋于 0，且状态之间存在局部纠缠时，单纯的全局重采样将陷入无尽的死循环。此时，我们需要使用高阶概率论工具：**构造性 Lovász 局部引理**（结合 Moser-Tardos 算法）。

假设有 $N$ 个构造违例事件（坏事件）$E_1, E_2, \ldots, E_N$，每个事件发生的概率最大为 $p$，且每个事件最多与 $d$ 个其他事件在变量上具有依赖关系（局部耦合度为 $d$）。

经典的 Lovász 局部引理指出，若满足代数阈值条件：

$$
ep(d + 1) \leq 1
$$

则全局完美合法解不仅严格存在，而且概率严格大于 0。

Moser-Tardos 算法则将这一存在性定理转化为了极其暴力的局部重采样构造：

1. 初始时，对所有变量进行完全随机赋值。
2. 只要发现图中存在某个坏事件 $E_i$ 发生，就将 $E_i$ 所依赖的所有变量强制局部重新随机赋值。
3. 重复步骤 2，直到没有任何坏事件发生。

在上述阈值条件成立的前提下，MT 算法的期望重采样次数不仅有限，而且是多项式级别的！这为所有受到稀疏度限制的高阶构造题提供了一个降维暴力的通行证。


## 第十三章：极限信息论与高阶交互

如果说传统的构造题是在明文的代数空间中绘制图谱，那么交互式构造就是在未知的黑盒中进行信息重构。此时，每次查询本质上是向黑盒抛出一个测试函数，并通过其返回值切分巨大的状态空间。

### 13.1 黑盒重构与信息熵下界

对于交互式构造，我们必须建立严格的信息论视角。设隐藏状态空间大小为 $S$（例如对于未知排列，$S = n!$），每次查询返回 $K$ 种可能的结果。由香农信息熵原理，任意查询树在最坏情况下的深度 $Q$ 必须满足：

$$
Q \geq \frac{\log_2(S)}{\log_2(K)}
$$

这意味着，若想在限制步数内还原全局状态，我们必须保证每一次交互都能尽可能均匀地平分当前候选状态空间（使其信息增益最大化）。一旦存在某种查询在部分情况下导致极端的偏斜切分，必然给对抗性交互器提供构造最坏数据的漏洞。

### 13.2 分治交互与极限黑盒破译

考虑以下高度抽象的黑盒序列重构：给定隐藏排列 $P_0, \ldots, P_{n-1}$（元素包含 0 到 $n-1$），允许的交互手段仅为：查询 $(u, v)$，黑盒返回两者在二进制下的按位或结果 $P_u \mid P_v$。要求在极少的查询次数（如 $2n$ 左右）内完全确定整个排列。

此时的盲区在于：按位或操作极大地抹杀了原始数据的信息。例如 $x \mid y = 7$，我们无法直接判定是谁贡献了哪一个二进制位。然而，如果我们找到了排列中的**绝对零元**（即数值为 0 的元素），由于 $0 \mid x = x$，一旦零元位置暴露，只需进行 $n - 1$ 次查询，整个排列便唾手可得。核心矛盾转化为：如何用不到 $N$ 次操作在盲态中精确定位 0 的位置。

此时我们将信息论与随机化极致结合。

设我们维护一个当前的"零元候选者" $c$，并已知其真实值 $v = P_c$。

我们线性扫描其他元素 $i$。查询 $c$ 和 $i$ 得到 $ans = P_c \mid P_i$。

如果 $ans = v$，这在二进制下意味着 $P_i$ 的所有 1 的位置都被包含在 $P_c$ 的 1 的位置中，即 $P_i$ 是 $P_c$ 的严格子集（因为排列中没有重复元素）。

所以只要 $ans = v$，就说明 $i$ 是一个比 $c$ 严格更小（包含更少二进制 1）的优等候选者！此时就可以把 $c$ 更新为 $i$。因为最大二进制长度只有 11 位，这种转移最多只可能发生 11 次。

而每次转移后，我们需要确切知道新候选者 $c$ 的真值 $v$ 怎么求？

再次利用概率论极限定理：随机挑选约 20 个不同的索引 $y$，求 $\bigwedge (P_c \mid P_y)$。由于按位或会保留 $P_c$ 的所有位，并随机填补其他位；而在按位与的收敛下，不属于 $P_c$ 的位每次都有极大概率被另一个数的 0 抵消。20 次之后，非 $P_c$ 的位存活的概率 $(1/2)^{20}$ 微乎其微。

这种 $O(\log n)$ 的随机化逼近在自适应对抗测试中绝对收敛，查询总数严格受限于 $20 \times 11 + n + n \approx 2200 \leq 4269$。


### 核心问题数学刻画

在不超过 4269 次 OR 交互内还原长度 $n \leq 2048$ 的排列，且底层评测机自适应。

### 算法与复杂度

维护当前最小元下标 $c$ 与其精确值 $v$。顺序遍历 $i \in [1, n]$，若 $(P_c \mid P_i) = v$，则发生状态迭代，更新 $c = i$，并通过 20 次随机交互精算其新值 $v$。最终 $c$ 必为 0 的下标。时间与查询复杂度均严格 $O(n + K \log n)$，空间复杂度 $O(n)$。

```cpp
#include<bits/stdc++.h>
using namespace std;

int n;
int a[2055];
mt19937 rnd(19937);

int qry(int u, int w) {
    if (u == w) return 0;
    cout << "?" << u << " " << w << endl;
    int r;
    cin >> r;
    return r;
}

int get(int u) {
    int r = (1 << 11) - 1;
    for (int k = 0; k < 25; ++k) {
        int y = rnd() % n + 1;
        while (y == u) y = rnd() % n + 1;
        r &= qry(u, y);
    }
    return r;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    cin >> n;

    int c = 0;
    int v = get(c);

    for (int i = 1; i < n; ++i) {
        if (i == c) continue;
        int q = qry(c, i);
        // 若 P[c] | P[i] 仍等于当前候选值，说明 i 也是更优的零元候选
        if (q == v) {
            c = i;
            v = get(c);
        }
    }

    vector<int> ans(n);
    ans[c] = 0;

    for (int i = 0; i < n; ++i) {
        if (i != c) ans[i] = qry(i, c);
    }

    cout << "!";
    for (int i = 0; i < n; ++i) cout << " " << ans[i];
    cout << endl;

    return 0;
}
```

## 第十四章：组合优化与高维降维

在组合优化类的构造题中，最核心的任务往往不是直接求最值，而是**把高维的全局约束等价地拆解成若干个独立的低维子问题**。本章继续沿用前几章的代数思想，把它推向更复杂的约束场景。

### 14.1 核心案例：CF1630D 的完整代数映射

这道题在前文已经从代数视角出现过。这里不再重复大段抽象表述，而是把真正落到实现里的那几个结论重新收紧。

面对多长度、位置自由的翻转操作，直接贪心或动态规划无异于缘木求鱼。根据裴蜀定理，离散步长的线性组合所能生成的最小正步长为其最大公约数。假设 $B$ 集合中有长度 $b_1$ 与 $b_2$，我们对区间 $[i, i + b_1 - 1]$ 和 $[i + b_1 - b_2, i + b_1 - 1]$ 分别翻转，相当于仅翻转了长度为 $b_1 - b_2$ 的区间。经过欧几里得扩张，所有的翻转操作最终等效于只允许使用长度为 $g = \gcd(B)$ 的区间翻转。

进一步剥离表象，长度为 $g$ 的区间翻转意味着什么？我们对 $[i, i + g - 1]$ 翻转，再对 $[i + 1, i + g]$ 翻转，首尾抵消后，等效于对位置 $i$ 和位置 $i + g$ 两个单点进行了同时翻转。由此，不变量浮出水面：根据模 $g$ 的余数，整个序列 $A$ 被完美划分为 $g$ 个独立的等价类。在任意一个等价类内部，我们可以任意翻转偶数个元素的符号。这意味着，在每个等价类中，**负号的个数奇偶性是守恒的**。而一次长度为 $g$ 的区间翻转，等效于让这 $g$ 个等价类内部的负号个数奇偶性同时改变一次。最终状态只存在两根世界线：

1. 所有等价类均保持初始的负号奇偶性。
2. 所有等价类均翻转一次负号奇偶性。

我们仅需在两种状态中取元素和的极大值。

### 实战代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

ll gcd_ll(ll a, ll b) {
    return b ? gcd_ll(b, a % b) : a;
}

void slv() {
    int n, m;
    cin >> n >> m;

    vector<ll> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    ll g = 0;
    for (int i = 0; i < m; ++i) {
        ll x;
        cin >> x;
        g = gcd_ll(g, x);
    }

    ll c0 = 0, c1 = 0;

    for (int i = 0; i < g; ++i) {
        ll sm = 0, mn = 1e18, cn = 0;
        for (int j = i; j < n; j += g) {
            sm += abs(a[j]);
            if (a[j] < 0) cn++;
            mn = min(mn, abs(a[j]));
        }

        // cn为偶数，当前等价类最优解直接全正；为奇数则必须牺牲一个最小绝对值
        if (cn % 2 == 0) {
            c0 += sm;
            c1 += sm - 2 * mn;
        } else {
            c0 += sm - 2 * mn;
            c1 += sm;
        }
    }

    cout << max(c0, c1) << "\n";
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int t;
    cin >> t;
    while (t--) slv();

    return 0;
}
```

> https://codeforces.com/problemset/problem/1630/D

- 时间复杂度：序列扫描与等价类划分无交集地覆盖全图，操作复杂度为 $O(N + M \log(\max B))$。
- 空间复杂度：仅维护原序列数组，空间复杂度为 $O(N)$。


## 第十五章：多维约束下的网络流与图论降维

当构造题在二维矩阵或网格图上施加行、列的独立双重约束时，其底层往往指向二分图匹配、带上下界网络流或欧拉回路。将多维约束降维为图论的节点度数约束，是此类问题的标准杀招。

### 15.1 核心案例：Mike and Fish

**题目概括**：在二维平面上给出 $N$ 个坐标点。要求为每个点染色（红或蓝），使得在每一条水平线（行）和每一条垂直线（列）上，红色点与蓝色点的数量差绝对值不超过 1。

### 理论映射与思维收敛：

"数量差不超过 1"是极其强烈的图论度数暗示。

我们将行横坐标抽象为左部节点 $X$，纵坐标抽象为右部节点 $Y$。平面上的一个点 $(x_i, y_i)$，完美映射为连接左部节点 $x_i$ 与右部节点 $y_i$ 的一条无向边。

染红蓝双色，等同于为这条无向边定向。红色代表 $X \to Y$，蓝色代表 $Y \to X$。题目约束"行内红蓝点数量差 $\leq 1$"，在图论视角下即为：左部节点的出度与入度差 $\leq 1$。右部节点同理。

若所有节点的度数均为偶数，根据欧拉图性质，图中必然存在欧拉回路。在欧拉回路中沿着路径交替定向（一条正向，一条反向），每个节点必然是一进一出，此时出度与入度差严格为 0。若存在奇数度数节点怎么办？根据握手定理，奇度数节点必然有偶数个。我们只需建立一个超级虚拟节点（虚拟源汇），将所有奇度数节点向该虚拟节点连一条辅助边。此时全图皆为偶数度，跑一次全局欧拉回路即可。最后将辅助边舍弃，剩下的有向边即为完美染色方案，奇度数节点的出入度差必然严格为 1。

### 实战代码：

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 600005;
int hd[N], to[N], nx[N], id[N];
int dg[N], vs[N], an[N];
int ct = 1;

void add(int u, int v, int i) {
    to[++ct] = v;
    nx[ct] = hd[u];
    id[ct] = i;
    hd[u] = ct;
    dg[u]++;

    to[++ct] = u;
    nx[ct] = hd[v];
    id[ct] = i;
    hd[v] = ct;
    dg[v]++;
}

void dfs(int u) {
    for (int &i = hd[u]; i; i = nx[i]) {
        int e = i / 2;
        if (vs[e]) continue;
        vs[e] = 1;
        int v = to[i], c = id[i];
        if (c > 0) an[c] = (i % 2);
        dfs(v);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n;
    cin >> n;

    for (int i = 1; i <= n; ++i) {
        int x, y;
        cin >> x >> y;
        add(x, y + 200000, i);
    }

    // 奇数度数节点向超级源点 0 连边补齐
    int ls = 0;
    for (int i = 1; i <= 400000; ++i) {
        if (dg[i] % 2 != 0) {
            if (ls) {
                add(ls, i, 0);
                ls = 0;
            } else {
                ls = i;
            }
        }
    }

    // Hierholzer 算法求欧拉回路交替染色
    for (int i = 1; i <= 400000; ++i) {
        if (hd[i]) dfs(i);
    }

    for (int i = 1; i <= n; ++i) {
        cout << (an[i] ? 'r' : 'b');
    }
    cout << "\n";

    return 0;
}
```

> https://codeforces.com/problemset/problem/547/D

### 复杂度剖析：

- 时间复杂度：由于采用引用传递 `&i = hd[u]`（当前弧优化）的 Hierholzer 算法，每条边严格遍历一次，时间复杂度为 $O(N + \max(X,Y))$。
- 空间复杂度：构建链式前向星图与记录答案数组，空间复杂度为 $O(N + \max(X,Y))$。


## 第十六章：随机化与代数构造的结合

当操作集合在常规代数域上显得很难直接控制时，确定性硬推往往会迅速变得臃肿。此时，把随机化和代数工具放在一起看，往往能把"先造工具、再造目标"的过程压缩得很干净。

### 16.1 核心案例：XOR Inverse

**题目概括**：给定一个奇数 $x$。你仅允许使用两种操作：$A + B$ 与 $A \oplus B$，且操作数必须是初始或已构造出的数字。要求在不超过 $10^5$ 次操作内，构造出数字 1。中间结果限制在 $5 \times 10^{18}$ 范围内。

### 理论映射与思维收敛：

加法代表了实整数环 $\mathbb{Z}$，而异或代表了伽罗瓦域 $\mathbb{F}_2$ 上的多项式运算。题目要求用这两个完全正交的代数系统联手逼近 1。

我们需要在两种运算间寻找一座数学桥梁。思考：在什么条件下，整数域的减法与位运算域的异或能等效？

若 $A - B = 1$，说明 $A$ 比 $B$ 大 1。若此时 $B$ 为偶数，则 $B$ 的二进制最低位必为 0，$A$ 的最低位必为 1，且两者除最低位外的所有高位完全一致。

这就得到一个非常关键的桥梁：若 $A - B = 1$ 且 $B \equiv 0 \pmod{2}$，则必定有 $A \oplus B = 1$。

于是构造目标从"位运算拼凑"转化为求解线性丢番图方程 $A - B = 1$。

我们只需在 $\mathbb{Z}$ 上找到 $a, b$，使得 $a \cdot x - b \cdot y = 1$。根据扩展欧几里得定理，只要 $\gcd(x, y) = 1$，方程必然有解。

$y$ 从何而来？我们直接通过随机化生成！由于 $x$ 是奇数，我们随机选取一个偏移量 $k$，令 $z = x \ll k$（即 $x$ 不断加自己 $k$ 次），此时 $z$ 必然为偶数。

令 $y = x \oplus z$，此时奇数异或偶数，$y$ 依然为奇数。

若 $\gcd(x, y) = 1$，则存在 $A = a \cdot x$ 与 $B = b \cdot y$ 满足 $A - B = 1$。

进一步，若解得的 $B$ 并非偶数怎么办？由于 $A' = A + y \cdot x$，$B' = B + x \cdot y$，由于 $x$ 是奇数，若 $b$ 是奇数，加上 $x$ 后必定变为偶数！

至此，我们用加法（倍增思想实现乘法）构造出 $A$ 和 $B$，最后再异或一次就能得到 1。

### 实战代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

ll f1[100005], f2[100005];
char op[100005];
int tp = 0;

void ad(ll u, ll v) {
    f1[tp] = u;
    f2[tp] = v;
    op[tp] = '+';
    tp++;
}

void xo(ll u, ll v) {
    f1[tp] = u;
    f2[tp] = v;
    op[tp] = '^';
    tp++;
}

ll mul(ll v, ll c) {
    ll r = 0;
    while (c > 0) {
        if (c & 1) {
            if (r == 0) r = v;
            else { ad(r, v); r += v; }
        }
        c >>= 1;
        if (c > 0) { ad(v, v); v += v; }
    }
    return r;
}

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (!b) { x = 1; y = 0; return a; }
    ll x1, y1, d = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return d;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    ll x;
    cin >> x;

    mt19937 rng(19260817);

    while (true) {
        int k = rng() % 20 + 1;
        ll z = mul(x, 1LL << k);
        ll y = x ^ z;
        xo(x, z);

        ll a, b;
        if (exgcd(x, y, a, b) == 1) {
            a = (a % y + y) % y;
            b = (a * x - 1) / y;

            if (b % 2 != 0) {
                a += y;
                b += x;
            }

            ll A = mul(x, a);
            ll B = mul(y, b);
            xo(A, B);
            break;
        }
    }

    cout << tp << "\n";
    for (int i = 0; i < tp; ++i) {
        cout << f1[i] << " " << op[i] << " " << f2[i] << "\n";
    }

    return 0;
}
```

> https://codeforces.com/problemset/problem/1427/E

### 复杂度剖析：

- 时间复杂度：由于 $\gcd = 1$ 的分布极其稠密，随机次数期望 $\leq 3$。倍增乘法最多需要约 60 步加法，常数极小。时间复杂度 $O(\log^2(\max(A, B)))$。
- 空间复杂度：仅记录操作步骤，空间复杂度 $O(\text{操作数}) \approx O(\log(\max(A, B)))$。


## 第十七章：高阶交互与信息熵视角

交互题最容易让人误入的误区，是把它当成"会不会猜"的问题。更准确的视角是：每次询问到底缩小了多少候选空间，哪些信息值得花预算去确认，哪些信息只需要近似地锁定到一个候选者身上。

### 17.1 核心案例：X-OR

**题目概括**：有一个 $0 \ldots N - 1$ 的隐藏排列 $P$（$N \leq 2048$）。你最多可以进行 4269 次询问，每次询问可得到 $P[i] \mid P[j]$ 的值。求该排列 $P$。

### 理论映射与思维收敛：

若能找到值为 0 的元素所在索引 $z$，那么其余所有元素都可以通过 $P[i] \mid 0 = P[i]$ 直接读出来。因此，题眼在于用尽量少的代价找到 0 的位置。

这里有两个关键观察：

1. 如果固定一个位置 $x$，随机询问若干次 $P[x] \mid P[y]$，再把这些结果按位与起来，额外混入的高位会逐步被消掉，最后留下的就是 $P[x]$ 本身。于是我们可以用十几次随机询问，比较稳定地恢复某个候选位置的真实值。

2. 如果当前候选者是 $c$，并且我们已经知道了 $v = P[c]$，那么对任意位置 $i$ 查询一次 $q = P[c] \mid P[i]$。若 $q = v$，说明 $P[i]$ 的所有二进制 1 位都已经包含在 $P[c]$ 中，也就是说 $i$ 是一个不比当前候选更差的零元候选。

于是做法就很自然了：维护一个当前候选者 $c$，先用若干次随机询问恢复它的真实值 $v$；随后线性扫描所有其他位置。每当发现某个 $i$ 满足 $\text{ask}(c, i) = v$，就把候选者更新成 $i$，并重新用随机方式恢复新候选者的值。

由于排列中的值都在 $[0, n - 1]$，二进制位数至多只有 11 位；候选者真正更新的次数不会很多，因此总查询次数仍能稳定压在限制以内。最后得到零元位置后，再做一遍线性扫描即可恢复整组排列。

### 实战代码：

```cpp
#include<bits/stdc++.h>
using namespace std;

int ask(int i, int j) {
    cout << "?" << i + 1 << " " << j + 1 << endl;
    int r;
    cin >> r;
    return r;
}

int get(int i, int n) {
    int r = (1 << 11) - 1;
    for (int k = 0; k < 15; ++k) {
        int j = rand() % n;
        while (j == i) j = rand() % n;
        r &= ask(i, j);
    }
    return r;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    srand(19260817);

    int n;
    cin >> n;

    int c = 0;
    int v = get(0, n);

    for (int i = 1; i < n; ++i) {
        if (i == c) continue;
        int q = ask(c, i);
        // 若 P[c] | P[i] 仍等于当前候选值，说明 i 也是更优的零元候选
        if (q == v) {
            c = i;
            v = get(c, n);
        }
    }

    vector<int> ans(n);
    ans[c] = 0;

    for (int i = 0; i < n; ++i) {
        if (i != c) ans[i] = ask(i, c);
    }

    cout << "!";
    for (int i = 0; i < n; ++i) cout << " " << ans[i];
    cout << endl;

    return 0;
}
```

### 复杂度剖析：

- 交互查询复杂度：大致为两次线性扫描外加若干次候选者更新时的随机校准。由于更新次数很少，总查询次数可以稳定控制在限制以内。
- 空间复杂度：仅分配长为 $N$ 的数组保存答案，空间复杂度为 $O(N)$。
