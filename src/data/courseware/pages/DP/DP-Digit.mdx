## 数位DP

数位DP是一类计数问题的统称，它要求记录在一个大小范围内的数/字符串的某种权值。

比如最常见的数位DP是：求在一段区间$[l,r]$内满足一定条件的数的个数。

首先，面对这种问题一般都会先把两个限制拆成一个，求$[0,r]$内满足条件的个数减去$[0,l-1]$内满足条件的个数。

对于这种只有上限的数位DP，有两种基本的方法。

## 方法一

我们把上限$n$先数位分解为$n[0..m]$，从高往低位扫，扫到第$k$位时统计以$n[k+1 \cdots m]$为前缀，且第$k$位严格小于$n[k]$的数的信息和。如果这项信息能够$O(1)$直接计算就可以带入，如果不能，可以先预处理一个数组$f[i][j]$表示最高位$a[i]=j$，且$0 \sim i-1$位都任意填的所有数的信息和。

## 方法二

方法一有一定的局限性，它要求对于$n[k+1..m]$这些数位的信息要能够和$0..k-1$位的信息快速合并。还有另一种记忆化搜索的方式可以有效解决这个问题。我们从高位往低位搜索，每次枚举某一位填的数，然后用$pre[i][S]$表示$0 \sim i$位任意填，同时高位的数的信息状态为$S$的信息总和。在DFS时我们还加一个布尔参数$t$，表示当前枚举的高位是否严格等于$n$。如果$t=0$，可以对这一部分记忆化；如果$t=1$，则递归下去。最多只有$O(\text{位数})$个状态的$t=1$，其余部分进行记忆化，复杂度是$O(\text{状态数})$。

##### CF1073E Segment Sum

给定两个整数$l$和$r$（$l \leq r$）。计算从$l$到$r$之间所有数字中，每个数字最多包含$k$种不同数字的数的和，并输出该和对$998244353$取模的结果。

例如，如果$k = 1$，计算所有只由一种数字组成的数。在$l = 10, r = 50$时，答案为$11 + 22 + 33 + 44 = 110$。

$1 \le l \le r < 10^{18},\ 1 \le k \le 10$

<CollapsibleComponent title="做法"> 
设$f_{i,S,x,y},\ g_{i,S,x,y}$表示：当前确定了第$i$位到最高位，digit的集合是$S$，$x$代表与$N$卡满的关系，$y$代表是否全$0$。$f$表示在这个前提下，有多少填低位的方案；$g$表示这些方案填的数的和。

答案：

$$
\sum_{\text{popcount}(S)=k} g_{n,S,0,1}
$$

##### 计蒜之道 商汤的智能机器人

商汤推出了一款智能机器人，可以在一个无限大的二维平面内移动。

机器人初始在$(0,0)$点，它想移动到$(x,y)$点。每次机器人必须向右移动一格，然后再选择向上、向下或向右移动一格。

问：从$(0,0)$点移动到$(x,y)$点共有多少种方案？答案对$100003$取模。

$x,y \le 10^{18}$
    
<CollapsibleComponent title="做法"> 
    
计算：$\sum_{k=0}^{x}\binom{x+y+k}{k}\binom{x+y}{y+k} \bmod (10^5+3)$。

用$f[i][t1][t2][d]$表示在$p$进制下考虑了从小到大的第$i$位，第$i$位的$x+y+k$进位情况$(0,1,2)$，第$i$位的$y+k$的进位情况$(0,1)$，以及前$i$位的$k$是否越界（数位DP常用的状态）。

转移：枚举$k$在第$i+1$位的取值，然后用阶乘式$O(1)$计算在这一位的组合数，并与$f[t1][t2][d]$累乘加到下一位。

取$f[\log(\max)][0][0][0]$即为答案。

注意：这里的数位DP由于要考虑低位对高位的进位情况，采用从小往大的方式比较方便。
</CollapsibleComponent>
  
##### 例题
有$N$种消耗$1$点能量的设施和$M$种消耗为$2$点能量的设施，每一种都可以建造任意个。

求总共消耗$K$点能量来建造设施的方案数，答案模$p$。

$t \le 20,\ n, m \le 10^5,\ k \le 10^{12},\ p \le 10^6$，$p$为质数。
    
<CollapsibleComponent title="做法"> 


计算：$\sum_{i=0}^{\left\lfloor \frac{k}{2} \right\rfloor}\binom{k-2i+n-1}{n-1}\binom{i+m-1}{m-1}$。

这些组合数用卢卡斯定理+数位DP，并用乘法分配律合并后可简化。由于式子带减法，不仅要考虑低位往高位进位，还要考虑借位，状态的取值由$0,1,2$变成了$-2,-1,0,1,2$。

</CollapsibleComponent>

##### 位运算

给一个长度为$n$的序列$a$，有$q$组询问，每次询问给定参数$A,B,C,k,x$。

求解：构造序列$b_i = A \times \text{popcount}(a_i\ \text{and}\ x) + B \times \text{popcount}(a_i\ \text{or}\ x) + C \times \text{popcount}(c_i\ \text{xor}\ x)$，求$b$中第$k$小的数。

$n \le 10^6,\ s,q,A,B,C < 2^{16}$

<CollapsibleComponent title="做法"> 

注意到$\text{popcount}$函数的取值范围很小，因此可以把三个$\text{popcount}$的值作为状态来DP方案数。

因为是位运算，可以一位一位DP。

注意到$n$很大，所以复杂度需要避免和$n$相关。处理方式：一开始$x$还没有确定，而每个$a_i$是确定的；每处理完一位，$x$就多了一位，同时每个$a_i$就少了一位。

用$dp[i][x][s][a][b][c]$表示已经确定了$x$的前$i$位，有多少个$a_i$满足还没有确定的位为$s$，同时已经确定的位和$x$的and、or、xor的$\text{popcount}$分别为$a,b,c$的方案数。

优化：注意到$c=b-a$，所以不用记录$c$。

复杂度$O(16 \times 2^{16} \times 16^2)$。
</CollapsibleComponent>

##### arc222_d Shift and Add 

定义非负整数 $n$ 的**数位和**为 $n$ 在十进制表示下各位数字之和。例如，2026 的数位和为 $2 + 0 + 2 + 6 = 10$。

给定正整数序列 $A = (A_1, A_2, \ldots, A_N)$ 和 $B = (B_1, B_2, \ldots, B_N)$。

利用 $A$ 和 $B$，按如下方式定义整数序列 $X = (X_0, X_1, X_2, \ldots, X_N)$：

- 设 $X_0 = 0$。
- 对于每个 $i = 1, 2, \ldots, N$，选择 $X_i = 10X_{i-1} + A_i$ 或 $X_i = 10X_{i-1} + B_i$ 来确定 $X_i$。

对于每个 $k = 1, 2, \ldots, N$，求 $X_k$ 的最小可能数位和。

每个 $k$ 独立求解。也就是说，对于不同的 $k$，为使 $X_k$ 的数位和最小，确定整数序列 $X$ 的方式可以不同。

- $1 \leq N \leq 20000$
- $1 \leq A_i \leq 10^9 - 1$
- $1 \leq B_i \leq 10^9 - 1$
- 所有输入值均为整数。

<CollapsibleComponent title="做法"> 
简要题解：基于大数加法模型的动态规划

这道题的核心难点在于每次递推 $X_i = 10X_{i-1} + C_i$ 都会改变整个数字的量级，直接维护数值显然不可行。破局的关键在于将序列的递推转化为**竖式加法模型**。

1. 模型转换：从递推到竖式加法

如果我们把 $X_k$ 的生成过程展开，可以得到一个关于 $10$ 的多项式：

$$
X_k = C_k + 10 \cdot C_{k-1} + 100 \cdot C_{k-2} + \dots + 10^{k-1} \cdot C_1
$$

（其中 $C_i \in \{A_i, B_i\}$）

观察这个式子可以发现，这本质上就是一个**从右向左进行的大数加法**。

* 序列的最后一个元素 $C_k$ 对应加法中的个位。
* 倒数第二个元素 $C_{k-1}$ 对应十位。
* 依此类推，$C_1$ 对应最高位。

计算 $X_k$ 的数位和，就等价于在这个从右到左的加法过程中，将每一位产生的**当前位数字**累加，并将产生的**进位**传递给更高位。

2. 状态定义与转移

基于加法模型，我们可以利用动态规划来求解。由于加法是从低位向高位（即序列下标从大到小）进位的，但题目要求分别输出每个 $k$ 的答案，我们需要定义一个表示“前缀处理结果”的 DP 状态。

定义 $DP(i, c)$ 表示：**仅考虑序列的前缀 $C_1 \dots C_i$，当从它右侧（即第 $i+1$ 位）接收到的进位为 $c$ 时，这前 $i$ 个数字所能贡献的最小数位和。**

* **状态转移：**
在第 $i$ 位，我们从 $A_i$ 和 $B_i$ 中选择一个作为 $C_i$。加上传来的进位 $c$ 后，当前位的值为 $C_i + c$。
该操作对数位和的贡献是 $(C_i + c) \pmod{10}$，并向高位（第 $i-1$ 位）产生 $(C_i + c) / 10$ 的新进位。
因此，状态转移方程为：

$$
DP(i, c) = \min_{C \in \{A_i, B_i\}} \left( (C + c) \pmod{10} + DP\left(i-1, \lfloor \frac{C + c}{10} \rfloor\right) \right)
$$

* **边界条件：**
当 $i=0$ 时，所有的 $C$ 都已经处理完毕，此时剩下了一个最终的进位 $c$。这个进位会直接作为高位附加在数字的最前端，因此 $DP(0, c)$ 就是整数 $c$ 本身的数位和。
* **答案获取：**
对于任意的询问 $k$，由于它是个位，右侧没有更低位的进位输入，所以最终答案就是 $DP(k, 0)$。

3. 状态空间的剪枝

虽然理论上进位的上限可以达到 $10^8$ 级别，但在实际除以 $10$ 的收敛过程中，绝大多数进位值是永远无法到达的。如果我们将所有可能的 $c$ 均视为状态，时间和空间都会爆炸。

为了优化，我们需要将求解分为两步：

1. **逆向搜集有效状态：** 从 $N$ 到 $1$ 倒序推导，由初始进位 $0$ 开始，依次计算出每一位所有可能出现的进位值，并进行去重。这就构建出了一个极小且精确的有效状态图。
2. **正向计算 DP 值：** 从 $1$ 到 $N$ 正序计算 $DP(i, c)$，在已经预处理出的有效进位集合上进行状态转移，同时每次转移结束后，$DP(i, 0)$ 即为所求的第 $i$ 个询问的答案。
