# 背包DP

## 01背包问题

有若干物品，每个物品有一个体积和价值，你有一个指定容量的背包，求能够装的物品的最大价值。

$f[i][j]$表示只考虑前$i$个物品，用$j$单位容量能装物品的最大价值。

### 算法
- $f[0 \cdots n][0 \cdots m] \leftarrow 0$
- 对于 $i$ 从 $1$ 到 $n$：
  - 对于 $j$ 从 $v_i$ 到 $m$：
    - $f[i][j] \leftarrow \max(f[i-1][j], f[i-1][j-v_i] + w_i)$



## 空间优化

### 滚动数组
- $f[0 \cdots 1][0 \cdots m] \leftarrow 0$
- 对于 $i$ 从 $1$ 到 $n$：
  - 对于 $j$ 从 $v_i$ 到 $m$：
    - $f[i\&1][j] \leftarrow \max(f[1-(i\&1)][j], f[1-(i\&1)][j-v_i] + w_i)$


### 滑动数组
- $f[0 \cdots m] \leftarrow 0$
- 对于 $i$ 从 $1$ 到 $n$：
  - 对于 $j$ 从 $m$ 到 $v_i$ 递减：
    - $f[j] \leftarrow \max(f[j], f[j-v_i] + w_i)$

## 多重背包问题

有若干类物品，每类物品有一个体积和价值，每类物品有一定数量，你有一个指定容量的背包，求能够装的物品的最大价值

### 二进制分组

把一个可以使用k次的物品看成若干个体积和价值都为这个物品的2的整数次幂倍的01物品

显然根据二进制原理这个拆分数不超过log个，那么对这log个物品做01背包即可

### 单调队列

$$
f[i][j]=\max_{t \in [0,k]}(f[i-1][j-t*v]+t*w)
$$

把模$v$意义下相同的$j$放在一起做，那么问题就变成了求所有长度为$k$的区间的最大值，单调队列维护即可

## 多重背包拓展
有一个大小为 $n$ 的背包，$n$ 在 $k$ 进制下有 $m$ 位。

有 $m$ 种物品，编号从 $0$ 到 $m-1$，第 $i$ 种物品的大小为 $k^i$。每种物品有无限个。

计算合法的选物品方案数。合法的定义是选择的物品总大小不超过 $n$。两种方案不同当且仅当存在一种物品被选的个数不同。

对 $10^9 + 7$ 取模。

## 依赖背包问题

有若干个物品形成一棵树，每个物品有一个体积和价值，你有一个指定容量的背包，要求如果选了某个物品，则它的父亲也必须被选择，求能装的物品的最大价值。

首先我们把树的DFS序造出来。

转移时，如果选择了某个物品，则可以正常向后转移，如果未选择某个物品，则它的子树中不能选择任何物品，而dfs序上一棵子树是一段连续的区间，我们直接跳过这个区间转移到之后的状态即可。

## 树形背包复杂度

$f[i][j]$表示在$i$的子树中的最大收益，每次的转移就是合并两棵子树

假设节点$i$的每个孩子的子树大小为$s_1 \cdots s_n$，则转移复杂度为

$$
\begin{aligned}
\sum_{i=2}^{n}s_i \sum_{j=1}^{i-1}s_j &= \sum_{i=1}^{n} \left( s_i \times \sum_{j=1}^{n}s_j - s_i^2\right) \\
&\le \sum_{i=1}^{n}\left(s_i\sum_{j=1}^{n}s_i - s_i^2\right) \\
& = \sum_{i=1}^{n}\left(s_i \times sum -s_i^2\right) \\
& = sum^2-\sum_{i=1}^{n}s_i^2
\end{aligned}
$$


## 树形背包复杂度

如果每个物品的体积都为$1$，背包容量为$m$，则复杂度为$O(n \times m)$

证明：树，其实就是把$n$个孤立点按照某种顺序，每次合并两个连通块，如果两个连通块大小为$x,y$，则复杂度的贡献是$\min(x,m) \times \min(y,m)$

考虑每次合并的时候:

- 如果$x \ge m,y \ge m$，则最多发生n/m次，复杂度$O(n/m \times m^2)=O(nm)$
- 如果$x<m,y<m,x+y \ge m$，则最多发生n/m次，复杂度$O(n/m \times m^2)=O(nm)$
- 如果$x+y < m$，则考虑每一个连通块，在大小不超过m之前，总复杂度不超过$siz^2$，这样总复杂度是$O(nm)$

### 例题

有$n$个物品和一个容量为$m$的背包，每个物品有体积和价值

给一个数$k$

求，对于所有长度为$k$的区间的背包问题答案

即，对于任意$1 \le i \le n-k+1$，求仅考虑$[i,i+k-1]$这段区间里的物品，$01$背包问题的答案是多少

$n,m \le 5000$

<CollapsibleComponent title="解法">

固定长度的区间问题，一个常见套路就是按照$k$分段

这样，每一个询问会恰好跨过一段的后缀和下一段的前缀

预处理所有段前缀和后缀的背包即可

</CollapsibleComponent>

##### T652960 背包问题
	
有$n$种物品，每种物品的体积都是$1$。

现在你有一个容量为$m$的背包，需要装载一些物品。每种物品最多选三个，并且按照如下规则计算价值：


- 每种物品第一次选择时，价值是$a_i$
- 每种物品第二次选择时，价值是$b_i$
- 每种物品第三次选择时，价值是$a_i$


现在，你需要对于$m = 1,2,3 \ldots, 3 \times n$均求出，能装载物品的最大价值和是多少。

$n \le 10^5, 1 \le a_i,b_i \le 10^9$

<CollapsibleComponent title="解法"> 
可以把每个物品当成两个独立的物品，一个是体积为$1$，价值为$a_i$的物品，一个是体积为$2$，价值为$a_i+b_i$的物品

这样，把所有体积为$1$和体积为$2$的物品分开从大到小排序，一定是选一段前缀
</CollapsibleComponent>

##### P3188 HNOI2007 梦幻岛宝珠
普通的$01$背包问题，$n$个物品，每个物品有体积$v$和价值$w$，背包容量为$m$

现在所有物品有一个特点：$v_i = a \times 2^b$，其中$0 \le a \le 10, 0 \le b \le 30$

问背包问题的答案

$n \le 100, v_i,m < 2^{30}$

<CollapsibleComponent title="解法">

因为$v_i = a \times 2^b$，我们考虑把物品按照$b$进行分组

令$f[i][j]$为考虑了所有前$i$组的物品，当前选的物品体积和为$j \times 2^i$，的最大价值

相当于一边跑背包一边跑数位DP

每一组内部先做一个背包，然后再把第$i$组的背包数组和$f[i-1]$合并
</CollapsibleComponent>

##### 例题
有 $n$ 间屋子，由 $n-1$ 条双向道路连接成了一个树形结构。其中，第 $i$ 间屋子里居住了 $1$ 个种族为 $c_i$ 的人。

现在你要召集一个连通块内的人。设 $a_j$ 表示被召集的种族为 $j$ 的人个数，若存在 $2a_k>\sum_{j=1}^{n} a_j$，则种族为 $k$ 的人会造反。

你想知道有多少个连通块会使某种人造反，答案对 $998244353$ 取模。

$1 \le n \le 3000, 1 \le c_i \le n$

<CollapsibleComponent title="解法">
枚举哪一个族群的人$x$是连通块人数最多的。假设整棵树有$S[x]$个人种族为$x$

用$DP[i][j]$表示DP完了子树$i$，从子树中选了一个包含$i$的连通块，连通块内，$x$的人数减去其它人数为$j$的方案数

$j$的取值范围只需要$[-S[x],S[x]]$就够了

根据树形背包的复杂度，复杂度为$O(nS[x])$
</CollapsibleComponent>
