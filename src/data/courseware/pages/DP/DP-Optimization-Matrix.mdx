##### T466368 数数（count）

##### CF506E Mr. Kitayuta's Gift

给定一个字符串$s$，求长度为$n$且包含$s$作为子序列的回文串个数  

要求的时间复杂度: $O(|s|^3 \log n)$

<CollapsibleComponent title="做法">

先考虑最终串长为偶数的情况

考虑判定一个串是否合法，这要求它是回文串且包含$s$作为子序列。这可以通过从两边向中间贪心进行判断。按这个方法dp，设$f(i,j,k)$表示考虑最终串前后$i$个字符，还剩$s_{j..k}$没有匹配的方法数和$g(i)$表示最终串前后$i$个字符且已经包含$s$作为子序列的方案数。

注意到，这相当于求一张没有自环以外的环的有向图中起点到汇点的长度为$\frac{n+|s|}{2}$的路径方案数。其中，结点分为有$24$个自环的点($f(i,j,k)$其中$s_j \neq s_k$)，有$25$个自环的点($f(i,j,k)$其中$s_j = s_k$)和有$26$个自环的汇点($g(i)$)三类。

考虑对每种去除自环后所得的不同的简单路径计数，注意到这样的路径的方案数仅和经过的前两类点的个数有关，考虑按这个合并等价的路径。每次离开第二类点相当于让剩余部分的长度减少$2$（一般情况）或$1$（剩余部分长度为$1$的情况），离开第一类点减少$1$，因此离开第一类点的次数可以确定离开第二类点的次数，仅需考虑离开第一类点的次数即可。考虑dp，设$h(u,i)$表示从起点到$u$的路径中含恰$i$个第一类点的方案数，这容易$O(|s|^3)$求出。

对所有$O(|s|)$种本质不同的路径分别建矩阵求幂，时间复杂度$O(|s| * |s|^3 \log n)$。接下来有两个优化的方法

1. 猜测每种路径的答案是项数$O(|s|)$的常系数齐次线性递推（好像确实如此），时间复杂度$O(|s|^3 + |s| * (|s|^2 + |s|\log |s|\log n)) = |s|^3 + |s|^2 \log |s|\log n$
2. 考虑建出一个大小$O(|s|)$的图一次性求出答案进行优化，这可以通过建出$O(|s|)$个第一类点连成链，然后建出$O(|s|)$个第二类点连成链并连接一个第三类点，然后让每个第一类点连向合适的第二类点（边权为这类路径的数量）来完成，矩阵快速幂，时间复杂度$O(|s|^3 \log n)$
