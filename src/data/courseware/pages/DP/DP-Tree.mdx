##### 洛谷NOIP2025模拟赛
小Z最近新学习了深度优先搜索，他也同时了解到了 dfs 序列的定义，于是他构思了这样一道有趣的题目。

给出一棵有 n 个节点的以 1 为根的有根树 T，每个点有点权 $a_i$，对每个节点以某种顺序遍历其所有儿子，最终得到一个 dfs 序列，请你最大化 dfs 序列中偶数下标位置的点权之和。换言之，你需要最大化：

$$
\sum_{1 \leq i \leq n} \lfloor 2|i| \cdot a[\text{dfsorder}_i]
$$

请你输出这个最大值。

对所有数据，保证 $2 \leq n \leq 2 \times 10^5, 1 \leq T \leq 1000, \sum n \leq 5 \times 10^5, 1 \leq a_i \leq 10^9, 1 \leq f_i \leq i$。

<CollapsibleComponent title="20pts:满二叉树">    

此时可以发现每棵子树的大小都是奇数，因此两棵子树的贡献分别是所有的偶数位置和所有的奇数位置。

因此设 $\text{dp}[u][0/1]$ 表示以 $u$ 为根的子树，从 $u$ 开始 $\text{dfs}$，偶数/奇数位置点权和的最大值。

转移的时候，一边取 $\text{dp}[v][0]$ 一边取 $\text{dp}[v][1]$ 即可。

时间复杂度 $O(\sum n)$。

剩下的一些部分感觉没有什么好做法，暂且不表。

其实满二叉树的做法提示性已经很强了。

</CollapsibleComponent>

<CollapsibleComponent title="满分做法"> 
沿用满二叉树的做法，设 $\text{dp}[u][0/1]$ 表示以 $u$ 为根的子树，从 $u$ 开始 $\text{dfs}$，偶数/奇数位置点权和的最大值。

然后对一个节点 $u$，他的若干棵子树：
- 如果所有子树大小均为偶数，那么每个儿子在 $\text{dfs}$ 序中位置的奇偶性都是一样的，可以直接计算
- 如果有至少一棵子树大小是奇数，那么：
    1. 所有大小为偶数的子树可以自由决定开始位置的奇偶性，因为可以选择放在最前面遍历或者紧跟着第一个奇子树遍历
    2. 而所有大小为奇数的子树，开始位置奇偶性是 0/1 交替的，如果有 $c$ 棵子树大小为奇数，那么开始位置为偶数的子树有 $\lfloor c/2 \rfloor$ 个，开始位置为奇数的子树有 $\lceil c/2 \rceil$。因此一开始先默认全部取成开始位置为偶数，然后贪心选最大的几个 $\text{dp}[v][1]-\text{dp}[v][0]$ 即可

最终时间复杂度为 $O(\sum n \log n)$。

</CollapsibleComponent>

##### P1272 重建道路

给你一棵$n$个点的树，以及一个参数$p$，求通过求通过删除最少的边，使得存在某个连通块大小为$p$。

$1 \le p \le n \le 150$

<CollapsibleComponent title="做法">
令$f[i][j]$表示$i$子树中剩余包括$i$结点在内共$j$点所需删去最少边数

$f[fa][p]=min(f[fa][p-j]+f[son][j],f[fa][p])$

除设定的根节点外，其余结点更新$ans$方法为

$Ans=min(f[now][p]+1,ans)$,加一表示删去该子树与树上其他部位联系所需的经过的路径

对于设定的根节点$Ans=min(f[root][p],ans)$
</CollapsibleComponent>

##### Tree（poj1848）

题意：对于一棵$（3 \le n  \le 100)$个结点的树，添加最少的边使得树中每一个结点正好落在一个（仅一个）环中

<CollapsibleComponent title="做法">

- 先分析各种情况：构成环至少需三个点
- 定义$f[i][0 \sim 2]$：$f[i][0]$记录包括i在内所有i子树上的构成环所需添加的边数
- $f[i][1]$记录不包括i在内所有i子树上的构成环所需添加的边数
- $f[i][2]$不包括i及与其相连的一条链在内所有i子树上的构成环所需添加的边数
- 可以证明，子树内i若与两条链相连却不处理的情况非法

###### Case1：$i$的各个儿子节点都在环中，$i$无法构成环

$f[fa][1]=sum(f[son][0])$

![](/DP/G4.png)

###### Case2：除$p$点或$p$链不在环中$i$的各个儿子节点都在环中，$i$与$p$为链

$f[fa][2]=sum(f[son][0])+(max(f[p][1],f[p][2])- f[p][0])$

![](/DP/G5.png)
    
###### Case3：除$p$点或$p$链、$q$点或$q$链不在环中$i$的各个儿子节点都在环中，$i$与$p$,$q$为环

$F[fa][0]=sum(f[son][0])+(max(f[p][1],f[p][2])-f[p][0])+(max(f[q][1],f[q][2])-f[q][0])+1$

![](/DP/G6.png)

###### Case4：除$p$链不在环中$i$的各个儿子节点都在环中，$i$与$p$链为环

$F[fa][0]=sum(f[son][0])+(f[p][2]-f[p][0])+1$

![](/DP/G7.png)

###### 边界情况
    
$i$为叶子节点时，$f[i][0],f[i][2]$非法

$f[son][0]$非法超过两次时，无法满足答案，退出

$f[son][0]$非法时必须选其$f[son][1]$或$f[son][2]$（无论是否合算）

</CollapsibleComponent>

##### P4408 [NOI2003] 逃学的小孩

在一棵树中，每条边都有一个长度值，现要求在树中选择$3$个点$X,Y,Z$，满足$X$到$Y$的距离不大于$X$到$Z$的距离，且$X$到$Y$的距离与$Y$到$Z$的距离之和最大，求这个最大值。

<CollapsibleComponent title="做法"> 
咋看题目，类似求最长路径问题

思考：如果$x,y,z$在同一条链上，则：

一：$x$与$z$在$y$的同一侧时$s=xy+zy>max(xy，zy，xz)$

二：$x$与$z$在$y$的异侧时$s=xy+zy=xz=max(xy，zy，xz)$

故$x$必在$y,z$之间。又：如果$x$从一条分链上走到$y,z$路径上一点$A$则更优
    
朴素算法$s=XA+YA+YZ=XA+2YA+ZA$
    
又：$YA=XY-XA<XZ-XA=ZA$

在$A$确定,$X,Y$允许互换的情况下$XA<YA$比$XA>YA$更优

为此枚举分叉点$o(n)$似乎不错；但由于每次以分叉点为根计算复杂度为$o(n)$，总的时间复杂度为$o(n^2)$
    
两遍dfs，第一遍后根遍历以任一点为根节点，记录其不再同一子树路径的最大值与次大值，并记录其由谁转移

第二遍先根遍历，转移最值同时处理答案：

Case 父节点的最大值不由该子树提供：$ans=fmax[fa]+fmax[son]+fmid[son]+w$

Case 父节点的最大值由该子树提供：$ans=fmid[fa]+fmax[son]+fmid[son]+w$

之后记得用父节点最值更新子节点最值 $f[son]=f[fa]+w,g[son]=fa$

</CollapsibleComponent>

##### Apple Tree（poj2486）
    
给定一棵$n(n \le 100)$个节点的树，每个节点上有一个值

从root出发，走$k(k \le 200$)步，每步必须往其相邻的点走，每到一个节点将此节点上的值累加起来（不能重复累加）

问最多可以得到多大的累加值

<CollapsibleComponent title="做法">

易证：对于每棵子树我们只需进入一次；对于每条路径，我们最多往返各一次

定义$f[i][j][0,1]$

$f[i][j][0]$表示从$i$点向其子树走$j$步并最终返回i点可得苹果数，$f[i][j][1]$表示从$i$点向其子树走$j$步不需返回$i$点可得苹果数

对于叶子节点：$f[i][0][0]=f[i][0][1]=apple[i]$

对于其他节点：$F[fa][j][0]=\{$选$k$个子树往返即$f[sonx][i][0]$,在各子树共走$j-2*k$步$\}$

$F[fa][j][1]=\{$选$k-1$个子树往返即$f[sonx][i][0]$,另一子树不需返回,在各子树共走$j-2*k+1$步$\}$
    
</CollapsibleComponent>

##### P3354 River
    
在Byteland国，有$n$个伐木的村庄，这些村庄都座落在河边

所有的河水都汇聚并流进了一条大河，最后这条大河流进了大海

这条大河的入海口处有一个村庄名叫Bytetown

在Bytetown，有一个巨大的伐木场，它处理着全国砍下的所有木料。 木料被砍下后，顺着河流而被运到Bytetown的伐木场。

国王决定，为了减少运输木料的费用，再额外地建造$k$个伐木场。这$k$个伐木场将被建在其他村庄里。这些伐木场建造后，木料就不用都被送到Bytetown了，它们可以在运输过程中第一个碰到的新伐木场被处理。

显然，如果伐木场座落的那个村子就不用再付运送木料的费用了。它们可以直接被本村的伐木场处理。

注意：所有的河流都不会分叉，也就是说，每一个村子，顺流而下都只有一条路——到bytetown

国王的大臣计算出了每个村子每年要产多少木料，你的任务是决定在哪些村子建设伐木场能获得最小的运费

其中运费的计算方法为：每一块木料每千米1分钱

计算最小的运费

$n \le 100, k \le 50$

每个村庄每年生产的木料数$\le 10000$

每个村庄到下游最近的村庄距离$\le 10000$
    
<CollapsibleComponent title="做法">

- 朴素算法：列出一个自然方程
- 如果 $f[son][i][p]$ 存在：$f[fa][k][w]=f[son][i][p]+f[fa][k-i][w-p]+p*w$
- 明显超时超空间
- 思考：目前村庄、建场数、未处理木块、费用，似乎一个也不能少

- 未来型动态规划
- 在状态里设出当前节点祖先中最近的伐木场
- 每 DP 一个节点即可计算当前节点木料的运输成本
</CollapsibleComponent>
