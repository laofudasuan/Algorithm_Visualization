# 平衡树

## 二叉搜索树
	
一棵二叉树，每个点有个值Value

对于任何一个点，左子树的所有点Value都比它小

对于任何一个点，右子树的所有点Value都比它大

相当于一个按照权值分治的结构

##### P12861 [NERC 2020 Online] Lookup Performance

<CollapsibleComponent title="做法">

问对于一颗二叉搜索树来说，如果我们要找一个值域区间的值有多少个，他会向下递归查找几次，

设，第$ i $个节点所代表的最大最小值为$ l_i, r_i $，此时我们要查询$ L, R $之间的值有多少个，

- 如果$ L \leq l_i \leq r_i \leq R $，那么我们不会递归下去查询，意味着当访问完这个点后不会对答案产生新的贡献。
- 如果$ r_i < L $ or $ l_i > R $，同样的，访问完这个点后我们不会递归查询下去，意味着当访问完这个点后不会对答案产生新的贡献。

综上我们只要找到，有多少个$ l_i, r_i $，满足①$ l_i < L, r_i \geq L $，②$ r_i > R, l_i \leq L $任意一个的点有多少个，然后对数量乘以二再加上一即可。

可以看作有多少条线段与$ L, R $有交，并且，这些线段不能包含在$ L, R $里。

这样就变成了一个二维数点问题
</CollapsibleComponent>
