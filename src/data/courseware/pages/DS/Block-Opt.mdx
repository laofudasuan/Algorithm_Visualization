# 操作分块


##### P10150 [Ynoi1999] TS-54

给定整数序列 $a_1,\dots,a_n$ ，满足不存在 $1\le i<j<k<l\le n$ 使得 $a_i=a_j=a_k=a_l$ ；

共 $m$ 次操作，每次操作给出 $x$ ，首先进行修改，将 $a_1,a_2,\dots,a_x$ 翻转为 $a_x,\dots,a_2,a_1$ ，然后查询有多少个不同的 $k$ ，满足存在 $1\le i\le x<j\le n$ 使得 $a_i=a_j=k$ 。

对于 $100\%$ 的数据，满足所有数值为整数，$1\le a_i\le n$，$1\le x\le n$，$n,m\le 5\times 10^5$。

<CollapsibleComponent title="小技巧">

注意到每个数最多出现三次，因此想让一个数在左右两边同时出现，只有三种情况：

- 左边出现一次，右边出现一次
- 左边出现一次，右边出现两次
- 左边出现两次，右边出现一次

因此可以这样转换：

- 对于出现两次的数，假设出现位置为$x,y$，定义二元组$(x,y)$的权值为$1$
- 对于出现三次的数，假设出现位置为$x,y,z$，定义二元组$(x,y),(x,z),(y,z)$的权值分别为$0.5$

这样，对于每次询问，跨过中点的二元组权值和就是答案

</CollapsibleComponent>

<CollapsibleComponent title="分块"> 

对操作分块，每$B$次操作一起处理

$B$次操作会把整个序列分为$B$段，段内始终是一个整体（可能翻转）

先预处理出$f[i][j]$表示端点分别在第$i$段和第$j$段的二元组数量，时间$O(B^2+n)$

接下来对操作分治，每次把操作分为两半，变为两个子问题，子问题的分段就变成了$B/2$，对子问题也建立$f$数组，然后把当前层的$f$累加到子问题对应的段中去

递归复杂度为$T(B)=T(B/2)+O(B^2)$，解得$T(B)=O(B^2)$

取$B=\sqrt{n}$，得总复杂度$O((n+q)\sqrt{n})$

</CollapsibleComponent>
