# 倍增值域分块（分组）
## 一、算法概述
带 $\log$ 时间复杂度的均摊类问题，可分为两类：
1. 元素被操作一次后数值**直接减半**
2. 元素单次操作降幅很小，需多次操作后才会减半

- 第一类难点：快速定位每次需要修改的元素
- 第二类主流解法：**倍增值域分块**
- 典型适用场景：形如**对所有 $\ge x$ 的元素执行 $-x$** 的操作问题
- 该套路灵活性较强，需要结合具体题目分析

## 二、经典例题 & 题解
### 1. CF702F T-Shirts
#### 题意
1. 共 $n$ 种T恤，每种有价格 $c_i$、品质 $q_i$；
2. $m$ 个人，每人持有固定金额，独立选购；
3. 规则：每次优先买**品质最高**的T恤，同品质选**价格最低**的；每件T恤每人最多买一件；
4. 求每个人最终购买T恤的数量。

#### 解题思路
1. 预处理：将所有T恤按品质 $q_i$ **从大到小**排序；
2. 状态定义：$a[i]$ 表示第 $i$ 个人剩余金额，$b[i]$ 表示购买件数，初始 $b[i]=0$；
3. 人群排序：将所有人按剩余金额 $a[i]$ 从小到大排序；
4. 遍历每件T恤：设当前T恤价格为 $x=c_j$，对所有 $a[i] \ge x$ 的人执行 $a[i]-=x、b[i]++$；
5. 数据结构优化（平衡树+标记）：
   - 平衡树按 $a[i]$ 有序维护所有人；
   - 划分值域：$[0,x)$、$[x,2x]$、$(2x,+\infty)$
     - $[0,x)$：元素无操作；
     - $[x,2x]$：暴力修改，该区间元素修改后数值至少减半，每个元素最多暴力 $\boldsymbol{O(\log v)}$ 次；
     - $(2x,+\infty)$：整体打懒标记，统一扣钱、计数；
   - 标记不会造成值域重叠，保证正确性。

#### 复杂度
$O((n+m)\log n \log v)$（$v$ 为数值上界）

### 2. Luogu7447 [Ynoi2007] rgxsxrs
#### 题意
序列长度 $n$，操作次数 $m$（$n,m \le 5\times10^5, 1\le a_i,x\le10^9$），共两种操作：
1. 区间 $[l,r]$：将所有**大于 $x$** 的元素减去 $x$；
2. 区间 $[l,r]$：查询区间和、最小值、最大值。

#### 解题思路
1. **倍增值域分块规则**：按 $[0,1)、[1,2)、[2,4)、[4,8)\dots[2^k,2^{k+1})$ 划分值域块，总块数 $\boldsymbol{O(\log v)}$；
2. 对每个值域块，单独维护一棵线段树；
3. 针对值域块 $[2^k,2^{k+1})$ 分三类处理修改操作：
   - 若 $2^k > x$：块内所有元素都要减 $x$，区间批量修改；
   - 若 $2^{k+1} \le x$：块内无元素需要修改，直接跳过；
   - 若 $2^k \le x < 2^{k+1}$：仅块内部分大数需要减 $x$，元素修改后数值减半，单个元素该操作最多 $\boldsymbol{O(\log v)}$ 次；
4. 元素跨块处理：若元素减 $x$ 后脱离当前值域块，将其拆分转移到对应下层值域块；
5. 优化写法：序列底层先分块，再建线段树，减少节点数量、优化缓存，降低常数。

#### 复杂度
$O((n+m)\log n \log v)$

### 3. Luogu9069 [Ynoi Easy Round 2022] 堕天作战
#### 题意
序列长度 $n$，操作次数 $m$（$n,m \le 5\times10^5, 0\le a_i,x\le10^9$），两种操作：
1. 给定 $x$：对所有 $a_i \neq x$ 的元素执行 $a_i \mathrel{:=} a_i - x$；
2. 区间 $[l,r]$：查询区间内所有 $a_i \neq 0$ 的元素和。

#### 解题思路
1. 拆分修改对象：区分 $a_i > x$、$a_i < x$ 两类元素，避开 $a_i=x$；
2. 处理 $a_i < x$：
   - 负数元素：统一线段树区间减 $x$；
   - 非负数元素：减 $x$ 后必然变为负数，暴力修改，每个元素仅该过程仅发生一次；
3. 处理 $a_i > x$：沿用**倍增值域分块** $[2^k,2^{k+1})$ 策略 + 多棵值域线段树，逻辑同上一题；
4. 常数优化：底层序列分块再建线段树，优于纯平衡树写法。

#### 复杂度
时间：$O((n+m)\log n \log v)$
空间：$O(n)$

### 4. CF1515I Phoenix and Diamonds
#### 题意
1. $n$ 种钻石，每种初始库存 $a_i$，重量 $w_i$、价值固定排序优先级；
2. $m$ 次操作：进货、出货、查询；
3. 查询：给定背包容量 $c$，按**价值从大到小、重量从小到大**取钻石，求能取到的总价值（仅模拟，不实际修改库存）。

#### 解题思路
1. 预处理：钻石按优先级固定排序，进货/出货转化为**单点修改**；
2. 值域分组：按二进制最高位划分 $[2^k,2^{k+1})$，共 $O(\log c)$ 组；
3. 性质：
   - 减去一个 $\ge 2^k$ 的元素，$c$ 的二进制最高位必然下降；
   - 反复减去 $<2^k$ 的元素，直到无法再取，$c$ 最高位同样下降；
4. 数据结构：对每个值域分组维护一棵线段树，分别维护前缀和、区间最小值；
5. 流程：逐层下降二进制最高位，每层二分查找可行位置，最多遍历 $\boldsymbol{O(\log c)}$ 层。

#### 复杂度
$O((n+m\log n)\log c)$

### 5. LOJ#3527 「IOI2021」地牢游戏
#### 题意
$n$ 个敌人、$n+1$ 个地牢，英雄初始在地牢 $a$、能力值 $z$，规则：
1. 英雄能力 $\ge$ 敌人能力 $s[i]$：获胜，能力增加 $s[i]$，前往编号更大的地牢；
2. 英雄能力 $<$ 敌人能力 $s[i]$：战败，能力增加 $p[i]$，随机跳转地牢；
3. 进入地牢 $n$ 游戏结束；$q$ 次模拟查询最终能力值。

#### 解题思路
1. 核心：对英雄能力值 $z$ 做**倍增值域分块** $[2^k,2^{k+1})$；
2. 性质：$z$ 处于 $[2^k,2^{k+1})$ 时，对战该值域内敌人后，$z$ 必然进入下一个值域块；
3. 算法结合：**值域分块 + 图上倍增**
   - 按值域层分层处理，每层用倍增加速状态转移；
   - 维护：转移后的地牢位置、能力值增量、击败当前值域敌人的最小初始能力；
4. 拓展：可自定义底数 $B$（不固定为2）做 $[B^k,B^{k+1})$ 分块，实现复杂度平衡。

#### 复杂度
$O((n+q)\log^2 v)$

### 6. Luogu4587 [FJOI2016]神秘数
#### 题意
定义**神秘数**：集合中无法用子集和表示的**最小正整数**；
给定序列，$m$ 次询问区间 $[l,r]$ 的神秘数（$n,m\le10^5,a_i\le10^9$）。

#### 前置结论（子集和 mex）
设当前能表示 $[0,x]$ 的所有整数，加入新元素 $y$：
- 若 $y \le x+1$：新可表示区间拓展为 $[0,x+y]$；
- 若 $y > x+1$：$x+1$ 即为神秘数。

#### 解题思路
1. 迭代拓展：每次求区间内值域 $[a+1,b]$ 的元素和，不断扩大可表示区间；
2. 值域性质：每两轮拓展，可表示值域至少**翻倍**，迭代次数 $O(\log v)$；
3. 数据结构：**可持久化值域线段树**，快速查询区间内指定值域的元素和。

#### 复杂度
$O(n\log v + m\log^2 v)$

### 7. 2019ICPC徐州 H - Yuuki and a problem
#### 题意
序列支持**单点修改**、**查询区间子集和的 mex**（$n,m\le10^5,a_i\le10^9$）。

#### 解题思路
1. 沿用子集和 mex 核心逻辑，结合**倍增值域分块** $[2^k,2^{k+1})$；
2. 值域块性质：若可表示前缀覆盖某一个值域块内元素，则必然覆盖整块；
3. 数据结构：对每个值域块单独建线段树，维护**区间最小值、区间和**；
4. 判断规则：通过块内 min、sum 快速判定是否停止拓展、继续遍历下一块。

#### 复杂度
$O(n\log n + m\log n \log v)$

## 三、倍增值域分块 核心总结
### 1. 适用场景
- 操作形式：对**大于/大于等于 $x$** 的元素统一执行减法/修改；
- 元素特性：单次修改降幅小，多次修改后数值会减半；
- 数据范围：值域极大（$10^9$ 级别），无法普通值域分块，迭代次数受 $\log v$ 限制。

### 2. 标准分块方式
默认按**2的幂**划分值域：
$$[2^0,2^1),\ [2^1,2^2),\ [2^2,2^3),\dots,[2^k,2^{k+1})$$
总分块数量：$\boldsymbol{O(\log v)}$（$v$ 为元素最大值）。

### 3. 通用处理流程
1. 按倍增值域划分块，每个块搭配线段树/平衡树维护信息；
2. 遍历所有值域块，分三类判定修改范围：全改、全不改、部分修改；
3. 部分修改时，元素数值减半，单个元素最多被暴力修改 $O(\log v)$ 次；
4. 元素跨值域块时，拆分并转移至对应下层块。

### 4. 复杂度平衡技巧
不固定以 $2$ 为底数，改用自定义底数 $B$，按 $[B^k,B^{k+1})$ 分块：
- 调大 $B$：减少分块数量，预处理更快、单次询问更慢；
- 调小 $B$：增加分块数量，预处理更慢、单次询问更快；
可根据题目 $n、m$ 数据规模灵活平衡。

### 5. 常见搭配数据结构
1. 多棵值域线段树：主流写法，逻辑清晰；
2. 序列分块 + 线段树：优化缓存、降低常数；
3. 平衡树：空间线性，但常数极大，一般不优先使用；
4. 可持久化线段树：适配区间查询类子集和/mex 问题；
5. 倍增：结合图论、模拟类题目，加速状态转移。

### 6. 通用时间复杂度
绝大多数经典题目最终复杂度为：
$$O((n+m)\log n \log v)$$
$n$：序列长度/元素总数，$m$：操作/询问数，$v$：数值上界。
