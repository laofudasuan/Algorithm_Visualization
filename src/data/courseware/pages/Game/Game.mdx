# 博弈论

计算问题归类：

- 模拟
- 计数
- 优化
  - 单人优化
  - 多人优化-博弈论

多人博弈的最优解$\to$二人博弈

- 完全信息，例如：象棋、围棋
- 不完全信息，例如：军旗

- 公平博弈：对于当前任何一个状态，无论是轮到甲行动，还是乙行动，它们的操作空间是一样的
- 不公平博弈：甲和乙的操作空间不一样
- 对于公平博弈，胜负只和谁先手谁后手有关；对于非公平博弈，还需要考虑当前轮到谁走了

##### 博弈论的最优解

什么叫最优解？

假设博弈的双方都绝顶聪明，都会选择最优的策略

必败状态：如果无论怎么操作，都会转移到对手必胜的状态，则该状态必败

必胜状态：如果存在一种操作，会转移到对手必败的状态，则该该状态必胜

## 博弈论问题的通用解法

- 博弈搜索
- SG函数


<BoxWithTag tag="两种方法的对比">
直接搜索的优点：每个状态的答案很简单，要么是必胜，要么是必败。方便剪枝：只要搜到一个必败的后继，则就不用继续搜了，直接返回必胜

SG函数的优点：在遇到多个问题拼接在一起时，计算的效率比较高。局限性：只能针对公平博弈问题
</BoxWithTag>

##### P16541 [EGOI 2026] 饼干 / Biscuits

Aurora 和 Bianca 特别喜欢意大利杏仁饼干，今天，她们的爷爷烤了一大堆饼干（形成一个栈）。为了分这些饼干，她们发明了以下游戏。只要栈里还有饼干，她们就重复以下步骤：

+ Aurora 选一个整数 $X \geq 0$。
+ 接下来，Bianca 选一个整数 $Y \geq 0$，满足：
  - 剩下的饼干至少有 $Y$ 个，并且
  - $Y \neq X$。
+ 然后 Aurora 吃掉最顶上的 $Y$ 个饼干（如果 $Y=0$ 就不吃）。
+ 最后，如果还有剩下的饼干，Bianca 会吃掉最顶上的那一块。

当然，两个女生都想吃得越多越好。栈里的每块饼干都有一个重量 $1 \leq W_i \leq 50$。当所有饼干被吃完后，每个人的**幸福度**等于她在游戏中吃掉的所有饼干的重量总和。两个女生都知道如何最优地玩这个游戏——每个人总是会做出能让自己的最终幸福度最大化的选择。

因为这个游戏太好玩了，她们现在每天都要玩！在接下来的 $Q$ 天里，她们的爷爷每天都会烤一堆同样数量的饼干。为了让游戏更有趣，爷爷每天会改变其中一块饼干的重量，而其他饼干的重量保持不变。

对于初始的饼干堆，以及在每天进行改变之后，你需要计算出每天游戏结束时 **Bianca 的幸福度**。

- $2 \leq N \leq 100\ 000$。
- $0 \leq Q \leq 100\ 000$。
- $1 \leq W_i \leq 50$（是的，意大利杏仁饼干很轻！）。
- $0 \leq P_i \leq N-1$ 且 $1 \leq Z_i \leq 50$。

<CollapsibleComponent title="朴素做法"> 

考虑做一个转化：令$D=$Aurora的幸福度$-$Bianca的幸福度，这样Aurora希望最大化$D$，Bianca希望最小化$D$

朴素做法：用$f[i]$表示后缀$i \sim n$的答案

根据Bianca选择的$Y$，有转移$f[i] = f[i+T+1]+\sum_{j=i}^{i+T-1}w_j - w_{i+T}$

因为Aurora会禁用一个$Y$，所以最终Bianca会选择所有转移的次小值
</CollapsibleComponent>

<CollapsibleComponent title="优化"> 
考虑换一个DP形式，用$f[i][j]$表示后缀$i \sim n$，Biance如果选择$Y=j$的答案

- 初始$f[n] = [-w_n,w_n,w_n,w_n,w_n,w_n,\ldots]$
- 考虑$f[n-1]$
  - 对于$f[n-1][0]$，Biance会吃掉$w_{n-1}$，接下来Aurora会禁掉$f[n]$的最小值$-w_n$，所以$f[n-1][0] = w_n-w_{n-1}$
  - 对于$f[n-1][1]$，Aurora会吃掉$w_{n-1}$，Biance会吃掉$w_{n}$，所以$f[n-1][1]=w_{n-1}-w_{n}$
  - $f[n-1] = [w_n-w_{n-1},w_{n-1}-w_{n},w_{n-1}+w_n,w_{n-1}+w_n,w_{n-1}+w_n,w_{n-1}+w_n,w_{n-1}+w_n,\ldots]$
- 发现$n$和$n-1$都满足一个性质：$f[i]$的最小值和次小值是相反数
- 接下来考虑归纳法证明对$f[1 \sim n]$都成立：
- 假设$f[i+1]$成立，$f[i+1]$的最小值为$-D$，次小值为$D$，其他值都$\ge D$
- 对于$f[i][0]$，Biance会吃掉$w_{i}$，接下来Aurara会禁掉$-D$，从而$f[i][0]=D-w_i$
- 对于$f[i][j](j \ge 1)$，Aurora会吃掉$w_{i}$，那相当于$w_i+f[i+1][j-1]$，因此$\min(f[i][1 \ldots]) = w_i+\min(f[i+1]) = w_i-D$，由此最小值和次小值仍然是相反数

</CollapsibleComponent>

##### arc222_c 2 Directions vs 4 Directions

有一个 $N \times N$ 的网格，其中 $N$ 是至少为 2 的整数。对于 $1 \leq i, j \leq N$，从上数第 $i$ 行、从左数第 $j$ 列的格子记为 $(i, j)$。

初始时，所有格子均为黑色。对于每个格子 $(i, j)$，给定将其颜色从黑色变为白色的代价 $A_{i,j}$。

Alice 和 Bob 使用该网格和一个棋子进行游戏。游戏包括以下三个步骤。

1. 裁判指定棋子的初始放置位置。
2. Alice 执行以下操作零次或多次：
  - 选择一个黑色格子 $(i, j)$，支付代价 $A_{i,j}$，并将该格子变为白色。
3. 将棋子放置在步骤 1 中指定的初始位置。然后，从 Alice 开始，Alice 和 Bob 轮流移动棋子。
  - 在 Alice 的回合，Alice 将棋子向左或向右移动至相邻格子。
  - 在 Bob 的回合，Bob 将棋子向上、下、左或右任意方向移动至相邻格子。
  - 不允许将棋子移出网格。

步骤 3 在 Alice 和 Bob 各移动了 $10^{10}$ 次后立即结束。

步骤 3 结束时，如果棋子位于白色格子上，则 Alice 获胜；如果位于黑色格子上，则 Bob 获胜。在步骤 3 中，Alice 和 Bob 均采取最优策略以争取获胜。

对于每个格子 $(h, w)$，若步骤 1 中指定 $(h, w)$ 为初始位置，求 Alice 在步骤 2 中为保证获胜所需支付的最小总代价。

共有 $T$ 组测试数据，请对每组数据求解。

<CollapsibleComponent title="解法"> 
这是一道将**博弈论**与**最短路/动态规划**巧妙结合的极佳问题。

面对极其庞大的操作步数，我们需要跳出模拟的思维，去寻找一种能让 Alice 绝对掌控局面的**构造性必胜策略**。以下是这道题的完整逻辑推导。

题目中一个极其反常的条件是：双方各走 $10^{10}$ 步。

在一个 $N \times N$ 的有限网格里走天文数字的步数，游戏必然陷入无限循环。我们来梳理一下回合的奇偶性：

* 总步数是 $2 \times 10^{10}$ 步（偶数）。
* Alice 先手，Bob 后手。
* 这意味着**全局的最后一步必然由 Bob 走出**。

Alice 若想获胜，必须保证游戏结束时棋子停在白格上。由于 Bob 可以在全图上下左右任意移动，Alice 想要赢，就必须构筑一种**绝对防御**：无论 Bob 怎么走，他走完之后的落脚点**必定是白格**。

Alice 有一个致命的限制，也是她最大的武器：**她只能左右移动**。这意味她能在水平方向上完全纠正 Bob 的横向移动。为了防御 Bob 的纵向移动，Alice 需要在地图上修建一条贯穿上下的“主干道”。

**策略核心：**

1. **规划主干道**：Alice 从第 1 行到第 $N$ 行选定一条路径作为“主干道”。
2. **修建护城河**：Alice 支付代价，将主干道上所有格子的**左侧和右侧的格子全部染成白色**。
3. **主干道的连通规则**：相邻两行的主干道格子，其列坐标的差的绝对值必须严格等于 1。即如果第 $r$ 行的主干道在第 $c$ 列，第 $r-1$ 行和第 $r+1$ 行的主干道必须在 $c-1$ 或 $c+1$ 列。

**为什么这个策略必胜？**
假设当前棋子在主干道上，轮到 Bob 行动：

* **Bob 向左或向右走**：他会直接踩入 Alice 提前染白左右两侧的“护城河”中。轮到 Alice 时，她只需反方向走一步，就能把棋子重新拉回主干道。
* **Bob 向上或向下走**：因为主干道的列坐标在相邻行必定偏移 1 列，所以 Bob 上下移动后的落点，恰好会落在上一行或下一行主干道的“护城河”（白格）里！轮到 Alice 时，她只需向左或向右走一步，顺势将棋子拉入新一行的主干道。

只要 Alice 成功启动这个策略，Bob 的每一步都只能踩在白格上，直到游戏在 Bob 的回合结束，Alice 稳操胜券。

明确了必胜策略后，博弈问题就彻底转化为了一个求最小代价的 DP 问题。

如果某个格子 $(i, j)$ 被选为主干道的一部分，Alice 需要付出的局部代价就是将它左右两边染白的代价之和，即 $A_{i, j-1} + A_{i, j+1}$。

我们的目标是在网格中找到一条满足对角线相连（即每次只能向左下或右下走）的贯穿上下边界的路径，使得整条路径的局部代价之和最小。

**动态规划拆解：**

* **自顶向下计算**：计算出从第 1 行出发，按照对角线相连规则走到第 $i$ 行第 $j$ 列的最小累积代价。
* **自底向上计算**：计算出从第 $N$ 行出发，反向按照规则走到第 $i$ 行第 $j$ 列的最小累积代价。
* **合并路径**：对于网格中的任意一点 $(i, j)$，将其自顶向下的代价与自底向上的代价相加（并扣除一次重复计算的 $(i, j)$ 本身的代价），即可得到**一条必须经过 $(i, j)$ 且贯穿全局的最优主干道总代价**。

我们可以通过两次遍历，预处理出网格中每一个点作为主干道必经点时的全局最小代价。

游戏开始时，裁判指定了初始位置 $(h, w)$。

Alice 是先手，且只能向左或向右走。为了启动上述的必胜循环，Alice 的**第一步必须立刻将棋子移入主干道**。

这意味着，对于初始位置 $(h, w)$，Alice 有两个选择：

* 第一步走到 $(h, w-1)$，那么她需要的最低总代价就是经过 $(h, w-1)$ 的最优主干道代价。
* 第一步走到 $(h, w+1)$，那么她需要的最低总代价就是经过 $(h, w+1)$ 的最优主干道代价。

Alice 只需要在预处理好的结果中，查询这两个相邻位置的最优代价，取其中的**最小值**，即为当前初始位置下的答案。通过对整个网格的 $O(N^2)$ 预处理，我们可以做到 $O(1)$ 回答每一个初始坐标的查询。
</CollapsibleComponent>
