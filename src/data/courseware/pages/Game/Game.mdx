# 博弈论

计算问题归类：

- 模拟
- 计数
- 优化
  - 单人优化
  - 多人优化-博弈论

多人博弈的最优解$\to$二人博弈

- 完全信息，例如：象棋、围棋
- 不完全信息，例如：军旗

- 公平博弈：对于当前任何一个状态，无论是轮到甲行动，还是乙行动，它们的操作空间是一样的
- 不公平博弈：甲和乙的操作空间不一样
- 对于公平博弈，胜负只和谁先手谁后手有关；对于非公平博弈，还需要考虑当前轮到谁走了

##### 博弈论的最优解

什么叫最优解？

假设博弈的双方都绝顶聪明，都会选择最优的策略

必败状态：如果无论怎么操作，都会转移到对手必胜的状态，则该状态必败

必胜状态：如果存在一种操作，会转移到对手必败的状态，则该该状态必胜

## 博弈论问题的通用解法

- 博弈搜索
- SG函数


<BoxWithTag tag="两种方法的对比">
直接搜索的优点：每个状态的答案很简单，要么是必胜，要么是必败。方便剪枝：只要搜到一个必败的后继，则就不用继续搜了，直接返回必胜

SG函数的优点：在遇到多个问题拼接在一起时，计算的效率比较高。局限性：只能针对公平博弈问题
</BoxWithTag>
