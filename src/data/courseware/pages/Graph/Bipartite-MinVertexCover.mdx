# 二分图最小点覆盖

定义：选择最少的点使得所有边的两端点至少一个被选择

Konig定理：最小点覆盖=最大匹配

# 二分图最大独立集

最大独立集(选择最多的点使得它们两两没有边直接相连)=点数-最大匹配

# 最小边覆盖

最小边覆盖(选择最少的边取覆盖所有的顶点)=点数-最大匹配
