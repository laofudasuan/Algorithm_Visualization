## Borůvka算法

每次让每个连通块连向与它相邻的, 边权最小的连通块。

这个算法最多进行log轮，因为每进行一轮，最小连通块的大小至少*2。

##### CF888G Xor-MST
给一张$n$个点的完全图，每个点有一个点权$a_i$，$i$和$j$的边权为$a_i \oplus a_j$

求最小生成树，$n \le 2 \times 10^5, 0 \le a_i < 2^{30}$
 
<CollapsibleComponent title="做法">
使用Boruvka算法后，问题变成什么形式？

初始$n$个连通块，每次需要合并一些连通块，或者对每个连通块求出与其 xor 最小的连通块

可以将所有连通块对应的点排列成一个序列。

对于第$i$个连通块，其内部的点构成一个区间$[l_i,r_i]$。

我们需要对$[l_i,r_i]$中每个点找到$[l_i,r_i]$区间外的最小xor点。

看到 xor 可以想到用 01-Trie 贪心解决。$O(n\log n\log v)$
</CollapsibleComponent>

##### 牛客多校 - 5670B
给定一棵$n$个点的树，每条边权重为$w_i(2 \le n \le 10^5, 0 \le w_i < 2^{30})$

可以任意加边或者删边，但是要求在过程中的任何时刻，必须保证图连通，并且任何一个环的异或和为$0$

求最终得到的树，边权和最小值

<CollapsibleComponent title="做法">
由于每个环的 xor 和都得是 0，所以其实$(u,v)$边的边权可以确定下来，就是$u$到$v$在树上的路径 xor 和。

然后问题变成一个完全图最小生成树问题：

对任意两个点 $u,v$ 都有一条边，边权为树上 $u$ 到 $v$ 树上路径的边权 xor 和

现在要求这个完全图的最小生成树。
 
边权 xor 和就想到用树上差分来处理。

记录 $f[x]$ 表示 $x$ 到根路径的边权 xor 和。

于是 $x$ 到 $y$ 路径的边权 xor 和 $= f[x] ^ f[y]$。

于是问题变成给你一个 $f[1] \ldots f[n]$ 的数组，任意两点 $u,v$ 之间有边权为 $f[u] \oplus f[v]$ 的边，求完全图 MST。

于是就是上一道题。
 
</CollapsibleComponent>

##### AT_cf17_final_j Tree MST

给一棵$n$个点的树，每个点有点权$w$，每条边有长度$d$

现在有一张完全图，$x$到$y$的边长为$w_x+w_y+dis_{x,y}$,$dis_{x,y}$为树上$x$到$y$的所有边长度之和

求最小生成树$, n \le 2 \times 10^5$
 
<CollapsibleComponent title="做法">
使用 Boruvka 算法后，问题变成什么形式？

初始 $n$ 个连通块，每次需要合并一些连通块，或者对每个连通块中的每个点 $x$，求其他连通块中的小的 $w[x] + w[y] + dis(x,y)$
也就是求最小的 $w[y] + dis(x,y)$

Boruvka 算法有一个优势，每次可以将每个连通块进行染色，然后变成一种静态问题。

这道题中，就是树上每个点有一个颜色，对每个 $x$，求最小的 $w[y] + dis(x,y)$ 满足 $x$ 和 $y$ 颜色不同。
 

树上每个点有一个颜色，对每个点求出异色的点的最小的 $w[y]+dis(x,y)$

子树外的最近点可以换根 dp，子树内的最近点可以树形 dp。

异色的限制怎么办？

维护最近的点和第二近的点，要求二者颜色不同。

也就是说维护最近的颜色和第二近的颜色。

单次时间复杂度 $O(n)$，总复杂度$O(n \log n)$
 
</CollapsibleComponent>

##### 星街彗星
给定数组$x_{1 \ldots n}$，有一张$n$个点的完全图，对于任意$1 \le i < j \le n,i$到$j$的边权为$x_j-x_i$

求最小生成树，$n \le 3 \times 10^5, -3 \times 10^5 \le x_i \le 3 \times 10^5$
 
<CollapsibleComponent title="做法">
使用 Boruvka 算法后，问题变成什么形式？

对于点 $u$，要求和 $u$ 不同连通块中的点 $v$

如果 $u<v$，则边权为 $x[v]-x[u]$，否则为 $x[u]-x[v]$

于是分别求两种情况下的最近点。

不在同一个连通块：序列化，然后变成求前缀和后缀的最近距离。
 
进一步分析，如果 $u<v$，则边权为 $x[v]-x[u]$，否则为 $x[u]-x[v]$

其实就是 $u<v$ 的时候找最小的 $x[v],u>v$ 的时候找最小的 $-x[v]$

这个可以对前缀后缀跑值域线段树，平衡树，也可以用线性前驱后继技术。

于是总时间复杂度 $O(n\log^2n)$ 或者 $O(n\log n)$。
</CollapsibleComponent>

##### CF1550F Jumping Around
数轴上顺次有$n$个点$a_1 < a_2 < \ldots < a_n$

有一只青蛙，初始在$a_s$，小青蛙有两个参数$d,k$，其中$d$是固定的，$k$是每次询问不一样的

小青蛙可以从$a_i$跳到$a_j$，当且仅当$d-k \le |a_i-a_j| \le d+k$

给定$a_{1 \ldots n},d$，有$q$次询问，每次给定$i,k$，求青蛙能否跳到$a_i$

$n,q \le 2 \times 10^5, 1 \le s,i \le n, 1 \le a_i,d,k \le 10^6$
 

<CollapsibleComponent title="做法">

$s$ 到 $t$ 的边的最小的 $k$ 是多少？

$\min(|a[s]+d-a[t]|,|a[s]-d-a[t]|)$

$s$ 和 $t$ 连通至少需要多大的 $k$ 等价于 $s$ 到 $t$ 的所有路径上最大的边权最小是多少。

这个是瓶颈路问题，于是可以变成求 MST。

问题转换成完全图 MST 问题：

$(u,v)$ 的边权为 $\min(|a[u]-a[v]+d|,|a[u]-a[v]-d]|)$
 
接下来跑 Bovuvka 算法，可以把之前几道题常见的套路拼起来。

每个点要求不在同一个连通块的最近距离。

不在同一个连通块：序列化，然后变成求前缀和后缀的最近距离。
 
最近距离：对点 $u$，找到 $v$ 使得 $\min(|a[u]-a[v]+d|,|a[u]-a[v]-d|)$ 最小。

设 $a[u]+d=x,a[u]-d=y$

即 $\min(|x-a[v]|,|y-a[v]|)$ 最小，可以分别求最小的 $|x-a[v]|$ 和 $|y-a[v]|$。

这个可以对前缀后缀跑 set，也可以用线性前驱后继技术。

于是总时间复杂度 $O(n\log^2n)$ 或者 $O(n\log n)$。
 
</CollapsibleComponent>

##### 最大生成树 · 曼哈顿距离

给定 $n$ 个二维平面点 $(x_i,y_i)$，定义两个点的距离为平面上的曼哈顿距离。

求完全图的最大生成树。

$n \le 2 \times 10^6$
 
<CollapsibleComponent title="做法">
使用 Boruvka 算法后，问题变成什么形式？

对每个点 $(x_i,y_i)$，找到最远的 $(x_j,y_j)$ 满足两点不在同一个连通块中。

如果用之前的套路处理方法，这里 Boruvka 每一层需要 $O(n\log n)$ 的时间，总时间复杂度是 $O(n\log^2n)$ 的。

有没有简单点的性质？
 
对于点 $(x_i,y_i)$，最远点一定是 $x_j+y_j，x_j-y_j，-x_j+y_j，-x_j-y_j$ 最大的四个点 $j$ 中的一个。

但是如果这四个点都和 $i$ 点在同一个连通中？

对于每种情况，找不同色的前 $2$ 大点即可。

于是每个连通块只会和 $O(1)$ 个点连边。

总时间复杂度 $O(n\log n)$。
 
能不能做到 $O(n)$ 呢？

每个连通块中维护内部 $x_j+y_j，x_j-y_j，-x_j+y_j，-x_j-y_j$ 的最大值。

每个连通块其实每次只和外面的 $O(1)$ 个连通块计算距离，只有内部的 $4$ 个极值和外部的 $4$ 个极值。

Boruvka 过程中每一轮连通块数减半，于是总时间复杂度是 $n+n/2+n/4+n/8+...=O(n)$

</CollapsibleComponent> 

##### Hdu 5398（弱化版）
给你一个 $n$,让你输出一个最大生成树的价值。

有 $n$ 个点，任意两点 $(u,v)$ 有条边，边权为 $gcd(u,v)$。

$n \le 10^5$

<CollapsibleComponent title="做法"> 
这个题用 Boruvka 反而麻烦了，因为输入只有 $O(1)$，其实我们可以考虑找找规律。

如果 $(x,y)$ 连边，且 $d=gcd(x,y)$ 使得 $d<x$ 且 $d<y$，那么考虑 $(d,x)$，$(d,y)$，去掉边 $(x,y)$ 后 $d$ 必然和一个不在一起，那么连上这条边即可。

$gcd(x,y) \ge gcd(x,d),gcd(y,d)$

所以最后的任意边 $(x,y)$ 都是 $x|y$ 或 $y|x$ 的，我们只需要维护这样的边就可以了。

由调和级数，我们找出的边是 $O(n\log n)$ 条的。
</CollapsibleComponent>
 
##### CF1648E Air Reform
一张$n$个点$m$条边的无向带权简单连通图，一条路径的权值为所有边权的max

考虑这张图的补图，补图中一条边的权值为原图中该边两端点间的最短路（路径长度的定义同上）。保证补图亦是连通图。

对于原图中每条边，求出其两端点在补图中的最短路（定义仍同上）。

$n,m \le 2 \times 10^5$
 
<CollapsibleComponent title="做法">
问题是多次询问两点之间的瓶颈路，于是考虑先求出 MST。

使用 Boruvka 算法后，问题变成什么形式？

对每个点 x，求出和 x 不在同一个连通块中的最近点。

在原图的Kruskal 重构树上，找一个和它LCA点权最小的点，并且和它不在一个连通块
 
$i$和$j$的LCA尽可能深，那就是DFS序尽可能接近

其实就是求在DFS上，离$i$最近的，和$i$不在一个连通块，并且和$i$在原图中不相连的$j$

维护一个指针暴力跳，从$i$的左侧和右侧出发，发现两个点在原图中有边相连，就继续往两侧跳

随着 Boruvka 算法的执行，之前的指针会不断前移，之后的指针会不断后移。失配的总次数是$O(m)$级别的
</CollapsibleComponent>
