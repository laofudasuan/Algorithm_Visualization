<CollapsibleComponent title="做法"> 
网络流的容量来限制门同一时刻只能进一个人的关系

把一个门拆成很多个时间点，然后每个时间点向$T$连边

预处理每个门到各个空格的最短路，每个空格直接连对应的最短时间

##### gym104821E
给定一个$n \times m$的网格图，边有非负边权。

BaoBao 想从第一列的某个点$(p,1)$出发，到第$m$列的某个点$(q,m)$截止，走一条简单路径。

BaoBao 想走尽量少的路，所以 BaoBao 会选择$(p,q)$和它们之间的路径使得路径长度最短。

Little Cyan Fish 可以每次把某一条边的边权增加$1$，花费$1$的代价。

请问想让 BaoBao 走的路径长度增加$k$至少需要花费多少代价。

$1 \le n \times m \le 500,1 \le k \le 100$，给出的边权$ \le 10^9$，多组数据，$\sum n \times m \le 5000$。

<CollapsibleComponent title="做法"> 
考虑对偶图，我们要做的是把最大流增加$k$。

我们在原来的图上的每条边额外增加一条费用为$1$，容量为$\infty$的边。

为了保证复杂度，需要先跑 dinic，再在残量网络上跑费用流。

时间复杂度$O(n^2m^2k)$。
</CollapsibleComponent>

##### P3511 [POI 2010] MOS-Bridges

- 给定一个 $n$ 个点 $m$ 条边的简单无向图，第 $i$ 条边 $(u_i, v_i)$ 有两个边权 $l_i, p_i$，分别表示 $u_i \to v_i$ 和 $v_i \to u_i$ 方向的权值。
- 你需要找到一条从点 $1$ 开始的欧拉回路，满足经过的所有边的对应方向的权值中最大值最小。
- $2 \leq n \leq 1000$，$1 \leq m \leq 2000$，$1 \leq l_i, p_i \leq 1000$。

<CollapsibleComponent title="做法">
- 不妨二分答案，问题转化为：判定一个有若干条边还未定向的有向图，是否存在一种定向方案使其存在欧拉回路。
- 对于弱连通的有向图，存在欧拉回路的充要条件是所有节点都满足入度与出度相等。
- 记 $d_i$ 为原图点 $i$ 的度数，不难给出一个最大流建模：
  - 对边 $(u_i, v_i)$ 连边 $(s, i, 1)$。
  - 对点 $j$ 连边 $\left(j + m, t, \frac{d_j}{2}\right)$。
  - 对边 $(u_i, v_i)$，若 $u_i \to v_i$ 方向可行则连边 $(i, v_i + m, 1)$，若 $v_i \to u_i$ 方向可行则连边 $(i, u_i + m, 1)$。
- 转为判定是否满流即可，时间复杂度 $O(m^2 \log \max\{l_i, p_i\})$
</CollapsibleComponent>
