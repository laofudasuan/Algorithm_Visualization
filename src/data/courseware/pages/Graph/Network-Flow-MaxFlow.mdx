# 最大流例题

##### P2764 最小路径覆盖问题
给定有向图 $G = (V, E)$。设 $P$ 是 $G$ 的一个简单路（顶点不相交）的集合。如果 $V$ 中每个顶点恰好在 $P$ 的一条路上，则称 $P$ 是 $G$ 的一个路径覆盖。$P$ 中路径可以从 $V$ 的任何一个定点开始，长度也是任意的，特别地，可以为 0。$G$ 的最小路径覆盖是 $G$ 所含路径条数最少的路径覆盖。设计一个有效算法求一个 DAG（有向无环图）$G$ 的最小路径覆盖。

$n \le 150, m \le 6000$

<CollapsibleComponent title="做法"> 
直接求解看似很难，我们不妨换一个理解方式：一条简单路径必然包含的点数$=$包含的边数$+1$。包含的点数总和恒为$n$,那么$n-$最多包含的边数就是答案。

现在问题变成了要选出尽量多的边，同时为了保证方案的合法性，每个点最多有一条出边被选择，最多有一条入边被选择。这实际上就是一个二分图匹配问题，每个点最多只能与一个点匹配。

所以直接用匈牙利/网络流即可。
</CollapsibleComponent>

##### 环覆盖问题
一张$n$个点$m$条边的有向图，你要从中选出若干个点不相交的环。记这些环覆盖的点集为$S$。

求一种方案使得$S$中的点从大到小排序后字典序最大。

<CollapsibleComponent title="做法">
一样的方法，我们给每个点都加一个自环，这样选出若干个不相交的环$\Leftrightarrow$每个点入度出度都为$1$。

然后贪心地从大往小扫每个点，能不选自环就不选自环。
</CollapsibleComponent>

##### gym104821E
给定一个$n \times m$的网格图，边有非负边权。

BaoBao 想从第一列的某个点$(p,1)$出发，到第$m$列的某个点$(q,m)$截止，走一条简单路径。

BaoBao 想走尽量少的路，所以 BaoBao 会选择$(p,q)$和它们之间的路径使得路径长度最短。

Little Cyan Fish 可以每次把某一条边的边权增加$1$，花费$1$的代价。

请问想让 BaoBao 走的路径长度增加$k$至少需要花费多少代价。

$1 \le n \times m \le 500,1 \le k \le 100$，给出的边权$ \le 10^9$，多组数据，$\sum n \times m \le 5000$。

<CollapsibleComponent title="做法"> 
考虑对偶图，我们要做的是把最大流增加$k$。

我们在原来的图上的每条边额外增加一条费用为$1$，容量为$\infty$的边。

为了保证复杂度，需要先跑 dinic，再在残量网络上跑费用流。

时间复杂度$O(n^2m^2k)$。
</CollapsibleComponent>

##### P3731 [HAOI2017] 新型城市化

- 给定一个 $n$ 个点 $m$ 条边的二分图，你需要对每条边判断删去这条边后最大独立集大小是否会 $+1$。
- $1 \leq n \leq 10^4$，$0 \leq m \leq \min\left\{1.5 \times 10^5, \frac{n(n - 1)}{2}\right\}$。

<CollapsibleComponent title="做法">
- 建出经典的求解二分图最小点覆盖的网络流建模：
  - 对于左部点 $x$ 连边 $(s, x, 1)$。
  - 对于右部点 $y$ 连边 $(y, t, 1)$。
  - 对于原图的边 $(x, y)$，连边 $(x, y, +\infty)$（等价于 $(x, y, 1)$）。
- 题意即判断边 $(x, y)$ 是否为最大流必须流经的边。
- 鉴于所有边容量均为 $1$，求出残余网络后只保留所有流量 $> 0$ 的边，如果有边 $(x, y)$ 就判断 $x, y$ 是否不在同一个强连通分量中即可。
- 用 Dinic 时间复杂度 $O(m\sqrt{n})$。
</CollapsibleComponent>

##### P3511 [POI 2010] MOS-Bridges

- 给定一个 $n$ 个点 $m$ 条边的简单无向图，第 $i$ 条边 $(u_i, v_i)$ 有两个边权 $l_i, p_i$，分别表示 $u_i \to v_i$ 和 $v_i \to u_i$ 方向的权值。
- 你需要找到一条从点 $1$ 开始的欧拉回路，满足经过的所有边的对应方向的权值中最大值最小。
- $2 \leq n \leq 1000$，$1 \leq m \leq 2000$，$1 \leq l_i, p_i \leq 1000$。

<CollapsibleComponent title="做法">
- 不妨二分答案，问题转化为：判定一个有若干条边还未定向的有向图，是否存在一种定向方案使其存在欧拉回路。
- 对于弱连通的有向图，存在欧拉回路的充要条件是所有节点都满足入度与出度相等。
- 记 $d_i$ 为原图点 $i$ 的度数，不难给出一个最大流建模：
  - 对边 $(u_i, v_i)$ 连边 $(s, i, 1)$。
  - 对点 $j$ 连边 $\left(j + m, t, \frac{d_j}{2}\right)$。
  - 对边 $(u_i, v_i)$，若 $u_i \to v_i$ 方向可行则连边 $(i, v_i + m, 1)$，若 $v_i \to u_i$ 方向可行则连边 $(i, u_i + m, 1)$。
- 转为判定是否满流即可，时间复杂度 $O(m^2 \log \max\{l_i, p_i\})$
</CollapsibleComponent>
