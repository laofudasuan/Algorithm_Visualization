# 贪心+调整法

## 调整法证明贪心策略

##### 例题
    
给定 $n$ 个二元正整数对 $(a_i, b_i)$，将它们按照任意顺序排成一列。定义排成一列的代价为每个二元组的 $a$ 乘上序列中这个二元组之后的所有二元组的 $b$ 之和的总和。求最小的代价。

$$n < 10^6, 1 \leq a_i, b_i \leq 10^6$$


<CollapsibleComponent title="解法">
用调整法来找最优解

答案的表达式为$\sum_{1 \le i<j \le n}a_ib_j$

对于相邻两项$i$和$i+1$，如果交换它们两项，答案的变化量为：

$$
a_{i+1}b_j-a_ib_{j+1}
$$

这个式子跟其他的项都无关，因此最优解就是按照$\frac{a_i}{b_i}$排序
</CollapsibleComponent>

##### CF632C The Smallest String Concatenation

给定$n$个字符串$s_{1 \ldots n}$，你需要找一种顺序把这$n$个串拼成一个大串，让大串的字典序最小

$|\sum s_i| \le 5 \times 10^5$

<CollapsibleComponent title="解法">
考虑对于任意一种方案，对于前后相邻的两个字符串$s_i$和$s_j$，如果$s_j+s_i<s_i+s_j$，则交换更优，可以证明这个关系满足传递性

因此最优解就是把所有串按照字典序排序

实现可以用二分+哈希或者后缀数组

</CollapsibleComponent>

##### P6927 ICPC 2016 WF Swap Space
有 $n$ 块硬盘，需要对这些硬盘进行格式化。第 $i$ 块硬盘在格式化前容量为 $a_i$，格式化后容量为 $b_i$。初始时每块硬盘中都装满了数据，但在格式化一块硬盘的过程中，需要将这块硬盘上的所有数据移动到其他硬盘或者存储空间中。数据可以进行任意转移，任意分割。求最少需要多少的额外存储空间，才能格式化所有的硬盘并保留数据。

$n \leq 10^6, 0 \leq a_i, b_i \leq 10^9$


<CollapsibleComponent title="解法">

设第 $i$ 次格式化的硬盘为第 $p_i$ 块。则在格式化第 $p_i$ 块硬盘前，需要的额外空间为

$$
\max \left(0, \sum_{j=1}^{i-1} b_{p_j} - \sum_{j=1}^{i} a_{p_j}\right)
$$

因此问题相当于给定 $n$ 对 $(a_i, b_i)$，找到它们的一个排列，最大化

$$
\min_{i=1}^{n} \left\{\sum_{j=1}^{i-1} b_j - \sum_{j=1}^{i} a_j\right\}
$$

如果考虑相邻两项$i$和$j$，令$S$为这两项之前的$\sum (b_j-a_j)$，如果$i$放$j$前面，对答案的贡献为$S+\min(-a_i,b_i-a_i-a_j)$，如果$i$放$j$后面，则贡献变为$S+\min(-a_j,b_j-a_j-a_i)$

显然，应该先考虑$a_i<b_i$的硬盘，再考虑$a_i>b_i$的硬盘

阶段一：$a_i < b_i, a_j < b_j$：

假令 $a_i \leq a_j$（否则交换$i,j$）
    
- 如果 $b_i \geq a_j$。则按照$i$在前的顺序，min为$-a_i$；而按照$j$在前的顺序，min为$-a_j$。所以按照 $i,j$ 顺序更优。
- 如果 $b_i < a_j$。则按照$i$在前的顺序，min为 $b_i-a_i-a_j$；而按照$j$在前的顺序，min为$-a_j$。而$b_i-a_i>0$，所以按照$i,j$顺序更优。
    
综上，对于所有$a_i<b_i$的项，此时按照 $a_i$ 从小往大排序正确。

阶段二：$a_i > b_i,a_j>b_j$：

假令$b_i \ge b_j$（否则交换$i,j$）

- 如果 $b_i \geq a_j$。则按照$i$在前的顺序，min为 $-a_i$；而按照$j$在前的顺序，min为$b_j-a_j-a_i$。因为$b_j-a_j<0$，所以按照 $i,j$顺序更优。
- 如果 $b_i < a_j$。则按照$i$在前的顺序，min为$b_i-a_i-a_j$；而按照$j$在前的顺序，min为$b_j-a_j-a_i$，而因为$b_i \ge b_j$，所以按照顺序$i,j$更优。
    
综上，此时按照 $b_i$ 从大往小排序正确。

沿用之前的方法，定义 $x \leq y$ 当且仅当 $F(\{x, y\}) \leq F(\{y, x\})$，对于两个元素 $(a_1, b_1)$, $(a_2, b_2)$，$(a_1, b_1) \leq (a_2, b_2)$ 当且仅当 $\min\{-a_1, b_1 - a_1 - a_2\} \geq \min\{-a_2, b_2 - a_1 - a_2\}$。考虑这样定义的 $\leq$ 关系是否满足上述性质。对于性质 2.3，设最后的序列为 $(a_1, b_1), \cdots, (a_n, b_n)$，交换的元素为

##### P4511 日程管理 CTSC2015

对于每个任务$i$有一个对应的截止日期$t_i$以及收益$p_i$，表示若幽香能在不晚于第$t_i$天完成这个任务，便可以得到$p_i$的收益。幽香办事的能力非常强，任何任务都可以用恰好一天的时间做完。但由于任务实在太多了，有时候并不能完成所有任务，于是幽香会想知道这个情况下，完成任务可以给她带来的最大的累积收益是多少。

幽香希望支持以下2个操作： 
    
- ADD t p：表示新添一个截止日期为t，收益为p的任务。 
- DEL t p：表示删除一个截止日期为t，收益为p的任务。如果有多个这样的任务，只删除一个。数据保证这样的任务一定存在。 

在每次操作执行完毕后，你都需要输出能够完成的任务的最大收益和。 

幽香一共有$T$天需要安排，从第$1$天到第$T$天。你能帮助他写出这个高效率的软件吗？ 

$T\le 300000，Q \le 300000$


<CollapsibleComponent title="解法">
    
- 当不存在修改操作时，比较经典的做法是按照权值从大到小能选就选。
- 如何判断当前能否选择呢?
- 只需要满足对于任意的$i$，$t[k] \le i$的$k$的个数$\le i$即可。
- 所以一开始所有天数$i$的计数器赋值为$i$，如果当前添加了一个元素$k$，那么需要把$[t[k],T]$这段区间的计数器$-1$，如果出现了负数就不合法。
- 线段树的基本操作:区间加减、最值查询。
- 如何添加元素，设当前需要添加$t[x],p[x]$，那么查找$[t[x],T]$这段区间最小值是否为$0$，如果不为$0$则直接添加
- 否则我们可以找到从$t[x]$开始第一个$0$的位置$v$，那么只要删除区间$[1,v]$内的任意一个元素就可以把它添加进去。
- 用第二颗线段树维护已添加元素的区间最小值，如果最小值小于当前元素则进行替换
- 考虑删除，对于删除元素$t[x],p[x]$，如果它当前未被选择则直接删除
- 否则我们可以找到区间$[1,t[x]]$的最后一个$0$的位置$v$(如果不存在$0$则赋值为$0$)
- 那么删除元素$x$后可以在$[v+1,T]$内任意添加一个元素。
- 用第三棵线段树维护未被选择的元素的最大值。对于第二、三棵线段树，它的叶子节点可以用堆或者平衡树维护。
    
</CollapsibleComponent>

有一排格子，每个格子有三个数 $p_i, a_i, b_i$，现在你要玩一个游戏，你站在第一个格子上，要跳到第 $n+1$ 个格子，$p_{n+1} = \infty$。有一个格子集合 $S$，你必须跳到 $S$ 中的所有格子（其它随意）。

假设你站在格子 $i$，下一步你可以选择：

- 花费 $a_i$ 的代价，跳到 $i+1$。
- 花费 $b_i$ 的代价，跳到 $i$ 后面第一个满足 $p_j > p_i$ 的位置 $j$。
    
一轮游戏的代价是跳的总代价。

有 $q$ 轮游戏，一开始 $S$ 为空，每轮的 $S$ 是上一轮的 $S$ 加入或删去一个格子。请对于每一轮游戏求出最小的代价。

<CollapsibleComponent title="解法">

##### CF1495F Squares

定义$f[i]$为$i$右边第一个$p_j>p_i$的点

考虑先固定决策为每次+1，然后再把其中一些连续段$[i,f[i]]$的+1调整为$b[i]-\sum_{j=i}^{f[i]-1}a[j]$

注意到所有的$[i,f[i]]$区间要么包含，要么不相交。也就是说我们最后选的区间是一定无交的

这样，我们可以用扫描线求解从一个点到另一个点的最短路

对于每次询问的$S$，相当于是求$S$相邻两个点的最短路之和。每次修改时段数的变化为$O(1)$，因此可以离线出所有区间然后扫描线询问。

</CollapsibleComponent>

##### P12074 CF2079B Arithmetic Exercise
给定一个长为 $m$ 的序列 $x_1 \sim x_m$。你有 $n$ 个变量 $a_1 \sim a_n$，初始全部为 $0$。你需要对 $i = 1, 2, \cdots, m$ 依次执行以下操作：

- 选择 $j (1 \leq j \leq n)$，令 $a_j \leftarrow x_i - a_j$。
    
求出 $m$ 个操作完成后 $\sum_{i=1}^{n} a_i$ 的最大值。

$n,m \le 3 \times 10^5$

<CollapsibleComponent title="解法">

把序列$a$倒过来，问题变成了：把$a$分解为不超过$n$个子序列，最大化每个子序列的奇数项减去偶数项之和

可以把问题转化为：确定每个$a_i$的系数$b_i \in \{1,-1\}$，满足$b$的前缀和都$\in [0,n]$，最大化$\sum a_i \times b_i$

从前往后考虑，如果$a_i>0$则我们希望$b_i=1$，但需要考虑合法性，如果之前$b$之和$<n$则可以填$b_i=1$，否则我们需要把之前的某个$+1$改成$-1$

同时我们这个操作会把前面的前缀和变小，为了保证合法，可以被改的$+1$应该是一段后缀，所以在这段后缀中找一个最小的修改。

所以可以对所有$b_i=1$的项和所有$b_i=-1$的项分别开一棵线段树维护。

对于$a_i<0$的情况也同理。
</CollapsibleComponent>

- 求所有合法方案中正面向上的卡片数量最多的值。
- $1 \le N, Q \le 100000, 1 \le A_i,B_i,C_i,D_i,E_i \le 10^9$
    
###### Q=1
    
- 如果只需要判断一组解合不合法的话，可以每次删两个最大的看能不能删。
- 记$sum$为后缀和，就是对任意数值$x$，都有$suma_x \le sumc_x$，也即$sum_x = suma_x − sumc_x \ge 0$,其中$sum_x$是某个序列$\ge x$的值的个数。
- 那么我们给一张卡牌翻面的时候，就是给一段区间$+1$。
- 每次找到最右边的$<0$的位置，然后选左端点最靠左的区间加上去。
- 时间复杂度$O(N \log N)$

- 加入一张卡片相当于是让一个前缀减少了$1$。
- 不妨先求出只有$N$张卡片时的解，然后再选择一些区间去覆盖这个前缀。

- 考虑用$Q=1$时的方法求得的一组解

- 做到某个点$x$时，因为在它后面的点都至多差$1$，如果你用一个左端点较大的区间去覆盖后面的点的话，不如将这个区间放入你预留出来的位置，此时后面的区间都已经和这个点的决策没关系了，剩下的肯定选左端点较小的。

##### Pretty Boxes(Codechef November Chanllenge 2019 Div1)
有$N$个盒子，第$i$个盒子大小为$S_i$，美丽程度为$P_i$

对于两个盒子$i,j$，如果$S_i \le S_j$则可以把盒子$S_i$装在盒子$S_j$当中。装好以后的美丽程度为$P_j-P_i$

对于每一个$K \in [1,N/2]$，求出，从$N$个盒子中选出$2K$对盒子，使得每一对盒子的美丽程度之和最大

$N \le 2 \times 10^5$

<CollapsibleComponent title="做法">
把所有盒子按照$(S_i,P_i)$双关键字排序，问题就变成了要选择一个括号序列，左括号价值为$-P_i$，右括号价值为$P_i$。

左括号看成$1$，右括号看成$-1$，则括号序列合法当且仅当前缀和数组$\ge 0$

考虑每次加一对括号$(a,b)$如何保证合法：

如果$a<b$则显然合法，否则需要满足，$b$到$a$这一段的前缀和不能为$0$

这样我们可以把序列看成是被前缀和为$0$的位置分割出来的一段段连通块，每一个连通块内可以随意选一对，连通块与连通块之间只能左括号在左边，右括号在右边

线段树维护这样的信息：
	
- 区间中最小的前缀和
- 区间中连通块内的最优答案
- 区间中跨越连通块的最优答案

在合并时需要用到:

- 左区间中 右边连续的一段不跨过最小值 的最大权值
- 右区间中 左边连续的一段不跨过最小值 的最小权值
- 以及任意的最小值最大值
