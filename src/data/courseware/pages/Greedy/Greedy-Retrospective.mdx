##### arc220_c Range Increment 

给定整数 $N, M, K$，以及一个长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$。保证 $A$ 中的每个元素都在 $0$ 到 $M-1$ 之间（包含两端）。

你可以对整数序列 $A$ 执行 0 到 $K$ 次操作（包含 0 和 $K$），每次操作的规则如下：
- 选择一对整数 $(l, r)$，满足 $1 \le l \le r \le N$，并对每个 $k = l, l+1, \dots, r$，将 $A_k$ 替换为 $(A_k + 1) \bmod M$。

求执行完操作后，字典序最小的序列 $A$。

共有 $T$ 组测试用例，请你分别求解。

> 序列的字典序定义：对于两个序列 $X$ 和 $Y$，若存在下标 $i$ 使得 $X_i < Y_i$，且对所有 $j < i$ 都有 $X_j = Y_j$，则称序列 $X$ 的字典序小于 $Y$。

- $1 \le T \le 3 \times 10^5$
- $1 \le N \le 3 \times 10^5$
- $2 \le M \le 10^9$
- $1 \le K \le 10^{15}$
- $0 \le A_i < M$
- 所有测试用例的 $N$ 之和不超过 $3 \times 10^5$
- 所有输入值均为整数

<CollapsibleComponent title="做法">
字典序最小的问题，显然应该从左往右贪心

考虑到一个位置时，如果能变0就变0，不能变0就停止所有区间，让这一位不变

难点：例如$M=10,A_i=6$，之前有$8$个区间还没有结束，此时有两种选择：
- 新增$6$个区间
- 让$4$个区间结束

第一反应感觉让$4$个区间结束好，但是有反例：如果之后考虑到一个时刻，已经放的区间都结束了，$A_i=2$，同时$k=6$，这个时候是无法新增$8$个区间的，但是可以把之前这一次的结束四个区间改成新增六个区间

所以可以进行反悔贪心
</CollapsibleComponent>

## 老鼠进洞模型

### 原始模型

数轴上有$n$只老鼠和$m$个洞，每个洞有一个容量限制

问让所有老鼠都进洞的最小总距离

$n,m \le 10^5$
 
<CollapsibleComponent title="做法">
从前往后动态加边

小技巧：在$-\infty$处放一个容量为$n$的洞，这样可以保证所有S的出边始终都是满流状态

增加一个老鼠时，找一条新增广路

增加一个洞时，找一个负权环

用堆维护

具体实现：

```
开两个堆，一个老鼠堆，一个洞堆

把老鼠和洞排序从左往右扫

如果当前扫到的是老鼠i：
{
    从洞堆中取出最小值w
    ans += x[i]+w
    往老鼠堆中放入   -(x[i]+w)    - x[i]
}
如果当前扫到的是洞i：
{
    从老鼠堆中取出最小值w
    if (x[i]+w <0) {
            ans += x[i]+w;
            往洞堆中放入 -(x[i]+w) - x[i]
    } else 往洞堆中放入 -x[i]
}
```
</CollapsibleComponent>
