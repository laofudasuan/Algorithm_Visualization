## 老鼠进洞模型

### 原始模型

数轴上有$n$只老鼠和$m$个洞，每个洞有一个容量限制

问让所有老鼠都进洞的最小总距离

$n,m \le 10^5$
 
<CollapsibleComponent title="做法">
从前往后动态加边

小技巧：在$-\infty$处放一个容量为$n$的洞，这样可以保证所有S的出边始终都是满流状态

增加一个老鼠时，找一条新增广路

增加一个洞时，找一个负权环

用堆维护

具体实现：

```
开两个堆，一个老鼠堆，一个洞堆

把老鼠和洞排序从左往右扫

如果当前扫到的是老鼠i：
{
    从洞堆中取出最小值w
    ans += x[i]+w
    往老鼠堆中放入   -(x[i]+w)    - x[i]
}
如果当前扫到的是洞i：
{
    从老鼠堆中取出最小值w
    if (x[i]+w <0) {
            ans += x[i]+w;
            往洞堆中放入 -(x[i]+w) - x[i]
    } else 往洞堆中放入 -x[i]
}
```
</CollapsibleComponent>

无解输出-1。
