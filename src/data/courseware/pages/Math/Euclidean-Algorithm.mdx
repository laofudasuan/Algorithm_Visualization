## 欧几里得算法

求两个数的最大公约数

## 欧几里得

Lemma: $\gcd(a,b)=\gcd(b,a \bmod b)$

Proof: 如果 $g|a, g|b$，那么 $g|(a-b)$。所以 $\gcd(a,b)|(a \bmod b)$

## Problem

求两个数的最小公倍数

$$\text{lcm}(a,b)=\frac{ab}{\gcd(a,b)}$$

## O(1)gcd

多组询问，每次给两个不超过 $10^5$ 的数，询问他们的 gcd

## O(1)gcd解法

一个结论：任何一个数 $x$ 一定能分解成三个数 $p_1,p_2,p_3$，满足 $p_i$ 为质数或者 $p_i \le \sqrt{x}$。

这样我们只需要预处理出任意 $a,b \le \sqrt{n}$，$\gcd(a,b)$ 的值，就可以求出 $a$ 分解的三个数分别与 $b$ 的 gcd 然后组合。

如何构造这三个数的组合呢？

我们在线性筛时把一个数 $x$ 拆成它的最小质因子 $p$ 和 $k=x/p$ 的形式。

那么把 $k$ 分解出来的三个数中最小的那个数乘上 $p$ 就得到了 $x$ 的拆分。

证明：对于数 $k$ 的三个拆分 $k_1 \le k_2 \le k_3$ 一定满足 $k_1 \le k^{1/3}$。如果 $k_1=1$，那么 $kp$ 会被分解为三个质数或 $1$，一定满足条件。

否则，由于 $p \le k$ 的最小质因子，则 $p \le k^{1/3}$。所以我们有 $k_1^2 p \le k \to k_1 p \le \sqrt{kp}$。

在 2077 年，世界被机器人奴役后，机器人决定实施教育改革，现在取模运算仅在“古代世界历史”学院中教授。以下是该学院的入学任务之一：

我们定义一个正整数数组 $b$ 的美观度为所有 $1 \leq i, j \leq n$ 数对中 $f(b_i, b_j)$ 的最大值，其中 $f(x, y) = (x \bmod y) + (y \bmod x)$。

给定一个长度为 $n$ 的正整数数组 $a$，输出 $n$ 个数字，其中第 $i$ 个数字 $(1 \leq i \leq n)$ 是数组 $a_1, a_2, \ldots, a_i$ 的美观度。

$n \le 10^6, a_i \le 10^9$

<CollapsibleComponent title="做法">

首先注意到，假设 $x>y$，$f(x,y) = y + x - \lfloor x/y \rfloor y$。

而 $\lfloor x/y \rfloor \ge 1$，因此 $f(x,y) \le x$。

这样，我们找到前缀最大值 $m$，可以证明 $m$ 必选：

- 如果存在 $[m/2, m-1]$ 内的数，则答案为 $m$
- 否则，选两个都 $<m$ 的数 $x,y$ 肯定不如选一个数搭配上 $m$ 更优

从前往后依次求出每个前缀的答案。

每次加一个数 $a[i]$：

- 如果最大值不变，则用 $f(m,a[i])$ 更新答案
- 如果最大值变了：
  - 如果新的最大值 $\le 2m$，答案 $=$ 新的最大值
  - 否则，说明新的最大值 $> 2m$，暴力

##### P11846 USACO25FEB Transforming Pairs P

回答 $Q$ $(1 \leq Q \leq 10^5)$ 个独立查询，每个查询的形式如下：

给定四个整数 $a$, $b$, $c$, $d$ $(-10^{18} \leq a, b, c, d \leq 10^{18})$。在一次操作中，你可以执行 $a += b$，或 $b += a$。求将 $(a, b)$ 转变为 $(c, d)$ 所需要的最小操作次数，或者如果不可能完成，输出 $-1$。

<CollapsibleComponent title="做法"> 

先考虑如果 $a,b$ 都是正数的情况。

在这种情况下，任何时候都不会出现负数，因此可以考虑从 $(c,d)$ 倒推。倒推的时候，因为不能出现负数，每一步都只能大的减去小的数，也就是一个辗转相除的过程。

$a,b$ 都是负数同理。所以接下来需要考虑一正一负的情况。

考虑 $a<0,b>0,c>0,d>0$ 的情况。

我们可以把过程分为两个阶段：第一阶段的过程中 $a,b$ 始终保持一正一负，到第一阶段的最后一步才变成两个正数。

第二阶段可以根据刚刚的做法倒推，得出 $\log$ 个等差数列。

而注意到第一阶段也可以分成 $\log$ 个等差数列，所以相当于是在两组等差数列中求交。

复杂度 $O(\log^2)$
