# 高斯消元

## 从方程组到矩阵

高斯消元用来求解**线性方程组**：未知数只能以一次项出现，不能有未知数之间的乘积。例如：

$$
\begin{cases}
2x_1+x_2-x_3=8,\\
-3x_1-x_2+2x_3=-11,\\
-2x_1+x_2+2x_3=-3.
\end{cases}
$$

把系数排成矩阵 $A$，常数排成列向量 $b$，就可以写成 $Ax=b$。计算时把它们放在一起，得到**增广矩阵** $[A\mid b]$：

$$
\left[\begin{array}{rrr|r}
2&1&-1&8\\
-3&-1&2&-11\\
-2&1&2&-3
\end{array}\right].
$$

每一行代表一个方程，每一列系数对应一个未知数。高斯消元的核心是：不断消去某些未知数，把方程组变成容易求解的阶梯形，同时保持解集不变。

## 为什么可以消元

下面三种**初等行变换**都不改变方程组的解集：

1. 交换两个方程，即交换两行。
2. 将一个方程的两边同乘一个非零数。
3. 将一个方程的若干倍加到另一个方程上。

第三种变换可以消去未知数。例如，若两个方程中 $x_1$ 的系数分别为 $2$ 和 $6$，就用第二行减去第一行的 $3$ 倍，使第二行中 $x_1$ 的系数变成 $0$。**常数项必须与系数一起变换**，否则方程就不再等价。

## 选主元、消元与回代

设当前准备处理第 $c$ 列，下一条主元行的位置为 $r$。已经处理过的行不再参与主元选择。

1. **选主元。** 在第 $r$ 行及其下方，选择第 $c$ 列绝对值最大的元素，并将它所在的行交换到第 $r$ 行。这个非零元素叫作主元。选择较大的主元可以减少除以很小的数带来的数值误差。
2. **跳过零列。** 如果这一列未处理部分的元素都接近 $0$，这一列不能产生主元。只移动列指针 $c$，不移动行指针 $r$。
3. **消去下方系数。** 对每一行 $i>r$，令 $t=a_{i,c}/a_{r,c}$，执行 $R_i\leftarrow R_i-tR_r$。于是 $a_{i,c}$ 变成 $0$，同一行右侧的系数和常数也一起更新。
4. **继续处理。** 当前主元处理完后，$r$ 和 $c$ 都向前移动。最终得到阶梯形矩阵。

如果方程组有唯一解，阶梯形矩阵的最后一条非零行只包含一个未知数。先求出它，再从下往上把已知值代入，依次求出其他未知数，这一步叫作**回代**：

$$
x_i=\frac{b_i-\sum_{j=i+1}^{n}a_{i,j}x_j}{a_{i,i}}.
$$

这里的回代公式对应每一列都有主元的情形。演示中的第一组方程最终得到 $x_1=2,\ x_2=3,\ x_3=-1$，可以代回原方程检查。

## 如何判断解的情况

消元完成后，先检查矛盾，再统计主元个数。设未知数有 $n$ 个，主元有 $r$ 个：

| 消元后的情况 | 结论 | 原因 |
| --- | --- | --- |
| 出现 $[0,0,\ldots,0\mid b]$，且 $b\ne 0$ | 无解 | 这一行要求 $0=b$，产生矛盾 |
| 没有矛盾，且 $r=n$ | 唯一解 | 每个未知数都能通过回代确定 |
| 没有矛盾，且 $r<n$ | 无穷多解 | 有 $n-r$ 个自由变量 |

全零行表示 $0=0$，只是冗余方程，**不代表无解**。非主元列对应的变量可以作为自由变量，给它们赋值后，再回代求主元变量。例如 $x_1+x_2=3$ 可以写成 $x_2=t,\ x_1=3-t$，其中 $t$ 为任意实数。

## 实现与复杂度

下面的代码处理 $m$ 个方程、$n$ 个未知数，输入矩阵有 $m$ 行、$n+1$ 列，最后一列为常数项。返回值 `0` 表示无解，`1` 表示唯一解，`2` 表示无穷多解；只有唯一解时才填写 `x`。

```cpp
#include <algorithm>
#include <cmath>
#include <vector>
using namespace std;

// a 按值传入，保留调用方的原始矩阵。
int gauss(vector<vector<double>> a, int n, vector<double>& x) {
    const double EPS = 1e-9;
    int m = (int)a.size(), r = 0;
    vector<int> pivot;
    x.clear();

    for (int c = 0; c < n && r < m; ++c) {
        int p = r;
        for (int i = r + 1; i < m; ++i)
            if (abs(a[i][c]) > abs(a[p][c])) p = i;
        if (abs(a[p][c]) < EPS) continue;
        swap(a[p], a[r]);

        for (int i = r + 1; i < m; ++i) {
            if (abs(a[i][c]) < EPS) continue;
            double t = a[i][c] / a[r][c];
            a[i][c] = 0;
            for (int j = c + 1; j <= n; ++j)
                a[i][j] -= t * a[r][j];
        }
        pivot.push_back(c);
        ++r;
    }

    for (int i = r; i < m; ++i)
        if (abs(a[i][n]) >= EPS) return 0;
    if (r < n) return 2;

    x.assign(n, 0);
    for (int i = r - 1; i >= 0; --i) {
        int c = pivot[i];
        double value = a[i][n];
        for (int j = c + 1; j < n; ++j)
            value -= a[i][j] * x[j];
        x[c] = value / a[i][c];
    }
    return 1;
}
```

对于 $n$ 个方程、$n$ 个未知数，时间复杂度为 $O(n^3)$，矩阵占用 $O(n^2)$ 空间；对于一般的 $m\times n$ 系数矩阵，消元时间为 $O(mn\min(m,n))$。

浮点数判断零时使用误差阈值，不能直接用 `== 0`。`1e-9` 是常见示例值，实际需要结合数据规模和精度要求调整；绝对值选主元也不能保证所有病态方程组都准确。对模意义下的方程组，除法需要改为合法的模逆元，不能直接套用这份实数模板。

这里采用的是“只消去主元下方元素，再回代”的高斯消元；如果把主元上方的元素也消去，得到更简洁的矩阵形式，则是常见的高斯–约旦消元。

## 应用：由球面上的点求球心

##### P4035 [JSOI2008] 球形空间产生器

有一个球形空间产生器能够在 $n$ 维空间中产生一个坚硬的球体。现在，你被困在了这个 $n$ 维球体中，你只知道球面上 $n+1$ 个点的坐标，你需要以最快的速度确定这个 $n$ 维球体的球心坐标，以便于摧毁这个球形空间产生器。

$N \le 10$

<CollapsibleComponent title="做法">
$n+1$个二次方程之间两两相减可以得到$n$个线性方程。

$a[n+1][n]$的一个数组，
其中第$i$个点的第$j$维的坐标为$a[i][j]$

设球心的坐标为$x[1 \ldots n]$

球心到每个点的距离都等于半径 $d$，因此对于第 $i$ 个点有：

$$
\sum_{j=1}^{n}(x_j-a_{i,j})^2=d^2.
$$

固定第 $n+1$ 个点作为基准。用第 $i$ 个方程减去基准方程，$x_j^2$ 和 $d^2$ 都会被消掉，整理后得到：

$$
2\sum_{j=1}^{n}(a_{n+1,j}-a_{i,j})x_j
=\sum_{j=1}^{n}(a_{n+1,j}^2-a_{i,j}^2),
\qquad 1\le i\le n.
$$

于是构造一个 $n$ 行、$n+1$ 列的增广矩阵：第 $i$ 行第 $j$ 列填 $2(a_{n+1,j}-a_{i,j})$，最后一列填右侧的平方和之差。高斯消元求出的 $x_1,\ldots,x_n$ 就是球心坐标，无需先求半径。

例如二维中，三个点为 $(0,0)$、$(2,0)$、$(0,2)$。选择 $(0,2)$ 作为基准，相减后得到 $4x_2=4$ 和 $-4x_1+4x_2=0$，所以圆心为 $(1,1)$。

构造矩阵需要 $O(n^2)$ 时间，求解需要 $O(n^3)$ 时间。只有当这些点提供了足够多的独立约束时，才能唯一确定球心；例如二维中三个点共线，就不能直接假定得到唯一解。
</CollapsibleComponent>

##### 小黑

有一由 $n$ 个节点和 $m$ 条边构成的无向图，保证图没有自环或重边。

在“夜”中，Kuro 需要将节点划分为两个集合。此后，所有两端点所属集合不同的边会消失。

我们称一个节点满足条件，当且仅当操作后其度数是偶数。Kuro 希望构造出一种方案，使得满足条件的节点数量最大化。

$n \le 2000, 0 \le m \le n(n-1)/2$

###### 输入格式

第 1 行输入 2 个正整数 $n, m$，含义见上。

接下来 $m$ 行，每行输入 2 个正整数 $u, v$，表示一条边。

###### 输出格式

第 1 行输出 1 个非负整数，表示你构造出的方案中满足条件的节点数量。

接下来 1 行输出一个长度为 $n$ 的 01 字符串，表示你构造出的方案。第 $i$ 个字符为 $1$（$0$）表示节点 $i$ 被划分到第 1 个（第 2 个）集合中。

<CollapsibleComponent title="做法">

如果写了暴力的话，很容易注意到答案总是为 $n$。

先暂时不证明这个结论。注意到我们只关心节点度数的奇偶性，令 $d_i$ 表示初始节点 $i$ 的度数的奇偶性。对于一个划分方案 $s_i$，容易注意到目标即为对任意 $i$，有 

$$
\sum_{(i,j) \in E} (s_i + s_j) \equiv d_i \pmod{2}.
$$

使用高斯消元求解出任意一组解即可。时间复杂度 $O(n^3)$。

###### 结论的证明

假设该方程组无解，则由 $\mathbb{F}_2$ 上的线性方程组的性质，必存在一个节点子集 $S$，使得将 $S$ 中对应的方程相加后，左侧所有变量的系数抵消为 0，且右侧常数项之和为 1。

考虑左侧变量 $s_u$ 的系数：对于任意 $u \in S$，其在自身方程中系数为 $d_u$，在 $S$ 内部邻居的方程中共出现 $|N(u) \cap S|$ 次。为满足左侧完全抵消，对 $\forall u \in S$ 必有 $d_u = |N(u) \cap S| \pmod{2}$。

再考察右侧常数项之和 $\sum_{u \in S} d_u$，将上式代入可得：

$$
\sum_{u \in S} d_u = \sum_{u \in S} |N(u) \cap S| \pmod{2}
$$

注意到 $\sum_{u \in S} |N(u) \cap S|$ 即为导出子图 $G[S]$ 中所有节点的度数之和。由于任意图的总度数恒为偶数，故 $\sum_{u \in S} d_u \equiv 0 \pmod{2}$。这与假设中右侧常数项之和为奇数相矛盾。

故假设不成立，该方程组恒有解，最大满足点数恒为 $n$。证明完毕。
</CollapsibleComponent>
