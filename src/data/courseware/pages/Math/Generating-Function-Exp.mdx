# 指数生成函数（EGF）
一般生成函数的相乘，对应的组合意义是，把物品集合按任意顺序合并。

而有时候会遇到固定顺序的物品合并问题，这个时候就要忽略内部的排列。

比如把两个长度为$n$和$m$序列合并成一个，但是要求原先序列内部的前后顺序不变。

方案数是$\binom{n+m}{n}=\frac{(n+m)!}{n!m!}$，这样就多了一个阶层项，我们就需要引入指数生成函数。

## 定义

数列$a$的指数生成函数定义为：

$$A(x)=\sum_{i \ge 0} \frac{A_i}{i!}x^i$$

为什么叫做指数生成函数，因为$A(x)$恰好是$e^x$的泰勒展开。

一般写代码时，我们会存储$\frac{A_i}{i!}$，等到输出时，才把$i!$乘上去。

## 常用 EGF

- $e^x=\sum_{i \ge 0}\frac{x^i}{i!}$
- $\frac{e^x+e^{-x}}{2}=\sum_{i \bmod 2 = 0}\frac{x^i}{i!}$
- $\frac{e^x-e^{-x}}{2}=\sum_{i \bmod 2 = 1}\frac{x^i}{i!}$
- $-\ln(1-x) = \sum_{i \ge 1} \frac{1}{i}x^i$

## 集合的 EGF

- 考虑用对象$A$中的一些元素，组成一个新的集合，则生成函数为$\sum_{i \ge 0}\frac{A^i}{i!} = e^A$

### 举例
- 一个置换是由若干个轮换拼接而成
- 用生成函数来说明：轮换的生成函数$f$为$[x^n]f(x) = \frac{(n-1)!}{n!}=\frac{1}{n}$，所以$f(x) = -\ln(1-x)$
- 置换的生成函数就是$g(x),e^{f(x)} = e^{-\ln(1-x)} = \frac{1}{1-x}$，这样$[x^n]g(x)=1$，所以$n$个数的置换个数就是$n!$
 
### 举例

给定一个整数集合$S$，问有多少长度为$n$的排列，满足每个轮换的长度都属于集合$S$

令$f(x) = \sum_{i \in S} \frac{1}{i}x^i$，答案就为$[x^n]e^{f(x)}$

### 集合的 EGF
求$n$个点的有标号无向连通图数量

用$G(x)$表示无向图数量的EGF，$C(x)$表示无向连通图数量的EGF，则序列

$$G(x)=\sum_{i \ge 0} \frac{2^{\binom{i}{2}}}{i!} x^i$$

$$G(x) = e^{C(x)}$$

$$C(x) = \ln(G(x))$$
