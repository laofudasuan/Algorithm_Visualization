# 多项式的定义

多项式是数学中的重要概念，在数学中，多项式是一种由系数和指数组成的表达式，例如：

$$
f(x) = a_nx^n + a_{n-1}x^{n-1} + a_{n-2}x^{n-2} + \cdots + a_1x + a_0
$$

其中，$a_n, a_{n-1}, \cdots, a_1, a_0$ 是多项式中的系数，$x$ 是多项式中的变量，$n$ 是多项式中的指数。

# 多项式基础运算

## 多项式加减

直接对应次数系数相加减。

令$f(x)=\sum_{i=0}^{n}a_ix^i$，$g(x)=\sum_{i=0}^{n}b_ix^i$。

则：$(f \pm g)(x)=\sum_{i=0}^{n}(a_i \pm b_i)x^i$。

## 多项式乘法

$(f \times g)(x)=\sum_{i=0}^{n} x^i\sum_{j=0}^{i}a_jb_{i-j}$。

暴力计算的复杂度是平方的。如果想做到更快需要学习快速傅里叶变换(FFT)算法

# 多项式的表示方法

$f(x) = a_nx^n + a_{n-1}x^{n-1} + a_{n-2}x^{n-2} + \cdots + a_1x + a_0$被称为系数表示法

除此之外，还有其他表示方法，如：

- 点值表示法：给定$n+1$个点$(x_i, y_i)$，$i=0,1,\cdots,n$，通过这$n+1$个点可以唯一确定一个$n$次多项式

# 为什么要研究多项式

多项式可以用来描述一个函数的复杂度，需要用多复杂的变量表示。

次数为$0$是最简单的情况，多项式退化成一个变量。

次数为$1$，多项式是一个一次函数，用两个变量表示。

次数为$k$，多项式需要用$k+1$个变量表示。

所以，很多时候，我们能把一些简单的函数用低次多项式来表示，从而进行简化。

比如，一个DP题的状态有$3$维$f[x][y][z]$，但是我们发现$f$是关于$z$的一次函数，这样就只需要存储$k[x][y],b[x][y]$，起到简化的效果。
