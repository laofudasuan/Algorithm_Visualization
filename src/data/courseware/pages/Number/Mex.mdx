# Mex问题

##### nfls p35231

定义一个可重集 $b$ 的权值为：

- 考虑其所有子集和 $S = \left\{\sum_{i \in b'} i : b' \subseteq b\right\}$。
- $b$ 的权值为 $\text{mex}(S)$，即 $S$ 中最小未出现的非负整数。

给定长度为 $n$ 的整数序列 $a$，你需要输出每个子区间视为可重集后的权值之和。

因为特别大的数会让 7sRef 世界崩溃，你只需要输出答案对 $998244353$ 取模后的结果即可。

$n \le 10^6, a_i \le 10^9$

<CollapsibleComponent title="做法">
- 初始化当前 mex 为 $1$。
- 每次取完 $<$ 当前 mex 的值。
- 如果取到了更多的数，则重新更新 mex 为取出元素的和 $+1$。
- 否则返回当前 mex。

注意到每轮迭代会让 mex 至少翻倍，因此迭代轮次上界为 $\log a$。

使用合适的数据结构可以优化到 $O(n^2 \log a)$。

使用扫描线快速计算固定左端点，所有右端点的权值和。

加入一个元素时，我们注意到可能产生几种变化：

- 加入的元素不超过 mex，但不会产生新一轮迭代。
- 加入的元素超过 mex，无事发生。
- 加入的元素不超过 mex，且会产生新一轮迭代。

前两种变换都可以简单维护，考虑第三种变换的情况。

注意到每轮迭代会让 mex 至少翻倍，因此对于同一左端点，迭代轮次上界为 $\log a$。

时间复杂度 $O(n^2 + n \log a \log n)$。

在算法三中，既然我们可以快速处理前两类贡献，就可以尝试找下一个第三类贡献。

我们等价于要维护这样的询问：

当前的和为 $X$，取不到的最小值为 $Y$，至少要取几个数才能满足如下条件……

- 将所有 $< X$ 的数加到 $X$，
- 将所有 $\ge X$ 的数都和 $Y$ 取 $\min$，
- 最后有 $X' \ge Y'$。

二分后等价于求区间 $\min$ 和区间 $\le k$ 的数的和，在值域不大时可以开桶维护。

需要仔细地讨论中间快速跳过的部分的贡献。

时间复杂度 $O(na \log n \log a)$ 或 $O(na \log a)$。

显然可以使用主席树维护上述过程。

时间复杂度根据是否是否使用离散化可以为 $O(n \log^2 n \log a)$ 或 $O(n \log^2 a \log n)$，结合特殊性质期望得分 68。

但三只 log 看起来跑的也太慢了！可以不用主席树吗？

如果不用主席树，最该优化的应该是值域的 log，所以考虑对值域离线。

注意到每个左端点的处理过程中，我们回答较小的询问可以获取下一个更大的询问。

因此可以用一个堆进行半在线处理，每次找到最小的询问即可。

此时确定性的值域上可以线段树二分做到单次 $O(\log n)$。

时间复杂度 $O(n \log n \log a)$。

似乎数据结构的尽头就是这里了！

倍增的特性使我们考虑值域分块来代替复杂的查找范围。

我们考虑当前 mex 在 $[2^k, 2^{k+1})$ 的范围，则我们将 $Y$ 和 $2^{k+1}$ 取 $\min$……

- 新增了 $\log a$ 个虚拟事件，总事件数量仍然是 $\log a$ 级别。
- 如果我们获取了任意 $\ge 2^k$ 的数，则必定触发下一个事件。
- 如果我们获取了任意 $< 2^k$ 的数，则它一定会加入集合。

扫右端点，同时维护所有左端点，根据 $k$ 分类。

不难发现，如果 $A$ 包含了 $B$，显然 $A$ 的权值不小于 $B$，因此按照下标分段即可。

每次只需暴力考虑每段的第一个元素能否触发下一个事件。具体地，我们可以从 $\text{mex} \ge 2^k$ 推出区间可以取遍每个 $< 2^k$ 的数，而只需任何一个 $\ge 2^k$ 的数就可以让其 $\text{mex}$ 达到 $2^{k+1}$。

只需维护后缀 $< 2^k$ 的所有数之和，后缀 $[2^k, 2^{k+1})$ 的最小值，时间复杂度 $O(n \log n \log a)$，代码非常好写。

最后发现对于同一个 $k$，询问区间的 $l, r$ 都是单调的，使用单调队列维护每个 $k$ 就可以做到 $O(n \log a)$，期望得分 $\mathbf{100}$。

## 所有子区间Mex问题

一个序列所有区间的Mex可以被刻画为$O(n)$个矩形，证明：

我们称满足 $\text{mex}(l,r) = x$ 的区间为 $x$-mex 区间。

对于一个 $x$-mex 区间 $[l,r]$，如果不存在另一个 $x$-mex 区间 $[l',r'] \subset [l,r]$，则称 $[l,r]$ 为「极小的 mex 区间」。

- 则有结论：极小的 mex 区间只有 $\Theta(n)$ 个；具体的，一个上界是 $2n$。
- 证明：对于一个满足条件的「极小的 mex 区间」$[l,r]$ 显然满足 $a_l \neq a_r$，否则删任意一个不影响答案，不妨假设 $a_l > a_r$，则 $a_r$ 和 $a_l$ 的加入先后影响了 $\operatorname{mex}(l,r)$ 的答案，则可以得到的是：$\operatorname{mex}(l + 1,r - 1) = a_r$，由于当 $l$ 固定时 $\operatorname{mex}$ 单调不降，且有多个满足他条件的 $r$ 只取最左边那个，所以对于任意的 $l$ 只有一个 $r$ 满足条件；同理，对于 $a_l < a_r$ 的情况，对于每个 $r$ 也至多只有一个 $l$ 满足条件，故最多只有 $2n$ 个「极小的 mex 区间」。

##### P9970 套娃
我们定义一个集合的**mex**是最小的不在 $S$ 中的非负整数。

给定一个序列 $a_1, \ldots, a_n$，对于每个 $1 \leq k \leq n$，我们按照如下方式定义 $b_k$：

- 对于 $a$ 的所有长为 $k$ 的子区间，求出这个子区间构成的数集的 mex。
- 对于求出的所有 mex，求出这个数集自己的 mex，记为 $b_k$。

请你求出序列 $b$。

<CollapsibleComponent title="做法">
先考虑：如何求快速求很多区间的Mex？

扫描线，从小到大枚举询问右端点，用线段树维护数组$last[x=0 \sim n]$表示$x$最后一次出现的位置。询问就是查询$last$数组第一个$<L$的位置

然后再考虑如何刻画所有区间的Mex，对于某一个$R$，所有左端点的Mex会本分成若干个区间（即$last$数组的单调栈），每当$R+1$时，最多只会增加一个区间。

因此，可以用$O(n)$个矩形刻画一个序列所有区间的Mex。

对于原问题，可以按照斜$45$度角做扫描线，需要维护一棵线段树，支持单点插入删除、查询全局Mex。用权值线段树即可。
</CollapsibleComponent>

##### CF1870E Another MEX Problem

$a_i \le n \le 5000$

<CollapsibleComponent title="做法">
序列划分问题，容易想到DP

但是异或值是不能用最大值DP的，因此只能考虑把所有可能的异或值都记录起来。

用$f[i][j]$表示考虑了$a_{1 \ldots i}$，能否让异或和成为$j$

朴素的DP，转移还需要枚举最后一段怎么选：

$$
f[i][j] = f[i-1][j] | \text{OR}_{k<i} f[k][j \text{ Xor }Mex(a_{k+1 \ldots i})]
$$

但根据上一题的经验，一个序列所有区间的Mex可以被刻画为$O(n)$个矩形，**而每个矩形显然只需要考虑最短的区间**，因此转移均摊是$O(1)$的
