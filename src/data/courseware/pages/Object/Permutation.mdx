##### arc220_b Incomplete Shuffle

给定一个正整数 $N$，以及两个长度为 $N$ 的整数序列：
$A = (A_1, A_2, \dots, A_N)$ 和 $B = (B_1, B_2, \dots, B_N)$。

你需要对序列 $A$ 执行 $N-1$ 次操作。第 $i$ 次操作（$1 \le i \le N-1$）的规则如下：
- 选择一个满足 $i < j \le N$ 的整数 $j$，交换 $A_i$ 和 $A_j$ 的值。

求执行完 $N-1$ 次操作后，满足 $A_k = B_k$ 的下标 $k$（$1 \le k \le N$）的**最大可能数量**。

共有 $T$ 组测试用例，请你分别求解。

- $1 \le T \le 10^5$
- $2 \le N \le 3 \times 10^5$
- $1 \le A_i, B_i \le N$
- 所有测试用例的 $N$ 之和不超过 $3 \times 10^5$
- 所有输入值均为整数
