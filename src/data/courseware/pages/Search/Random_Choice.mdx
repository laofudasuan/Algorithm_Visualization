##### ABC422E Colinear

二维平面上有 $ N $ 个点，$ N $ 是奇数。第 $ i $ 个点的坐标为 $ (x_i, y_i) $，所有点的坐标都是不同的。

判断是否存在一条直线经过超过 $ N $ 个点中的一半，如果存在，输出这条直线。

对于满足约束条件的任何输入，如果存在满足条件的直线，它可以用整数 $ a $、$ b $、$ c $ 表示为 $ ax + by + c = 0 $，其中 $ -10^{18} \leq a, b, c \leq 10^{18} $（且 $ (a, b, c) \neq (0, 0, 0) $）。输出这些 $ a $、$ b $、$ c $。

##### ABC272G Yet Another mod M

给定一个长度为 $N$ 的正整数序列 $A=(A_1,A_2,\dots,A_N)$，其中 $A$ 的所有元素互不相同。

你可以选择一个满足 $3 \leq M \leq 10^9$ 的正整数 $M$，并进行以下操作一次：

对于每个满足 $1 \leq i \leq N$ 的整数 $i$，将 $A_i$ 替换为 $A_i \bmod M$。

你能否通过巧妙地选择 $M$，使得操作后的 $A$ 满足以下条件？如果可以，请给出一个满足条件的 $M$。

存在某个整数 $x$，使得 $x$ 在 $A$ 中占据了多数。

这里，“$x$ 在 $A$ 中占据多数”指的是，满足 $A_i = x$ 的 $i$ 的个数严格多于满足 $A_i \neq x$ 的 $i$ 的个数。

$$N \le 5000, 1 \le A_i \le 10^9$$

<CollapsibleComponent title="做法">
    存在某个$x$出现次数超过一半，那么我们随机一个数让它变为$x$，正确率$\ge 50\%$
</CollapsibleComponent>
