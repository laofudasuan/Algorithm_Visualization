# 搜索算法

## 算法介绍

在我们遇到的一些问题当中，有些问题不能够确切的建立数学模型，或即便有数学模型但该模型的准确方法也不一定能运用现成算法

在要求枚举方案时，常常会遇到这一类问题

解决这一类问题，我们一般采用搜索的方法解决，即从初始状态出发，运用题目所给出的条件和规则扩展所有可能情况，从中找出满足题意要求的解答
    
## 搜索问题框架
    
一个搜索问题 包含:
    
- $S:$ 状态空间
- $S_{start}:$ 初始态
- Action$(s):$ 可行动作
- Succ$(s,a):$ 后继
- Cost$(s,a):$ 动作费用
- IsEnd$(s):$ 目标函数
    
一个解是一个从初始态出发到达一个终止态的可行动作序列
    
## 基本搜索方法
   
- DFS（深度优先搜索）
- BFS（广度优先搜索）
    
### 八数码问题

八数码难题：在$3 \times 3$的棋盘上，摆有八个棋子，每个棋子上标有$1$至$8$的某一数字

棋盘中留有一个空格（空格用$0$表示），空格周围的棋子可以移到空格中

给出一种初始布局（初始状态）和目标面局（目标状态），找到一种最少步骤的移动方法，实现从初始布局到目标布局的转变

以上图为例，从初始状态到目标状态的最少步数方案如下：

将8移到空位，将7移到空位，将4移到空位，将5移到空位，将6移到空位，将3移到空位，将2移到空位，将1移到空位
        
由于题目要找到的解是达到目标最少步骤
        
因此解题的方法为：从初始状态出发，先把移动一步后的布局全部找到，检查是否达到目标布局，如果没有，再从这些移动一步的布局出发，找到移动两步后的所有布局，再判断是否有达到目标的

如此继续，一直达到目标状态为止，输出结果

由于是按移动步数从少到多产生新布局的，所以找到的第一个目标一定是移动步数最少的一个，也就是最优解

    
## 深搜和广搜的对比

- 深搜每个时候只需要开一个状态，广搜需要开一个队列，存很多个状态
- 当状态量为无穷，求最小步数时，只能选择广搜
        
## $A^*$ 搜索

- 求状态图上一个点到另一个点的最短路
- 令$g(x)$表示从起点出发到达$x$的已走距离
- 用一个启发式函数$h(x)=x$表示到达终点的估测距离
- 令$f(x)$表示$x$这个方案的估价：$f(x)=g(x)+h(x)$
- 步骤：
  - 把起点放入优先队列
  - 从优先队列中取出$f(x)$最小的元素
  - 如果$x$为终点，直接结束
  - 否则枚举$x$的所有出边$(x \to y)$，把$y$放入优先队列中，回到步骤2
  - 保存路径，从终点开始，沿着父节点移动至起点，即为路径

## 启发式函数
    
一个启发式函数 $h$ 是 **admissible(Optimistic)** 当且仅当 :

$$
0 \le h(n) \le h^*(n)
$$
        
其中 $h^*(n)$ 是到达终点的真实距离
        
Consistency:
        
$$
h(A)-h(C) \le w_{a,c}
$$

## ID$\text{A}^*$

### MinMax Search
    
| Max-Value | Min-Value |
|-----------|-----------|
| <div className="font-mono text-sm leading-6 whitespace-pre-wrap">function Max-Value(state):<br/>    v ← −∞<br/>    for each successor of state:<br/>        v ← max(v, Min-Value(successor))<br/>    return v</div> | <div className="font-mono text-sm leading-6 whitespace-pre-wrap">function Min-Value(state):<br/>    v ← +∞<br/>    for each successor of state:<br/>        v ← min(v, Max-Value(successor))<br/>    return v</div> |

时间复杂度$O(b^m)$

空间复杂度$O(m)$
    
## Alpha-Beta 剪枝
    
| Max-Value(state, α, β) | Min-Value(state, α, β) |
|------------------------|------------------------|
| <div className="font-mono text-sm leading-6 whitespace-pre-wrap">function Max-Value(state, α, β):<br/>    v ← −∞<br/>    for each successor of state:<br/>        v ← max(v, Min-Value(successor, α, β))<br/>        if v ≥ β: return v<br/>        α ← max(α, v)<br/>    return v</div> | <div className="font-mono text-sm leading-6 whitespace-pre-wrap">function Min-Value(state, α, β):<br/>    v ← +∞<br/>    for each successor of state:<br/>        v ← min(v, Max-Value(successor, α, β))<br/>        if v ≤ α: return v<br/>        β ← min(β, v)<br/>    return v</div> |
        
最优时间复杂度：$O(b^{m/2})$
