# 笛卡尔树

##### P11392 [JOI Open 2019] 三级跳 / Triple Jump

##### Singpore NOI 2024 Final E. Field

##### P8492 无线电信号塔

给定数组$a_{1 \ldots n}$，对于任意两个点$i<j$，$i$和$j$有边当且仅当存在$i<k<j$使得$\max(a_i,a_j) \le a_k-\delta$

有$q$次询问，每次给定$ql,qr,\delta$，求仅考虑$[ql,qr]$的所有点，最大团是多大

$n,q \le 10^5$

##### P8492 无线电信号塔
首先转化条件：把$\max(a_i,a_j) \le a_k-d$变成$a_i \le a_k-d,a_j \le a_k-d$两个条件

这样可以发现，对于任意三个点$x<y<z$，如果$x,y$有边并且$y,z$有边，则$x,z$肯定也有边

也就是说，一个子集能不能构成团只需要看排序以后相邻两个点有没有边

<CollapsibleComponent title="做法" >

对于每个点$i$，求出$L_i = i$左边第一个$\ge a_i+d$的位置，$R_i = i$右边第一个$\ge a_i+d$的位置，这样，我们选出来的团需要满足，如果选了$i$，则左侧只能选$<L_i$的点，右侧只能选$>R_i$的点

如果把$[L_i,R_i]$当成一个区间，就相当于是要求选出来的点，每个点的区间不能包含其它点

同时注意到这些区间只有包含和相离，没有交叉关系

显然对于有包含关系的区间，取小的那个一定更优

因此其实就是要统计有多少个区间，没有包含其它区间。而对应的条件可以转化为$\forall j \in [L_i,R_i], a_j<a_i$

但问题是每次询问的$d$不一样，怎么办呢？

可以先预处理出$a_i$两侧第一个比$a_i$大的位置，这样我们可以推出当$d \le $某个值时，区间$i$没有包含其它区间

不过还漏了一种情况，就是对于一个询问，可能区间内存在$a_j>a_i$，但是这个$j$在询问区间外，所以其实是可以选$i$的

仔细想一想发现这样的$i$在左右边界最多只会漏掉一个，因此可以特殊处理
