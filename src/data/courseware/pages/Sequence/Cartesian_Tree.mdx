# 笛卡尔树


##### T829681 B. 排列翻转

给定一个长度为 $n$ 的排列 $a_1,a_2,\dots,a_n$。为了方便描述边界情况，定义 $a_0=0$ 且 $a_{n+1}=0$。

你可以进行任意次操作，也可以一次都不操作。每次操作：

1. 选择一个区间 $[l,r]$，其中 $1\le l\le r\le n$。
2. 要求区间中的每个元素都严格大于区间两侧紧邻元素中的较大者，即对所有 $i\in[l,r]$ 都满足 $a_i>\max(a_{l-1},a_{r+1})$。
3. 将区间 $[l,r]$ 内的元素顺序完全翻转。

请你求出经过任意次合法操作后，$\sum_{i=1}^n i\times a_i$ 能取得的最大值和最小值。

$1\le n\le 2\times10^5$。
