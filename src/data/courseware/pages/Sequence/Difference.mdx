# 任务3：进度（progression）

Damian 正在制作一款电子游戏！  
游戏共有 $N$ 个关卡，第 $i$ 关的初始难度为 $D_i$。  
采用最先进的游戏设计，这款游戏既可以**正向游玩**，也可以**反向游玩**。  
当然，让玩家感受到“进度感”非常重要——难度应该**持续上升**。  
因此，Damian 会进行一系列操作。

| 类型 | 格式 | 说明 |
|---|---|---|
| **补丁操作** | `1 L R S C` | 对所有满足 $L \le i \le R$ 的关卡 $i$，将其难度 $D_i$ **增加** $S + (i - L) \cdot C$。 |
| **重写操作** | `2 L R S C` | 对所有满足 $L \le i \le R$ 的关卡 $i$，将其难度 $D_i$ **直接设为** $S + (i - L) \cdot C$。 |

一个连续的关卡子序列 $a \ldots b$（$1 \le a \le b \le N$）构成**可玩片段**，当且仅当存在某个整数 $k$（可正、可负、可为零），使得对所有 $a \le i < b$ 都有$D_{i+1} - D_i = k.$

$N,Q \le 3 \times 10^5$
