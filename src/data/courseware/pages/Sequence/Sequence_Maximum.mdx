##### P8492 无线电信号塔
首先转化条件：把$\max(a_i,a_j) \le a_k-d$变成$a_i \le a_k-d,a_j \le a_k-d$两个条件

这样可以发现，对于任意三个点$x<y<z$，如果$x,y$有边并且$y,z$有边，则$x,z$肯定也有边

也就是说，一个子集能不能构成团只需要看排序以后相邻两个点有没有边

<CollapsibleComponent title="做法" >

对于每个点$i$，求出$L_i = i$左边第一个$\ge a_i+d$的位置，$R_i = i$右边第一个$\ge a_i+d$的位置，这样，我们选出来的团需要满足，如果选了$i$，则左侧只能选$<L_i$的点，右侧只能选$>R_i$的点

如果把$[L_i,R_i]$当成一个区间，就相当于是要求选出来的点，每个点的区间不能包含其它点

同时注意到这些区间只有包含和相离，没有交叉关系

显然对于有包含关系的区间，取小的那个一定更优

因此其实就是要统计有多少个区间，没有包含其它区间。而对应的条件可以转化为$\forall j \in [L_i,R_i], a_j<a_i$

但问题是每次询问的$d$不一样，怎么办呢？

可以先预处理出$a_i$两侧第一个比$a_i$大的位置，这样我们可以推出当$d \le $某个值时，区间$i$没有包含其它区间

不过还漏了一种情况，就是对于一个询问，可能区间内存在$a_j>a_i$，但是这个$j$在询问区间外，所以其实是可以选$i$的

仔细想一想发现这样的$i$在左右边界最多只会漏掉一个，因此可以特殊处理
</CollapsibleComponent>

##### P15582 [KTSC 2026] 平衡序列 / Balanced Sequence

**平衡序列**的定义如下：

- 长度为 $1$ 的序列是平衡序列。
- 长 $2k+1$ 的序列 $S=[S_0,\ldots,S_{2k}]$ 是平衡序列，当且仅当：
    - $[S_0,S_1,\ldots,S_{k-1}]$ 是平衡序列；
    - $[S_{k+1},S_{k+2},\ldots,S_{2k}]$ 是平衡序列；
    - $S_k$ 是 $S$ 中**唯一的**最大元素。

给定长度为 $N$ 的序列 $A$。定义 $A[i\ldots j]=[A_i,A_{i+1},\ldots,A_j]$。例如，若 $A=[3,5,7,2,9]$，则 $A[1\ldots 3]=[5,7,2]$，$A[4\ldots 4]=[9]$。

$Q$ 次操作，每次操作形如单点修改。操作是累积的。在初始状态和每次操作后，求出满足如下条件的 $(i,j)$ 对数：
- $0\le i\le j\le N-1$；
- $A[i\ldots j]$ 是平衡序列。

- $1\le N\le 10^5$；
- $0\le Q\le 10^5$；
- $1\le A[i]\le 10^9$；
- $0\le p\le N-1$，$1\le v\le 10^9$。

<CollapsibleComponent title="做法" > 
首先注意到，平衡序列的长度都为$2^k-1$的形式

这样可以得到一个单次询问$O(n \log n)$的做法：

$dp[i][j]$表示是否可以以$i$为中心，长度为$2^j-1$的区间是否是平衡序列

令$ls = i - 2^{j-1}, rs = i + 2^{j-1}$

$dp[i][j] = dp[ls][j] \& dp[rs][j] \& S[i]>S[ls] \& S[i]>S[rs]$

然后考虑如何修改

注意到一个核心性质：对于某一个$j$，所有满足$dp[i][j]=true$的$i$的距离都$> 2^{j-1}$

这样修改一个$p$时，对于每个$j$，最多影响到两个和$S[p]$有关的并且$dp[i][j]=true$的$i$
</CollapsibleComponent>
