# 序列前缀和

##### Qoj200 NOI 2019 Final B. Lasers

熊猫先生知道猫喜欢激光玩具，决定给拉尔夫猫买一个激光玩具。熊猫先生买的激光玩具有L个均匀分布的激光器，位于玩具顶部，指向下方。第1个激光器距离左边缘0.5单位，第L个激光器距离右边缘0.5单位。相邻激光器之间的距离为1单位。

玩具中有R行滑动墙，每行包含一组互不重叠的墙。具体来说，每行包含若干堵墙，这些墙的总长度不超过L。这些墙可以在同一行上滑动到任意位置，只要它们在该行上的相对位置保持不变且互不重叠。一堵宽度为x单位（x为正整数）的墙会恰好挡住x个连续的激光器。

拉尔夫猫作为一只好奇的猫，想知道：在他的玩具的L个激光器中，有多少个激光器会被至少一堵墙挡住，**在所有可能的配置中都是如此**？

- $1 \leq R \leq 5 \times 10^5$
- $1 \leq L \leq 10^9$
- $1 \leq \sum X \leq 5 \times 10^5$
- $1 \leq \text{宽度} \leq L$（每行中的每堵墙）
