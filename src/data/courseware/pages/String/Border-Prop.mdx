# Border性质

## Border的等差数列结构

### 引入

假设有一个长度为$15$的字符串，存在一个border，长度为$12$，能推出还有哪些Border呢？

长度为$12$的Border能推出一个长度为$3$的周期，因此，$3,6,9$也是Border

### 形式化

如果一个长度为$n$串存在某个长度超过一半的border$k$，那么可以推出一个长度为$n-k$的周期，因此可以推导出一些Border，形成一个以$n-k$为公差的等差数列

结论：一个串的所有Border可以划分为不超过$\log n$个等差数列

##### P5829 【模板】失配树

给定一个字符串 $s$，定义它的 **$k$ 前缀** $\mathit{pre}_k$ 为字符串 $s_{1\dots k}$，**$k$ 后缀** $\mathit{suf}_k$ 为字符串 $s_{|s|-k+1\dots |s|}$，其中 $1 \le k \le |s|$。

定义 $\bold{Border}(s)$ 为**对于 $i \in [1, |s|)$，满足 $\mathit{pre}_i = \mathit{suf}_i$** 的字符串 $\mathit{pre}_i$ 的集合。$\bold{Border}(s)$ 中的每个元素都称之为字符串 $s$ 的 $\operatorname{border}$。

有 $m$ 组询问，每组询问给定 $p,q$，求 $s$ 的 **$\boldsymbol{p}$ 前缀** 和 **$\boldsymbol{q}$ 前缀** 的 **最长公共 $\operatorname{border}$**  的长度。

对于 $100\%$ 的数据，$1\leq p,q \le |s|\leq 10^6$，$1 \leq m \leq 10^5$，$s_i \in [\texttt{a}, \texttt{z}]$。

<CollapsibleComponent title="做法"> 
```C++
x = next[x], y = next[y];
while(x != y){
    if(x < y) swap(x, y);
    if (next[x] > x/2) {
        int d = x - next[x];
        if(y % d == x % d) x = y;
        else x = x - (x/2/d) * d;
    } else x = next[x];
}
```
</CollapsibleComponent>

##### CF932G Palindrome Partition

给一个字符串$S$，你需要把它划分为偶数段$S=s_1+s_2+\ldots+s_k$

使得$s_1=s_k,s_2=s_{k-1},\ldots$

求方案数

<CollapsibleComponent title="做法">
假设字符串为$S[1 \ldots n]$

观察：分成偶数段：第一段等于最后一段、第二段等于倒数第二段

似乎有点像回文！

考虑把$S$重新排列成$S'=S[1]S[n]S[2]S[n-1]\ldots S[n/2]S[n/2+1]$

这样一来，我们发现$S$的一组合法划分，相当于把$S'$划分成很多个长度为偶数的回文串

这样可以得到一个平方DP

$$
dp[i] = \sum_{S[j+1 \sim i]\text{为回文串}} dp[j]
$$

这样，在回文自动机上DP就可以了


</CollapsibleComponent>

##### loj6681 yww与树上的回文串
给一棵树，每条边有一个字符

询问树上有多少条路径$x \to y$满足，路径上所有边组成的字符串为回文串

$n \le 50000$，字符集大小为$2$

<CollapsibleComponent title="做法">

树上路径问题，考虑点分治

每一层，以重心为根建立AC自动机

对于一条过重心的路径，枚举长的那一侧，问题变成了：对于每一个点，令深度为$l$，如果存在一个长度为$d$的前缀，则就需要查询它的长度为$l-d$的后缀在AC自动机中的出现次数

加速这个过程，可以对每一个等差数列一起计算，按照$l-d$是否$>\sqrt{n}$分块，大于根号的情况可以暴力，小于根号的情况，可以对$1$到$\sqrt{n}$的每一个公差，在fail树上记录一个前缀和

$$
T(n) = 2T(n/2)+O(n^{1.5})=O(n^{1.5})
$$

</CollapsibleComponent>
