# KMP与字符串的周期、Border

## 基础定义

对字符串 $ s $ 和 $ 0 < p \leq |s| $，若 $ s[i] = s[i + p] $ 对所有 $ i \in [0, |s| - p - 1] $ 成立，则称 $ p $ 是 $ s $ 的周期。

对字符串 $ s $ 和 $ 0 \leq r < |s| $，若 $ s $ 长度为 $ r $ 的前缀和长度为 $ r $ 的后缀相等，就称 $ s $ 长度为 $ r $ 的前缀是 $ s $ 的 border。


由 $ s $ 有长度为 $ r $ 的 border 可以推导出 $ |s| - r $ 是 $ s $ 的周期。


根据前缀函数的定义，可以得到 $ s $ 所有的 border 长度，即 $ \pi[n - 1], \pi[\pi[n - 1] - 1], ... $。


所以根据前缀函数可以在 $ O(n) $ 的时间内计算出 $ s $ 所有的周期。其中，由于 $ \pi[n - 1] $ 是 $ s $ 最长 border 的长度，所以 $ n - \pi[n - 1] $ 是 $ s $ 的最小周期。

##### AT_abc312_h [ABC312Ex] snukesnuke

高桥君需要给 $n$ 个人取一个绰号。

第$i$个人希望将其绰号设为$S_i$。为了避免给多个人取相同的绰号，高橋君决定采用以下步骤为这$n$个人分别确定绰号：

对于 $i=1,\ldots,n$，按以下步骤来确定第$i$个人的绰号：

- 将变量$k_i$设为$1$
- 将$S_i$重复$k_i$次得到的字符串已经是某人的绰号时，不断增加$k_i$的值，直到找到一个没有被使用过的绰号。
- 将$S_i$重复$k_i$次得到的字符串设为第$i$个人的绰号。

请计算出确定了$n$个人的绰号后的$k_1,k_2,\ldots,k_n$

<CollapsibleComponent title="做法">
- 首先求出每一个字符串的最小循环节，因为只有最小循环节相同的字符串，才会相互影响。然后我们把最小循环节相同的字符串放到一起处理。
- 那么我们转化成这样一个问题了：
- 每次给一个数$len$，找到最小的没有使用过的$len$的倍数$w$，并把$w$标记为使用。
- 这个问题，可以给每个数$x$开一个set，表示$x$的倍数中，还有哪些没使用的数。
- 这样，每次遇到一个$len$，$w$就是查询$len$的set中的最小值。然后接下来，把$w$的所有因数的set中删掉$w$。
</CollapsibleComponent>

##### P5770 [JSOI2016] 无界单词

定义一个长度为$n$的字符串是borderless的，当且仅当不存在一个长度小于$n$的后缀使得他等于对应长度的前缀。

给定$n,k$,求字典序第$k$大的borderless的01串

$n \le 64,5$组数据

<CollapsibleComponent title="做法">
- 大致方法：按位枚举每一位，DP计算以当前确定部分为前缀的方案数
- 问题变成了，如何求长度为n的以串S为前缀的borderless串个数?
- 首先用kmp求出S的next
- $f[x]$表示DP到第x位的方案
- 如果$x \le |S|$,那么$f[x]=[next[x]==0]$
- 如果$x > |S|$,我们使用容斥，不考虑borderless的限制有$2^x$种方案，然后减去不合法的
- 枚举一个$S$的最大border长度k，那么前缀和后缀要求相等，中间的可以任意放。
- 不过还要分$k \le |S|/2$和$k > |S|/2$来讨论。(因为前缀可能和后缀相交)
</CollapsibleComponent>

##### CF1286E Fedya the Potter Strikes Back
    
有一个字符串$S$和一个整数序列$W$，初始为空

接下来$n$次操作，每次会给字符串末尾加一个字符，序列末尾加一个数字

定义一个子串$[L,R]$的可疑度为：如果$S[L \ldots R] = S[1 \ldots R-L+1]$，则为$\min_{i=L}^{R}W_i$，否则为$0$

每次加完以后，求所有子串的可疑度之和

$n \le 6 \times 10^5$，强制在线

<CollapsibleComponent title="做法">
每次添加一个字符后，可疑度的变化量为所有border的可疑度之和

动态维护border的集合，每次增加一个字符$c$之后，对于之前每一个border，如果该border前缀的下一个字符不是$c$，则删除该border

如果$s[1]=c$，则新增一个长度为$1$的border

在跑kmp的同时记录另外一个数组$pre[i]$表示$S[1 \ldots i]$的所有border中，最长的，后继字符和$S[i+1]$不相同的border

这样，每次沿着pre数组一直跳就可以找到所有需要删除的border

求权值可以用线段树，也可以在单调栈上二分
</CollapsibleComponent>
