# Lyndon分解

## 最小后缀问题
用$Suf(S)$表示$S$的后缀集合，$minsuf(S)$表示最小的后缀

用$Ssuf(S)$表示$\{V \in Suf(S)|\exists T,VT =minsuf(ST) \}$，即，通过末尾加字符之后有可能成为最小后缀的后缀

定理：若$U,V \in Ssuf(S)$，且$|U|<|V|$，则$2|U|<|V|$

证明：这两个都有可能成为最小后缀，说明当前的前$|U|$位是相同的，若$2|U|\ge |V|$，则形成了一个$|V|-|U|$的周期，这样$U$和$V$不可能都有机会成为最小后缀

进而推出，$|Ssuf(S)| \le \log(n)$

## lyndon分解
如果一个串的最小后缀就是自己，则称为lyndon串

如果一个串有一个周期（非完整）是lyndon串，则这个串称为近似lyndon串

lyndon分解：将一个串分解为若干个字典序非严格递减的Lyndon串，即$S=t_1+t_2+\ldots+t_k$满足$\forall i\in [1,k], t_i$是Lyndon串且$t_i \ge t_{i+1}$

**lyndon分解存在且是唯一的**
    
如果$a,b$都是Lyndon串且$a<b$，则$ab$是lyndon串

求出Lyndon分解：

将字符串$S$分成三部分：$S=S_1+S_2+S_3$，其中$S_1$表示已经分解完，$S_2$表示一个近似lyndon串，$S_3$表示还没有分解。令$w$为$S_2$的非完整周期，即$S_2=w^c+p$($p$为$w$的前缀)

令$i$为$S_2$的开头位置、$j$为$S_3$的开头位置，$k=j-|w|$，每次我们将$S[j]$和$S[k]$比较：

- $S[j]=S[k]$，则将$S[j]$添加到$S_2$
- $S[j]>S[k]$，此时$S_2+S[j]$变成了一个Lyndon串，则令$w=S_2,c=1$
- $S[j]<S[k]$，此时$S_2+S[j]$不是近似Lyndon串了，将$S[i \sim i+|w|-1],S[i+|w|,i+2|w|-1],\ldots$加入$S_1$，$S_2$只保留$p$

##### P5334 JSOI2019 节日庆典

给一个字符串$S$，对每个前缀求最小循环表示

$|S| \le 3 \times 10^6$

<CollapsibleComponent title="做法">
考虑如何用Lyndon分解求一个串的最小循环表示

将Lyndon分解后相同的串合并得到$S=w_1^{k_1}w_2^{k_2}\ldots w_m^{k_m}$

定义$T_i=w_i^{k_i}w_{i+1}^{k_{i+1}}\ldots w_m^{k_m}$

如果$T_m$不是$w_{m-1}$的前缀，则最小循环表示不可能从$T_m$之前开始，依次类推可以发现，对于任意$i$，如果$T_i$不是$w_{i-1}$的前缀，则最小循环表示不可能从$T_i$之前开始

这样就可以得到一个$O(n\log n)$的做法了，在求出每个前缀的Lyndon串后，把候选的方案都拿出来比较。因为候选的方案满足$|w_{i-1}| \ge |T_i|$，所以候选的方案只有$O(\log n)$个
</CollapsibleComponent>

<CollapsibleComponent title="优化">
考虑在运行Lyndon分解算法的过程中，会把每个前缀$S[1 \sim i]$分解为$p+u^c+u'$，其中$u'$为$u$的前缀，那么答案只有可能是$u$或者$u'$的开头

如果取的是$u'$的开头，相当于循环表示为$u'+p+u^c$，而这同时也是$p+u^{c-1}+u'$的最小循环表示

因此，用$ans[i]$表示前缀$S[1 \sim i]$的最小循环表示的开头位置，在Lyndon分解算法的同时可以求出$ans$数组：

- $S[j]=S[k]$，那么需要比较$i$和$ans[j-|u|]+|u|$哪个开头的循环表示更小，即比较$1$开头的串和$i+j-(ans[j-|u|]+|u|)$开头的串哪个更小。比较一个后缀和整个串的大小，可以用EX-KMP
- $S[j]>S[k]$，此时$u^c+u'+S[j]$变成了一个Lyndon串，则$ans[j]=i$
- $S[j]<S[k]$，此时之前的Lyndon串$u$被更新了，但$u'$还不知道，我们接下来重新求解$u'$
</CollapsibleComponent>

##### P5211 ZJOI2017 字符串

- 求某个子串的最小后缀的下标
