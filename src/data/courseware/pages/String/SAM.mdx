## 想法来源

我们想用一个结构来表示一个字符串的所有子串

后缀字典树结构简单，但是时间复杂度太高，后缀树虽然降低了复杂度，但是边的压缩导致实现起来有很多细节

## 处理子串出现次数

- 即right集合大小
- 利用性质:每个非叶子节点代表的right集合是它所有儿子的并集
- 可以把parent树建出来，也可以利用$len[fa[k]]<len[k]$，使用桶排序。
- 上述方法只能求出right集合的大小，如何把整个集合内容求出来呢？
- 线段树合并即可

##### CF1016B Segment Occurrences

给定两个仅由小写拉丁字母组成的字符串 $s$ 和 $t$。

子串 $s[l..r]$ 表示取出 $s$ 的第 $l$ 个字符到第 $r$ 个字符，且保持原有顺序。

字符串 $a$ 在字符串 $b$ 中的每一次出现，定义为一个位置 $i$（$1 \le i \le |b| - |a| + 1$），使得 $b[i..i + |a| - 1] = a$（其中 $|a|$ 表示字符串 $a$ 的长度）。

你将会得到 $q$ 个询问：对于第 $i$ 个询问，需要你计算字符串 $t$ 在子串 $s[l_i..r_i]$ 中出现的次数。

##### Rikka with String BestCoder Round #37

给定一个长度为$n$的小写字母字符串$S$，你需要对每个$[1,n]$中的i求出$S[i]$修改成\#后S的本质不同的子串个数

$1 \le n \le 3*10^5$

首先答案的第一部分是$i*(n-i+1)$个跨越#的子串

第二部分是被#分裂成两部分的串的本质不同的子串的并集

我们先建出SAM，显然right集合里只要考虑第一个和最后一个，我们用差分标记一下即可
