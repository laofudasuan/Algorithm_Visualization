# 基本子串结构

把一个串的所有子串在平面上进行刻画

每一个子串$S[l,r]$就视为二维平面上一个点$(l,r)$

像压缩后缀自动机一样，把子串进行分类，出现位置左端点相同、右端点相同的都分进同一类

怎么求出这个分类？后缀自动机已经把右端点相同的分类完毕了

求出出现次数之后，在tran上把出边的次数和当前点相同的合并

##### CF1817F Entangled Substrings
给定字符串$s$

$s$的非空子串对$(a,b)$合法，当且仅当存在可空字符串$c$，使得每次$a$在$s$中

<CollapsibleComponent title="做法">
有了基本子串结构以后就不难了

$a$和$b$要想成为答案需要满足几条：

- $a$和$b$要在基本子串结构中属于同一类
- $a$和$b$在一类里不能相交
- $a$的出现位置要在$b$的左边
