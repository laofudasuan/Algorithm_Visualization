##### 例题

给两个字符串A,B，有五种操作。
- 在A开头添加一个字符
- 在A末尾添加一个字符
- 在B开头添加一个字符
- 在B末尾添加一个字符
- 询问B在A中的出现次数

<CollapsibleComponent title="SA做法">

我们先离线把A,B的最终形态求出来。

然后，对于某一时刻的询问，就是问B有多少个当前存在的后缀满足和A当前最长后缀的lcp$\ge$A串长。

在这些解对应后缀数组上一段区间，用ST表height倍增找到这段区间，然后用树状数组维护区间当前存在的后缀个数。

</CollapsibleComponent>

<CollapsibleComponent title="SAM做法">

首先我们可以预处理最终态A的SAM，然后求出B的每个前缀在SAM上对于的结点。

对于一次询问，我们可以用经典的倍增法求出B在SAM上对应的结点。然后要求出B在A已经出现过的区域内的出现次数。因为每次操作都是在前后添加字符，所以当前出现过的范围一定是一段区间。用线段树合并维护right集合直接查询。

</CollapsibleComponent>

##### CF1276F Asterisk Substrings

给定一个字符集为小写字母的长度为 $n$ 的字符串 $s$，设 $t_i$ 表示将 $s$ 中的第 $i$ 个字符替换为特殊字符 $*$ 时得到的字符串，比如当 $s = abc$ 时，$t_1 = *bc$，$t_2 = a*c$，$t_3 = ab*$。

求字符串集合 $\{s, t_1, t_2, t_3, ..., t_n\}$ 中本质不同的子串个数（需要计算空串）。

**注意** $*$ 仅表示一个字符，不表示其他含义（如通配符）。

$n \le 10^5$

<CollapsibleComponent title="做法">

答案分为几个部分：

- 不包含$*$的子串，答案就为$S$本质不同的子串个数
- 以$*$开头的子串，答案就为$S$删掉首字母后本质不同的子串个数
- 以$*$结尾的子串，答案就为$S$删掉尾字母后本质不同的子串个数

考虑用后缀自动机来枚举$*$左边的串，然后给Right集合的每一项$+2$就得到了$*$右边可行的开头位置。

这样相当于是要动态维护：选定部分后缀，求这些后缀中本质不同的前缀个数。

也就是相当于动态维护这些后缀的总长度-相邻两两的lcp之和。

可以在后缀自动机上启发式合并维护Right集合+2的所有后缀。

启发式合并改成线段树合并能做到一个$log$
</CollapsibleComponent>

##### P4482 BJWC2018 Border 的四种求法
给一个长度为$n$的字符串，$m$次询问，每次问一段区间$[l,r]$的最长Border长度

$n,m \le 2 \times 10^5$，时间$5s$

<CollapsibleComponent title="做法">

用$lcs(i,j)$表示前缀$i,j$的最长公共后缀

则区间最长border相当于找最大的$p$满足$lcs(p,r) \ge p-l+1$

而$lcs(p,r)$在后缀自动机上就是LCA的$len$

对于一个询问来说，$r$是固定的，所以LCA的范围就是$r$的所有祖先

这样就得到了一个暴力算法：预处理每个点Right集合，枚举$r$的所有祖先，这样就确定了长度len，然后查找这个点的Right集合中$\le l+len$的最大的元素。这个可以用线段树合并快速查询。

然后考虑优化。查询一条链的问题考虑树链剖分，每次查询某条重链上的一个点$u$到链顶$top$上的所有点

问如下形式的问题：依次给定递减的len，查询Right集合中$[l,l+len]$的最大值

然后把最大值分成两种情况：一种是，就在$u$的子树中，直接用线段树合并查询

另外一种是，在$u$到$top$的路径上，或者这些点挂出去的轻儿子子树中

然后修改一下条件，$lcs(p,r) \le p-l+1 \to p-lcs(p,r)<l$。

对于一条重链，我们预处理一个数据结构维护每个点挂出去的轻儿子子树的所有$p-lcs(p,r)$，查询就是查询重链一段前缀的不超过$l$的，在重链上最靠后的点

这个可以在线段树上二分实现
</CollapsibleComponent>

##### P4022 CTSC2012熟悉的文章
简述题意：有一个字符串集合S,现在给出一个串T，需要在这个串中提取若干个不相交子串，要求这些子串总长$\ge 90\%|T|$，并且每个子串都在字符串集合的某个串中出现过。

求这些子串长度的最小值的最大值。

<CollapsibleComponent title="做法">
题目非常复杂，我们先进行化简。

要求在字符串集合的某个串中出现过，可以用若干个特殊标记符把整个字符串集合拼在一起。这样只需要在这一个串中出现过就可以了。

##### P4218 珠宝商 (CTSC2010)
给你一棵n个点的树和一个长度为m的字符串S，树的每个点上有一个字符，求树上的每一条路径形成的字符串在S中的出现次数

$n,m\le50000$,原题时间限制$18s$,洛谷$8s$

<CollapsibleComponent title="做法">
- 先考虑怎么写暴力,稍微靠谱一点的是对S建后缀自动机,然后暴力扫描树上所有路径,统计出现次数总和,复杂度$O(n^2+m)$
- 树的路径的问题很显然可以无脑点分一发,然后计算过根的路径出现次数总和。
- 我们从根开始dfs整个连通块,把所有到达的路径进行标记
- 注意到这些路径拼凑起来时重复计算了根上的那一个字符
- 我可以以此为中转点,对每个字符统计它往前后和往后的方案数。
- 先在后缀树上进行标记,dfs完后把标记下放到叶子节点。
- 然后我们发现,做一次点分的复杂度是O(size+m)的。
- 当size已经很小时,复杂度瓶颈变成了m,我们可以改为暴力。
- 分析后可以得到复杂度为$(n+m)\sqrt{m}$
</CollapsibleComponent>

## 重要模型

一个经典问题：给定一个长度为n的序列，Q次询问，每次询问一段区间$[l,r]$不同数的个数。

一个经典方法：从小到大枚举询问的右端点，每次加入一个位置b时，如果之前有有一个位置a 和它的数相同，那么a对答案一定没有贡献，直接删除。

把重复出现的数保留最后一个后，直接在枚举的右端点到达询问位置后查询$[l,r]$内未被删除的数的个数就是答案。

总的来说，我们需要支持的操作是单点修改、区间查询，用树状数组即可。

如果强制在线可以把树状数组替换为可持久化线段树。

### 新问题

给定一个长度为n的串。有Q次询问，每次询问一段区间$[l,r]$本质不同的子串个数。

- 还是可以用同样的思想解决，但是，现在的关键问题是本质不同的子串个数是$O(n^2)$的，所以总复杂度会退化到$O(n^2logn)$
- 首先，后缀自动机上一个结点代表的串的出现次数都是相同的，我们可以一起统计。
- 在末尾加入一个字符后，所有重复出现的串为新建结点np在parent树上的所有祖先。
- 在后缀自动机一个结点上我们记一个串出现的最后位置last，一次操作我们需要把np 的所有父亲的last全部修改。
- 这个操作让我们想到了什么? ACCESS!
- tarjan告诉我们，对一棵树做n次ACCESS,prefer\_child的切换次数是$nlogn$的，所以复杂度就被优化到了$nlog^2n$

##### string (2016 ACM/ICPC Asia Regional Qingdao Online)

初始有一个长度为$n$的字符串，有$m$次操作。

操作1:在末尾添加一个字符

操作2:查询子串$[l,r]$中，出现次数$>1$的串的长度最大值。

$n,m \le 50000$


- 出现次数$>1$，即不是parent树上的叶子节点。
- 我们把初始给出的串也看做插入操作。每加入一个字符，我们维护以当前字符结尾的询问的答案。
- 首先,$ans_{l,r}$的初值可以设为$ans_{l,r-1}$，即先不统计包含字符$S_r$的串。
- 我们记last(p)为点p的right集合的最大值。
- 现在新加入字符后产生的结点为$np$，那么从$np$到根的一条链，它的出现次数都$+1$

<CollapsibleComponent title="做法">
- 因为之前存在的结点p代表串的出现次数必定$>0$，那么现在次数+1之后一定就满足要求
- 所以p所代表的串可以用来更新答案。它能更新的询问$ans_{l,r}$需要满足$l \le last(p)$
- 我们用可持久化线段树维护答案，那么需要支持的操作就是区间取max
- 但是p的个数是O(n)的，我们考虑优化枚举p
- 如果p和fa[p]的last相同，我们可以同时更新答案。
- 注意到，每做一次暴力扫的时候，都会把p到根的结点的last修改为同一个值
- 这恰好就相当于access操作。根据LCT，我们可以推导出，暴力扫描的p的总数是$nlogn$的
- 所以这题的总复杂度为$(n+m)log^2n$
</CollapsibleComponent>
