# Prufer序列

Prufer序列将$n$个点有标号的无根树一一对应上一个长度为$n-2$的序列。

构造方法：每次选择一个标号最小的叶子节点，把与它相邻的点加入序列，并删除这个点。

还原方法：每次把 Prufer 序列的第一个元素和可选集合中未出现在 Prufer 序列的最小的点连边，然后从可选集合中删除这个最小点以及 Prufer 序列的首项。

### 例题

$n$个点的完全图的生成树个数？

<CollapsibleComponent title="答案">
$n^{n-2}$
</CollapsibleComponent>
 
### 标记关键边的生成树计数

在一张完全图中标记若干关键边，问包含这些关键边的生成树个数。

 一个点的度数 = 在 Prufer 中的出现次数 + 1

如果 n 个点已经形成了 m 个连通块，每个连通块大小为$a_i$，那么这 n 个点的生成树个数为：

$$n^{m-2}\prod_{i=1}^{m}a_i$$

现在 Prufer 序列长度为 m-2，每个元素的取值范围是 $1 \sim n$

然后每次把一个度数为 1 的连通块和它相邻点相连时可以选择$a_i$个点中的任意一个。

##### 清华集训2017生成树计数
	
在一个$s$个点的图中，存在$s-n$条边，使图中形成了$n$个连通块，第$i$个连通块中有$a_i$个点。

现在我们需要再连接$n-1$条边，使该图变成一棵树。对一种连边方案，设原图中第$i$个连通块连出了$d_i$条边，那么这棵树$T$的价值为：

$$
val(T)=(\prod_{i=1}^{n}d_i^m)(\sum_{i=1}^{n}d_i^m)
$$

求出所有可能的生成树的价值之和，对998244353取模。

$n \le 3 \times 10^4,m \le 30$

<CollapsibleComponent title="朴素DP">
如果没有后面那个$\sum d_i^m$的话，是非常容易DP的

这个$\sum d_i^m$也很好处理，用组合的观点理解，可以视为：填完整个序列后，选择一个**关键点**$i$，对答案产生一个$d_i^m$倍的贡献

于是考虑 DP 它，令$f[i][j],g[i][j]$分别表示考虑了前$i$个连通块，序列的$j$个位置被填了，有/没有选择关键点的贡献和

复杂度$O(n^3)$
</CollapsibleComponent>

<CollapsibleComponent title="m=1">
考虑特殊情况:$m=1$

一个点在生成树的度数=在Prefer序列中出现的次数$+1$

相当于统计这样的方案数：把序列填好之后，在序列之后写上$1 \sim n$，然后对于$1 \sim n$，在序列中选择一个对应的数染黑的方案数

把这个过程倒过来，对于$1 \sim n$，先在序列中决定染黑一个位置，然后其他位置就能随意填写了

$F[i][j]$表示决策了前$i$个数，Prüfer 编码中$j$个位置被占用的方案数

复杂度$O(n^2)$
</CollapsibleComponent>

<CollapsibleComponent title="m=2">
考虑特殊情况:$m=2$

仿照$m=1$的思路，用组合的角度看一下

相当于选两个位置，分别染红和染绿，两个位置可以相同

怎么处理后面的$\sum d_i^2$呢

选择一个数，并选择它的两个位置分别染黄和染蓝，位置可以相同

设一个$F[i][j]$和$G[i][j]$就可以了
</CollapsibleComponent>

<CollapsibleComponent title="一般情况">
枚举这个染色过程占用了$k$个位置，转移的系数可以由第二类Stirling数推导得出

注意到DP过程的卷积本质，使用分治FFT优化到$O(nmlog⁡ n)$

</CollapsibleComponent>
