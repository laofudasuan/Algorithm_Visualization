# 树的括号序列

我们可以把树的每个点按照 dfs 序编号，得到一个序列。这个序列被称为树的欧拉序。

括号序列是处理树的问题的一种特殊手段。括号序列本质上就是树的欧拉序，但是进行了简化表示，用[表示向下走一条树边，用]表示向上走一条树边，那么树的括号序列就是由n-1个[和n-1个]组成的序列。

由于它本质上就是欧拉序，所以它满足一些基本的性质：

- 一棵子树的欧拉序位于整棵树的一段区间。
- 任意一个前缀都满足[的个数大于等于]的个数。
- 树的括号序列目前用处最大的功能是快速表示两个点之间的距离。

把括号序列中位于两个点之间的一段提出来，然后把相互匹配的括号删除(相互匹配指相邻两个括号，左边的为[，右边的为])，剩下的括号个数就是两点之间的距离。

给定 $n$ 个点，$m$ 个询问。

给你一棵树的括号序列，输出它的直径。

有 $m$ 次询问，每次询问表示交换两个括号，输出交换两个括号后的直径（保证每次操作后都为一棵树）

输出共 $m+1$ 行。

$3 \leq n \leq 100\,000, 1 \leq q \leq 100\,000$
