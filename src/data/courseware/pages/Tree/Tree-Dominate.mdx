# $O(n \log n)$ 支配对

## 支配对类题目

- 初始有 $n$ 个对象，两两对象之间可以产生一个**贡献**
- 每次给一个范围，求范围内的所有对象之间两两产生的贡献的信息合并
- 如果需要对两两对象计算贡献，并且每次询问需要求出范围内的两两对象的贡献，这样需要维护 $\Theta(n^2)$ 对贡献，即 $\Theta(n^2)$ 对二元组，复杂度过高

## 支配对类题目

- 但是问题经常有性质，导致可以找出 $\Theta(n \log n)$ 对两两对象之间的贡献，只需要查询范围内这 $\Theta(n \log n)$ 对的贡献，即可覆盖 $\Theta(n^2)$ 对的贡献
- 这个 $\Theta(n \log n)$ 对二元组就叫做原问题的 $\Theta(n^2)$ 对二元组的一个**支配集**
- 找出支配集后一般问题会变成几种平凡形式

## 第一类 支配对

- 两两对象产生一个贡献，总共产生 $\Omega(n^2)$ 对贡献，但是这些贡献中本质不同的只有 $O(n)$ 种
- 常见的题型：树保留区间点
- 一般这种问题在树上是常见的，有的树上问题要范围内的点两两点求出 LCA，这样是求范围内两两对象的贡献，但是 LCA 只有本质不同的 $n$ 个点
- 常见思路：树上启发式合并，加入点 $x$ 时，只考虑编号为 $x$ 的前驱后继的点与 $x$ 产生二元组，找出 $O(n \log n)$ 个二元组支配原本 $\Theta(n^2)$ 对贡献

### 例题

- Luogu7880 [Ynoi2006] rldcot
- Luogu8528 [Ynoi2003] 铃原露露

## 第二类 支配对

- 两两对象产生一个贡献，总共产生 $\Omega(n^2)$ 对贡献，但是这些贡献中本质不同的有 $\Omega(n^2)$ 种
- 常见的题型：区间内两两算个东西然后求 $\min$ 或 $\max$

有两种常见的支配对形式：

1. 对每个 $i$，可以用数据结构高效找出 $O(\log n)$ 个 $j$，这些 $(i,j)$ 的贡献支配了所有 $(i,1),(i,2),\ldots,(i,n)$ 的贡献
2. 对一维分治时，假设对大小 $n$ 的问题进行分治，会产生 $O(n)$ 对跨过分治中线的贡献，支配了本来两边产生的 $\Omega(n^2)$ 对贡献（一般对信息那一维分治，不对序列分治）

## 对每个 $i$，有 $O(\log n)$ 个 $j$

- $(x_1,y_1)$ 的贡献可以支配 $(x_2,y_2)$ 的贡献，则 $(x_1,y_1)$ 构成的区间被 $(x_2,y_2)$ 构成的区间包含，并且统计 $(x_1,y_1)$ 的贡献后，统计 $(x_2,y_2)$ 的贡献一定不改变询问答案
- 首先 $(i,i+1)$ 的贡献一定是必要的
- 对每个 $i$，先令 $j=i+1$，计算 $(i,j)$ 的贡献，然后找到一个 $k$，满足 $j<k$，$(i,k)$ 有贡献，当且仅当 $(i,j)$，$(j,k)$ 的贡献无法支配 $(i,k)$ 的贡献
- 利用这一条性质对 $a[k]$ 的可行范围做限制，如果可以保证每次 $a[k]$ 可行范围减半，则对每个 $i$ 最多有 $O(\log n)$ 个 $j$ 有贡献

## CF765F Souvenirs

> 给一个长为 $n$ 的序列，有 $m$ 次查询，每次查询区间 $[l,r]$ 中最小的 $|a[i]-a[j]|$ 满足 $l \le i,j \le r$

### Solution

- 考虑 $i$ 位置和哪些位置 $j$ 能形成有意义的二元组（即对答案有影响的 $(i,j)$）
- 如果是 $a_i < a_j < a_k$，则 $(i,k)$ 的意义被 $(i,j)$ 掩盖
- 考虑 $a_i < a_j,\ a_j > a_k$
  1. $a_i > a_k \Rightarrow |a_j-a_k| > |a_i-a_k|$，值域减半
  2. $a_i < a_k \Rightarrow |a_i-a_j| > |a_i-a_k|$，限制下界，之后出现 $a_i < a_{k'}$ 可类比 1
- 总的有贡献的二元组为 $O(n \log V)$ 个，其中 $V$ 为值域
- 可用可持久化值域线段树或其他方法 $O(n \log n \log V)$ 找出有意义的二元组
- 将询问看作二维平面上的点，每个 $(a[i], a[j])$ 的 pair 对所有 $l \in [1,i]$，$r \in [j,n]$ 的询问贡献 $|a[i]-a[j]|$，取 $\max$
- 矩形是 2-side 的，选择合适方向扫描线，只插入不删除
- 问题变为区间对 $x$ 取 $\max$，单点值 $\rightarrow$ 扫描线 + 线段树
- 总时间复杂度：$O(n \log n \log V + m \log n)$

## CodeChef MINXORSEG

> 给一个长为 $n$ 的序列，有 $m$ 次询问，每次求区间 $[l,r]$ 中最小的 $a[i] \oplus a[j]$，满足 $l \le i < j \le r$  
> $n,m \le 2\times 10^5,\ a[i] \le 10^9$

### Solution

- 用每个 $i$ 只有 $O(\log n)$ 个 $j$ 使得 $(i,j)$ 有贡献的支配对套路
- 假设 $i<j<k$，则 $(i,k)$ 的贡献不被 $(i,j)$ 支配掉，仅当 $a[i] \oplus a[k] < a[i] \oplus a[j]$
- 同时为了不被 $(j,k)$ 支配掉：$a[i] \oplus a[k] < a[j] \oplus a[k]$
- 考虑 $a[i], a[j], a[k]$ 二进制表示下的 LCP，以及下一个字符
- $a[i]$ 和 $a[j]$ 在 LCP 后的一个字符一定不同
  - 若 $a[i]$ 这一位是 $0$，$a[j]$ 是 $1$，则 $a[k]$ 这一位一定是 $0$，否则 $(i,k)$ 被 $(j,k)$ 支配
  - 若 $a[i]$ 是 $1$，$a[j]$ 是 $0$，则 $a[k]$ 一定是 $1$
- 满足上述条件的 $k$ 一定可以让 $(i,k)$ 的贡献无法被支配
- 每次找到新的 $(i,k)$ 后，$a[i]$ 和 $a[j]$ 的 LCP 长度至少 $+1$
- 对每个 $i$，找到 $O(\log V)$ 个 $j$，支配所有 $(i,i+1),(i,i+2),\ldots,(i,n)$ 的贡献
- 每次要找区间 $[l,r]$ 中最小的 $i$，满足 $a[i]$ 二进制前缀是 $x$
- 找的过程可用可持久化值域线段树上二分，$O(n \log^2 V)$
- 找到 $O(n \log V)$ 个支配对后，按左端点和右端点构造二维平面，支配对 $(i,j)$ 对所有 $[l,r]$ 满足 $l \le i,j \le r$ 都有贡献 $\rightarrow$ 2-side 矩形
- $\min=$ 修改，询问是单点 $\rightarrow$ 扫描线 + 线段树
- 总时间复杂度：$O(n \log V (\log n + \log V) + m \log n)$

## Luogu8078 [WC2022] 秃子酋长

> $n,m \le 5\times 10^5$

### Solution1

- 莫队算法，维护区间信息，转移时使用数据结构
- 总时间复杂度：$O(n\sqrt{m}\log n + m\log m)$
- 期望得分：看常数

### Solution2

- 不插入莫队（回滚莫队）
- 维护块到块端点的链表，支持 $O(1)$ 删除并求前驱后继
- 总时间复杂度：$O(n\sqrt{m} + m)$
- 期望得分：写得好可得 100 分

### Solution3

- 对值域分块，值域块内等价的只有 $O(\text{块大小}^2)$ 种情况
- 暴力预处理每个块内所有可能情况，询问时算每个值域块对答案的贡献
- 总时间复杂度：$O(n\sqrt{n+m} + m)$
- 期望得分：100 分

### Solution4

- 问题难以 polylog 维护的地方在于区间前驱后继 pair 的变化量很大
- 绝对值有非常好的性质
- 对序列分治，区间 $[l,r]$ 分治中心 $mid$
- 询问 $[x,y]$ 满足 $[x,y]$ 为 $[l,r]$ 子区间，且 $x \le mid \le y$
- 对 $[l,mid]$ 中的 $x$，求 $[x,mid]$ 内部答案；对 $[mid+1,r]$ 中的 $y$，求 $[mid+1,y]$ 内部答案
- 再考虑左边对右边、右边对左边的贡献
- 对每个 $[x,mid]$ 中排序后相邻的二元组 $(i,j)$，在 $[mid+1,y]$ 中找 $k$，满足 $a[i] < a[k] < a[j]$，且 $k$ 距离 $mid$ 最近
- 只需关心二元组之间是否插入了元素，不需要关心插入的元素有哪些
- 若询问 $[x,y]$ 不包含 $k$，则 $(i,j)$ 贡献为 $j-i$
- 若包含 $k$，则贡献为 $-j-i$，$k$ 的贡献在计算左边对右边二元组贡献时计入
- 若 $(i,j)$ 中有多个排序相邻的右侧元素 $k$，$k$ 内部贡献在右边内部已计算，$i$ 对最小 $k'$，$j$ 对最大 $k''$ 的贡献在左边对右边贡献中计算
- 每层分治找出的贡献为二维数点形式
- 从右往左扫 $[l,mid]$，从左往右扫 $[mid+1,r]$，用数据结构维护前驱后继，每次扫描改变 $O(1)$ 对相邻 pair
- 总共找出 $O(n)$ 个二维平面上的点
- 每层 $O(n \log n)$，总 $O(n \log^2 n)$
- 每组询问只会进入一层，拆成 $O(1)$ 次询问
- 总时间复杂度：$O(n \log^2 n + m \log n)$
- $n=m$ 时可多叉平衡为 $O(n \log^2 n / \log \log n)$
- 期望得分：100 分

## 对复杂维分治

- 一般对复杂的那一维进行分治
- 分治时，假设对大小 $n$ 的问题进行分治，会产生 $O(n)$ 对跨过分治中线的贡献，这些贡献支配了本来两边产生的 $\Omega(n^2)$ 对贡献
