# 树的基础知识

## 树的定义

树（Tree）是一种非线性的数据结构，它是由$n$（$n \geq 0$）个有限节点组成的一个具有层次关系的集合。当$n=0$时，称为空树；当$n \geq 1$时，树的结构满足以下条件：

- 有且仅有一个特定的称为根（Root）的节点
- 其余节点可分为$m$（$m \geq 0$）个互不相交的有限集合，每个集合本身又是一棵树，称为根的子树（Subtree）

树的结构特点使得它非常适合用来表示具有层次关系的数据，如文件系统、组织结构、决策树等。

## 树的基本术语

### 节点相关术语

- **节点（Node）**：树中的每个元素都称为节点
- **根节点（Root）**：树中没有前驱的节点，一棵树只有一个根节点
- **叶子节点（Leaf Node）**：没有子节点的节点，也称为终端节点
- **内部节点（Internal Node）**：除了根节点和叶子节点之外的节点
- **父节点（Parent）**：若一个节点含有子节点，则这个节点称为其子节点的父节点
- **子节点（Child）**：一个节点含有的子树的根节点称为该节点的子节点
- **兄弟节点（Sibling）**：具有相同父节点的节点互为兄弟节点
- **堂兄弟节点（Cousin）**：父节点在同一层的节点互为堂兄弟节点

### 树的度量

- **节点的度（Degree）**：节点拥有的子树数目
- **树的度（Degree of Tree）**：树中各节点度的最大值
- **节点的层次（Level）**：从根开始定义，根为第一层，根的子节点为第二层，以此类推
- **树的高度（Height）**：树中节点的最大层次数
- **森林（Forest）**：由$m$（$m \geq 0$）棵互不相交的树组成的集合

## 树的表示方法

### 1. 顺序存储结构

顺序存储结构主要用于完全二叉树的存储。在这种存储方式中，我们按照从上到下、从左到右的顺序将树中节点存入一维数组中。

对于完全二叉树，若节点的下标为$i$，则：
- 其左子节点的下标为$2 \times i + 1$
- 其右子节点的下标为$2 \times i + 2$
- 其父节点的下标为$\lfloor (i-1)/2 \rfloor$

```cpp
// 顺序存储表示完全二叉树
int binaryTree[] = {1, 2, 3, 4, 5, 6, 7};
// 数组索引:      0  1  2  3  4  5  6
```

### 2. 链式存储结构

链式存储结构是树最常用的存储方式。对于一般的树，每个节点需要存储数据和指向其子节点的指针。

## 二叉树

### 二叉树的定义

二叉树（Binary Tree）是$n$（$n \geq 0$）个节点的有限集合，该集合或者为空，或者由一个根节点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。

### 二叉树的性质

1. **性质1**：在二叉树的第$i$层上至多有$2^{i-1}$个节点（$i \geq 1$）
2. **性质2**：深度为$k$的二叉树至多有$2^k-1$个节点（$k \geq 1$）
3. **性质3**：对任何一棵二叉树，如果其叶子节点数为$n_0$，度为2的节点数为$n_2$，则$n_0 = n_2 + 1$
4. **性质4**：具有$n$个节点的完全二叉树的深度为$\lfloor \log_2 n \rfloor + 1$
5. **性质5**：对于有$n$个节点的完全二叉树，如果按从上到下、从左到右的顺序对节点进行编号（从1开始），则对于任意节点$i$（$1 \leq i \leq n$）有：
   - 若$i>1$，则其父节点为$\lfloor i/2 \rfloor$
   - 若$2i \leq n$，则其左子节点为$2i$
   - 若$2i+1 \leq n$，则其右子节点为$2i+1$

### 特殊二叉树

- **满二叉树（Full Binary Tree）**：除了叶子节点外，每个节点都有两个子节点，且所有叶子节点都在同一层
- **完全二叉树（Complete Binary Tree）**：除了最后一层外，每一层上的节点数都达到最大值，最后一层的节点都集中在该层最左边的若干位置
- **平衡二叉树（Balanced Binary Tree）**：任意节点的左右子树的高度差的绝对值不超过1
- **二叉搜索树（Binary Search Tree）**：对于任意节点，其左子树中所有节点的值都小于该节点的值，右子树中所有节点的值都大于该节点的值

## 树的遍历

树的遍历是指按照某种顺序访问树中的所有节点，使得每个节点恰好被访问一次。对于二叉树，常用的遍历方法有四种：

### 1. 前序遍历（Preorder Traversal）

**访问顺序**：根节点 -> 左子树 -> 右子树

```cpp
// 递归实现前序遍历
template <typename T>
void preorderTraversal(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    std::cout << root->data << " "; // 访问根节点
    preorderTraversal(root->left); // 前序遍历左子树
    preorderTraversal(root->right); // 前序遍历右子树
}

// 非递归实现前序遍历
template <typename T>
void preorderTraversalIterative(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    std::stack<BinaryTreeNode<T>*> stack;
    stack.push(root);
    
    while (!stack.empty()) {
        BinaryTreeNode<T>* node = stack.top();
        stack.pop();
        std::cout << node->data << " "; // 访问根节点
        
        // 注意右子树先入栈，左子树后入栈，这样出栈时才会先访问左子树
        if (node->right != nullptr) stack.push(node->right);
        if (node->left != nullptr) stack.push(node->left);
    }
}```
```

### 2. 中序遍历（Inorder Traversal）

**访问顺序**：左子树 -> 根节点 -> 右子树

```cpp
// 递归实现中序遍历
template <typename T>
void inorderTraversal(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    inorderTraversal(root->left); // 中序遍历左子树
    std::cout << root->data << " "; // 访问根节点
    inorderTraversal(root->right); // 中序遍历右子树
}

// 非递归实现中序遍历
template <typename T>
void inorderTraversalIterative(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    std::stack<BinaryTreeNode<T>*> stack;
    BinaryTreeNode<T>* current = root;
    
    while (current != nullptr || !stack.empty()) {
        // 一直向左遍历，将所有左子节点入栈
        while (current != nullptr) {
            stack.push(current);
            current = current->left;
        }
        // 出栈并访问节点
        current = stack.top();
        stack.pop();
        std::cout << current->data << " ";
        // 转向右子树
        current = current->right;
    }
}```
```

### 3. 后序遍历（Postorder Traversal）

**访问顺序**：左子树 -> 右子树 -> 根节点

```cpp
// 递归实现后序遍历
template <typename T>
void postorderTraversal(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    postorderTraversal(root->left); // 后序遍历左子树
    postorderTraversal(root->right); // 后序遍历右子树
    std::cout << root->data << " "; // 访问根节点
}

// 非递归实现后序遍历
template <typename T>
void postorderTraversalIterative(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    std::stack<BinaryTreeNode<T>*> stack1;
    std::stack<BinaryTreeNode<T>*> stack2;
    
    stack1.push(root);
    
    // 第一次遍历，根->右->左入栈stack2
    while (!stack1.empty()) {
        BinaryTreeNode<T>* node = stack1.top();
        stack1.pop();
        stack2.push(node);
        
        if (node->left != nullptr) stack1.push(node->left);
        if (node->right != nullptr) stack1.push(node->right);
    }
    
    // 第二次遍历，依次出栈stack2，得到左->右->根的顺序
    while (!stack2.empty()) {
        BinaryTreeNode<T>* node = stack2.top();
        stack2.pop();
        std::cout << node->data << " ";
    }
}```
```

### 4. 层序遍历（Level-order Traversal）

**访问顺序**：从上到下，从左到右依次访问每个节点

```cpp
// 层序遍历（使用队列）
template <typename T>
void levelorderTraversal(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    std::queue<BinaryTreeNode<T>*> queue;
    queue.push(root);
    
    while (!queue.empty()) {
        BinaryTreeNode<T>* node = queue.front();
        queue.pop();
        std::cout << node->data << " "; // 访问节点
        
        // 将子节点入队
        if (node->left != nullptr) queue.push(node->left);
        if (node->right != nullptr) queue.push(node->right);
    }
}```

## 树的应用

树结构在计算机科学中有广泛的应用，以下是一些常见的应用场景：

### 1. 文件系统

操作系统中的文件系统通常采用树形结构组织文件和目录，每个目录可以包含多个子目录和文件。

### 2. 数据库索引

许多数据库系统使用B树、B+树等树形结构来提高查询效率。

### 3. 决策树

在机器学习中，决策树是一种常用的分类和回归算法，通过树的结构来模拟决策过程。

### 4. 表达式树

表达式树用于表示数学表达式，其中叶子节点是操作数，内部节点是运算符。

### 5. 语法树

编译器在解析源代码时，通常会构建语法树来表示程序的语法结构。

### 6. 组织结构

企业、学校等组织的层级结构可以用树来表示。

## 树的实现示例

下面是一个简单的二叉树实现及其遍历示例：

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <queue>

// 二叉树节点类
template <typename T>
class BinaryTreeNode {
public:
    T data;
    BinaryTreeNode<T>* left;
    BinaryTreeNode<T>* right;
    
    BinaryTreeNode(T value) : data(value), left(nullptr), right(nullptr) {}
};

// 前序遍历函数声明
template <typename T>
void preorderTraversal(BinaryTreeNode<T>* root);

// 中序遍历函数声明
template <typename T>
void inorderTraversal(BinaryTreeNode<T>* root);

// 后序遍历函数声明
template <typename T>
void postorderTraversal(BinaryTreeNode<T>* root);

// 层序遍历函数声明
template <typename T>
void levelorderTraversal(BinaryTreeNode<T>* root);

// 创建二叉树
BinaryTreeNode<int>* createBinaryTree() {
    // 创建节点
    BinaryTreeNode<int>* root = new BinaryTreeNode<int>(1);
    BinaryTreeNode<int>* node2 = new BinaryTreeNode<int>(2);
    BinaryTreeNode<int>* node3 = new BinaryTreeNode<int>(3);
    BinaryTreeNode<int>* node4 = new BinaryTreeNode<int>(4);
    BinaryTreeNode<int>* node5 = new BinaryTreeNode<int>(5);
    BinaryTreeNode<int>* node6 = new BinaryTreeNode<int>(6);
    BinaryTreeNode<int>* node7 = new BinaryTreeNode<int>(7);
    
    // 构建树的结构
    root->left = node2;
    root->right = node3;
    node2->left = node4;
    node2->right = node5;
    node3->left = node6;
    node3->right = node7;
    
    return root;
}

// 释放树内存
template <typename T>
void deleteTree(BinaryTreeNode<T>* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    // 创建示例树
    BinaryTreeNode<int>* tree = createBinaryTree();
    
    std::cout << "前序遍历：" << std::endl;
    preorderTraversal(tree);
    std::cout << std::endl;
    
    std::cout << "中序遍历：" << std::endl;
    inorderTraversal(tree);
    std::cout << std::endl;
    
    std::cout << "后序遍历：" << std::endl;
    postorderTraversal(tree);
    std::cout << std::endl;
    
    std::cout << "层序遍历：" << std::endl;
    levelorderTraversal(tree);
    std::cout << std::endl;
    
    // 释放树内存
    deleteTree(tree);
    
    return 0;
}

// 递归实现前序遍历

    if (root == nullptr) return;
    std::cout << root->data << " ";
    preorderTraversal(root->left);
    preorderTraversal(root->right);

## 小结

树是一种重要的非线性数据结构，它在计算机科学的各个领域都有广泛的应用。通过本章的学习，我们了解了树的基本概念、术语、存储方法、遍历算法等内容。二叉树作为一种特殊的树结构，其遍历算法（前序、中序、后序、层序）是后续学习各种树应用的基础。

在实际应用中，我们需要根据具体问题的特点选择合适的树结构和操作算法，以提高程序的效率和性能。
