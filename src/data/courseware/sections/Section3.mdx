# 第三部分：常见算法类型

计算机科学中有许多经典的算法类型，每种都有其特定的应用场景。

## 排序算法

排序算法用于将数据按特定顺序排列：

- 冒泡排序
- 选择排序
- 插入排序
- 快速排序
- 归并排序
- 堆排序

## 搜索算法

搜索算法用于在数据结构中查找特定元素：

- 线性搜索
- 二分搜索
- 深度优先搜索 (DFS)
- 广度优先搜索 (BFS)

## 图算法

图算法处理图结构数据：

- 最短路径算法 (Dijkstra, Floyd-Warshall)
- 最小生成树 (Kruskal, Prim)
- 拓扑排序

## 动态规划

动态规划通过将复杂问题分解为子问题来求解：

- 背包问题
- 最长公共子序列
- 最优二叉搜索树

通过学习这些算法，你可以解决各种实际问题，并为进一步学习计算机科学打下坚实基础。
