# 从狼人杀圈子的发展历程中得到的一些感悟

今天在看京城大师赛的时候不禁意识到，JY近两年正在颠覆性地改变大师赛的运营思路。

说到狼人杀就不禁回想起，我关注这个游戏已经有很多年了。

## 认识狼人杀

我记得第一次接触狼人杀，是在2018年的国家队选拔之后。

![](/Blog/CTSC2018.jpg)

当时我刚成功以全国第三名的成绩入选中国国家代表队，长达数月的紧张备赛后终于迎来了理想的结果，所以想着应该马上放松庆祝一下。

正好当时有一个学弟王之栋在组织一群小伙伴打一个叫“狼人杀”的游戏，我虽然没有听说过，但看到参加的人还不少，也就一起跟着去了。（顺便提一下，当时还有人组织去网吧上网，但可惜我离18岁生日还有10天QAQ）

![](/Blog/2018wolf.jpg)

照片中戴帽子的帅哥就是我！

当时的我就完全是一个狼人杀小白，加上狼人杀又是一个以发言为核心的游戏，发言并不属于我擅长的领域，所以只能划划水。不过当年也就只玩了一个下午，所以其实对狼人杀并没有留下太深的印象。真正开始研究狼人杀，是在大学的一次偶然活动中。

## 熟悉狼人杀

在2019年我上大二的时候，报名参加了中国建国70周年的阅兵仪式，要在10月1日到天安门广场作为清华大学代表队伍的一员走方阵。为此，学校从7月份就开始组织训练。

在国庆节的前一个月，国家还专门组织了好几次夜晚去天安门的彩排。因为这场阅兵仪式非常重要，所以我们去彩排的时候除了身份牌不能带任何的物品。同时由于人非常多，后场时需要等待好多个小时。那么，在没有手机、没有电脑、连书都没有、身上只带了一个身份牌的情况下，如何渡过这漫长的等待时间呢？狼人杀再合适不过了！平时大家一方面娱乐方式有很多，一方面狼人杀一句的时间又太长，很难把很多爱好者聚集在一起。而在这个时刻，我们就是需要一个能消耗大量时间的游戏，狼人杀在这个时刻变成了最优解。

很快当时队伍里就有人组起了12个人，开始了一句又一句的游戏。此时的我们完全排除了学习、作业、手机、电脑等事物的感染，内心完全沉浸在了狼人杀游戏当中。当我们沉浸在游戏的同时，也就忘记了等待，甚至彩排开始了我们还有些念念不舍。也是在这个过程中，我开始从一个游戏纯萌新变为了一个初等玩家。

在迷上了这款游戏之后，我便开始在网上关注狼人杀相关的视频，也就借此机会追溯到了最早期的狼人杀综艺：Lyingman、PandaKill、Godlie，也认识到了一大批有趣的狼人杀玩家：JY、囚徒等。

## 对狼人杀行业的新思考

在我持续关注狼人杀的这些年，这个圈子也经历了很大的变化，很多节目虽然火爆一时，但都没能持续。而在这当中，JY创办的京城大师赛非常难得地坚持了下来，并且如今已经成为了狼人杀领域的绝对顶流。我开始思考，为什么那么多节目都倒下了，而只有京城大师赛能持续成长呢？

我想了想觉得有这样几个原因：

- 一个是时代原因，像Lyingman、PandaKill能火是因为当时处于狼人杀的早期，只要游戏本身有趣，节目组也能邀请到愿意认真参与的嘉宾就能火，观众更多地看的是对于这个新游戏玩法的探索。但随着这么多年过去，一方面玩法的创新机会越来越少，游戏变得越来越专业化，玩家的期待值也越来越高，所以，需要像JY这样，既对游戏、对主播有深入理解，又懂运营的综合性人才才能把节目做好。
- 一个是玩家的功利化，任何一件事情只有在初期可以去功力，让大家沉浸于自由探索。但玩久了以后，大家自然就需要开始考虑维持生计的问题，赚钱是不可避免的需求。所以节目一定要找到一个既能稳定赚钱，但又不至于太破坏和观众的感情的商业化方式，这一定是JY在行业一步步摸索出来的（这其实对于很多公司都是一个难题，像B站在商业化这条路上就走得很艰难，因为B站从一开始就有意把用爱发电作为标签，导致商业化很容易破坏和粉丝的感情）。
- 一个是对培养新玩家的重视程度大大提高，以前的京城大师赛都是几个圈内的常客在玩，也就是偶尔请一些跨界明星来客串一下。但这两年，京城大师赛开始大量培育想专注于狼人杀赛道的年轻人（当然这也基于大师赛已经有了一套成熟的商业化模式，来帮助新人快速在行业立足）。我觉得这也是JY从一个玩家、主播晋升为幕后操盘手的过程。因为游戏主播随着年龄增大，和观众，尤其是年轻的距离也会逐渐增大，所以培育年轻人，让年轻人能更快速度上大师赛也就是一个必然的过程。


- 京城大师赛现在商业化做得非常好，一定是源自JY在狼人杀圈多年的商业化经验积累。对于Lyingman、PandaKill这些节目组来说，他们是不需要考虑商业化的，他们是靠战旗TV、靠熊猫养着，不需要盈利，而JY很早就开始探索这条线如何盈利
就好像字节跳动在孵化番茄、红果、汽水这些平台时，也有着抖音商业化的经验
- 我们做教育其实也同理。像字节做教育、阿里做教育、戈尔做教育都又一个问题就是，学校有一个有钱的爸爸，使得学校一直生活在被宠爱之中，没有独立生存的能力。而我们从一开始就是拒绝资本的，寻找自身立足点。
