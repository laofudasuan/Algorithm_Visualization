##### P17143 [NOI 2026] 中位数

对于大小为 $m$ 的可重集 $S=\{x_0,x_1,\ldots,x_{m-1}\}$，设其所有元素 **从大到小** 排序后的结果为 $y_0\ge y_1\ge\cdots\ge y_{m-1}$。定义其 **中位数** $\operatorname{Median}(S)$ 为其中第 $\left\lceil\frac{m}{2}\right\rceil$ 大的数，即 $\operatorname{Median}(S)=y_{\left\lceil\frac{m}{2}\right\rceil-1}$。**注意：本题中的中位数定义与常规定义可能有所不同。**

给定长度为 $n$ 的序列 $[a_0,a_1,\ldots,a_{n-1}]$，以及一个正整数 $k$（$k\le n$）。定义一个 **划分** 如下：选择一个长度为 $k-1$ 的递增下标序列 $0<b_1<\cdots<b_{k-1}<n$，即可将原序列划分为 $k$ 个段，对应的下标区间依次为 $[0,b_1),[b_1,b_2),\ldots,[b_{k-1},n)$。

对于一个划分，定义该划分的 **平衡度** 如下：对于划分出的每个段，计算其中所有元素形成的可重集的中位数，则这 $k$ 个中位数形成的可重集的中位数即为该划分的 **平衡度**。形式化地，对于划分 $b_1,\ldots,b_{k-1}$，记 $b_0=0$，$b_k=n$，设第 $i$（$0\le i<k$）个段中所有元素形成的可重集的中位数为 $c_i=\operatorname{Median}(\{a_{b_i},a_{b_i+1},\ldots,a_{b_{i+1}-1}\})$，则该划分的平衡度为 $\operatorname{Median}(\{c_0,\ldots,c_{k-1}\})$。

请求出所有划分中平衡度的最大值。

设 $N$ 为单个测试点内所有测试数据的 $n$ 的和。对于所有测试数据，均有：
- $1\le t\le20$；
- $5\le n\le10^6$，$2\le k\le n$，$N\le10^6$；
- 对于所有 $0\le i<n$，均有 $1\le a_i\le n$。

###### 简单转化

二分答案 $x$，变成一个仅包含$1,-1$的序列问题:

> 能否把 $b$ 恰好切成 $k$ 个非空连续段，使和为正整数的段数至少为 $\left\lceil\frac{k}{2}\right\rceil$？

###### 打表找规律

定义

$$
g_k=[\text{序列能被合法地切成 }k\text{ 段}].
$$

例如输出 `0101010100000000`，表示 $g_1=0,g_2=1,g_3=0,\ldots$。下面三组数据很适合用来观察：

### 2.1 打表 DP 的状态

从左往右扫描序列。令 `dp[p][q]` 表示：

- 已经开出了 $p$ 段；
- 前 $p-1$ 段已经封口，其中恰有 $q$ 个好段；
- 在这些状态中，当前第 $p$ 段能够取得的 **最大元素和**。

读入下一个数 $b_i$ 时只有两种选择：

1. 不切：把 $b_i$ 接在当前段后面；
2. 切一刀：根据当前段的和是否非负更新 $q$，再用 $b_i$ 开启新段。

对于相同的 $(p,q)$，当前段的和越大一定越优，所以只保留最大值即可。扫描结束后，再把最后一段是否为好段计入答案。

下面的程序把 $B$ 设成 $n$，会输出全部 $g_1\sim g_n$，适合在小数据上自己改序列、观察规律。它不是完整提交代码；打表时建议令 $n\le50$。

```cpp maxLines=10
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;                    // 例如：--++---+---+----
    int n = (int)s.size();
    vector<int> b(n);
    for (int i = 0; i < n; ++i) b[i] = (s[i] == '+' ? 1 : -1);

    const int NEG = -1e9;
    int B = n;                   // 正式算法只需取一个小常数，如 B=7
    vector<vector<int>> dp(B + 2, vector<int>(B + 2, NEG));
    dp[1][0] = b[0];

    for (int i = 1; i < n; ++i) {
        vector<vector<int>> ndp(B + 2, vector<int>(B + 2, NEG));
        for (int p = 1; p <= min(B, i); ++p) {
            for (int q = 0; q < p; ++q) {
                if (dp[p][q] == NEG) continue;

                // 不切：b[i] 加入当前第 p 段
                ndp[p][q] = max(ndp[p][q], dp[p][q] + b[i]);

                // 切：封口当前段，用 b[i] 开启第 p+1 段
                if (p < B) {
                    int nq = q + (dp[p][q] >= 0);
                    ndp[p + 1][nq] = max(ndp[p + 1][nq], b[i]);
                }
            }
        }
        dp.swap(ndp);
    }

    cout << "k : ";
    for (int k = 1; k <= B; ++k) cout << k % 10;
    cout << '\n' << "g : ";
    for (int k = 1; k <= B; ++k) {
        int bestGood = -1;
        for (int q = 0; q < k; ++q) {
            if (dp[k][q] != NEG)
                bestGood = max(bestGood, q + (dp[k][q] >= 0));
        }
        cout << (bestGood >= (k + 1) / 2);
    }
    cout << '\n';
}
```

把案例 A 输入程序，会得到：

```text
k : 1234567890123456
g : 0101010100000000
```

当正式算法只求 $g_1\sim g_B$ 时，把上面程序中的 $B$ 改成常数即可。状态数为 $O(B^2)$，每个元素转移一次，复杂度为 $O(nB^2)$，空间复杂度为 $O(B^2)$。

### 2.2 从表中读出的稳定规律

对大量小序列枚举后，可以观察并证明下面的性质：设

$$
j=\max\{i\mid g_i=1\}.
$$

当 $i\ge6$ 时：

- $6\le i\le j$ 的所有偶数 $i$ 都可行；
- $6\le i\le j$ 的所有奇数 $i$ 要么全部可行，要么全部不可行。

所以不需要求出所有 $g_i$。取 $B=7$ 后：

- $k\le B$：直接读小 DP 得到的 $g_k$；
- $k>B$ 且 $k$ 为偶数：答案是 $[k\le j]$；
- $k>B$ 且 $k$ 为奇数：答案是 $[k\le j]\land g_7$。

现在只剩下一个问题：怎样在线性时间内求最大可行段数 $j$？

## 3. 把最大段数的构造画出来

设 $p$ 是序列中 $+1$ 的个数。一个好段至少含有一个 $+1$，所以好段数不超过 $p$。合法划分又要求坏段数不超过好段数，因此立刻有上界

$$
j\le \min(n,2p).
$$

下面说明什么时候能取到这个上界。

### 3.1 先搭一个“骨架划分”

先让每个 $+1$ 单独成为一个好段，把每个极长的连续 $-1$ 块先整体看成一个坏段。此时有 $p$ 个好段，而坏段至多有 $p+1$ 个。

- 如果坏段数已经不超过 $p$，骨架合法；
- 唯一麻烦的情况是恰有 $p+1$ 个坏段。此时必须消掉一个坏段。

能消掉一个坏段的局部模板只有以下几类：

| 位置 | 原局部结构 | 改成的好段 |
|:--|:--|:--|
| 左边界 | `-+` | `[-,+]` |
| 右边界 | `+-` | `[+,-]` |
| 两个 $+1$ 之间隔一个 $-1$ | `+-+` | `[+,-] [+]` |
| 两个 $+1$ 之间隔两个 $-1$ | `+--+` | `[+,-] [-,+]` |

每个方括号内的和都非负，因此仍是好段。如果四种位置都不存在，就无法把坏段数降到好段数以下，此时不存在任何可行划分。

### 3.2 再把长负段拆开

骨架合法以后，好段仍有 $p$ 个。只要坏段数还小于 $\min(p,n-p)$，就从某个长的纯负段里再切一刀。每切一刀会多出一个坏段，直到坏段数达到 $\min(p,n-p)$。

最终段数为

$$
p+\min(p,n-p)=\min(n,2p),
$$

恰好达到上界，也就得到了最大的 $j$。下面的交互图把“分块—消块—拆分”放在同一条序列上；切换到“无消块位置”还可以看到构造为什么会失败。

## 4. 完整判定流程与复杂度

对二分出的每个 $x$：

1. 构造 $b_i=[a_i\ge x]?+1:-1$；
2. 用 $O(nB^2)$ DP 求 $g_1\sim g_B$；
3. 扫描 $-1$ 块并寻找上述四种模板，求出最大可行段数 $j$；
4. 根据 $k\le B$、$k$ 的奇偶性以及 $k\le j$ 完成判断。

取 $B=7$，单次 `check` 的复杂度为 $O(nB^2)$，二分值域后的总复杂度为

$$
O(n\log n\cdot B^2),
$$

空间复杂度为 $O(n+B^2)$（$O(n)$ 用于保存二分后的序列）。
