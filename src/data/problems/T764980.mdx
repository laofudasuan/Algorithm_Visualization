##### T764980 删边最短路

有一个 $n$ 个点 $m$ 条边的简单无向连通图 $G$，你需要选择两条不同的边删去，得到图 $G'$，要求 $G'$ 仍然连通。

假设删掉的两条边为 $e_1 = (u_1, v_1), e_2 = (u_2, v_2)$，那么你希望最小化 $u_1, v_1$ 和 $u_2, v_2$ 在图 $G'$ 上最短路径长度的和。

求出这个最小值，并且求出有多少种删边的方式能达到这个最小值。

注意，我们把 $(e_1, e_2)$ 和 $(e_2, e_1)$ 当成同一种方案。并且数据保证存在一种合法的删边方案使得图仍然连通。

**输入格式**

第一行一个整数 $T$ 表示数据组数。对于每组测试数据：

第一行两个整数 $n, m$，表示图的点数和边数。

接下来 $m$ 行，每行两个整数 $u, v$ 表示一条边。

保证给出的图没有重边子环，以及数据保证至少存在一种合法的删边方案。

**输出格式**

对于每组数据，输出两个整数，分别表示最小值以及方案数。


**样例输出**

```

```

**数据范围**

对于所有数据，保证 $\sum n, \sum m \le 5000, n \ge 4, m \ge 5$。

保证给出的图没有重边自环，以及数据保证至少存在一种合法的删边方案。

- 子任务 1（20分）：$\sum n, m \le 300$。
- 子任务 2（15分）：保证所有答案第一问不超过 4。

- 子任务 4（20分）：保证 $m - n \le 100$。
- 子任务 5（30分）：无特殊限制。

<CollapsibleComponent title="做法">

令：$e_1 = (u_1,v_1),e_2 = (u_2,v_2)$。

我们称：$G - e$ 表示 $G$ 删掉边 $e$ 后的图。

记：$dis_G(u,v)$ 表示在图 $G$ 中 $u$ 到 $v$ 的最短路。

###### 观察一

如果 $e_1,e_2$ 满足如下两个条件中的其中一个：

- $e_2$ 是 $G - e_1$ 中 $u_1$ 到 $v_1$ 的最短路中必须经过的边。
- $e_1$ 是 $G - e_2$ 中 $u_2$ 到 $v_2$ 的最短路中必须经过的边。

那么选 $e_1,e_2$ 这两条边不优。

###### 观察二

如果 $e_1,e_2$ 不满足观察一中的任意一个条件，那么：
$$
dis_{G-e_1-e_2}(u_1,v_1) = dis_{G-e_1}(u_1,v_1) \\

dis_{G - e_1-e_2}(u_2,v_2) = dis_{G-e_2}(u_2,v_2)
$$

###### 做法

记 $f_{i,j} \in \{0,1\}$，表示第 $i$ 条边和第 $j$ 条边能否匹配，最开始令 $\forall f_{i,j} = 1$。

枚举一条边 $e_i =(u,v)$，得到 $G' = G - e_i$。

令 $d_i$ 表示 $u,v$ 在 $G'$ 中的最短路。

若 $G'$ 中 $u,v$ 不连通，则对所有 $j$，标记 $f_{i,j}= 0$，然后令 $d_i = +\infty$，然后接下来不做任何操做。

然后求 $G'$ 中的割边，因为他们都不能和 $e_i$ 匹配，这些边标记为 $f_{i,j} = 0$。

然后求 $G'$ 中最短路的必经边，然后标记 $f_{i,j } = 0$，做法是：

- 在 $G'$ 中以 $u,v$ 为源点求单源最短路 $disU,disV$，这个可以使用 BFS。

- 有一张空无向图 $H$。

- 对于图 $G'$ 中的一条边 $(u',v')$，若满足以下条件中的任意一个：
	$$
	disU(u') + 1 + disV(v') = d_i\\
	
	disU(v') + 1 + disV(u') = d_i
	$$
	则在 $H$ 中加入边 $(u',v')$。

- 因为 $H$ 恰好由所有 $u\to v$ 的最短路组成，所以一条边是所有最短路的必经边，当且仅当删掉它后 $u,v$ 在 $H$ 中不连通，所以求出 $H$  中的割边，他们就是最短路的必经边。

求一个图的割边用 Tarjan 可以做到 $O(n+m)$。

然后考虑求答案：
$$
Ans = \min_{i<j,f_{i,j} = f_{j,i} = 1} d_i + d_j
$$
然后求方案就是：
$$
Cnt = \sum_{i < j,f_{i,j} = f_{j,i} = 1} [d_i + d_j  = Ans]
$$
这里 $i<j$ 是为了去重。

总时间：$O(m(n+m) + m^2) = O(nm+m^2)$。

###### prove

证一下**观察一**，观察二易证！

要证：$e_2$ 是 $G - e_1$ 中 $u_1$ 到 $v_1$ 的最短路中必须经过的边时，选 $e_1,e_2$ 不优，另一个情况对称即可。

先排除一些显然不成立的组合，现在保证 $G - e_1-e_2$ 中 $u_1,v_1$ 连通，$u_2,v_2$ 连通。

下面假设：$e_2$ 在是 $G - e_1$ 中 $u_1,v_1$ 最短路的必经边。

下文认为：$G-e_1$ 中，$e_2$ 在 $u_1,v_1$ 最短路上的方向为：$u_2 \to v_2$，如果不是，交换 $u_2,v_2$。

考虑找一个边集 $P$，满足：$P$ 是 $G-e_1-e_2$ 中 $u_2 \to v_2$ 的最短路。

发现：$P$ 中至少有一条边不是必经边。

证明：

- 反设 $P$ 中每一条边都是必经边。

- 由于 $e_2$ 本身也是必经边，所以任意一条 $G-e_1$ 中 $u_1\to v_1$ 的最短路都必须同时经过 $e_2$ 和 $P$ 中的所有边。

- 而 $P\cup \{e_2\}$ 构成一个环，因此这条最短路会完整包含一个环。

- 由于边权均为 $1$，任意最短路都可以看成一条简单路径，简单路径不可能完整包含一个环，矛盾。

- 所以 $P$ 中至少有一条边不是必经边。

记 $P$ 中不是必经边的任意一条边为 $e_3 = (u_3,v_3)$。

然后考虑 $P \cup e_2$ 是一个环是边双，由于 $G - e_1 -e_2$ 中 $u_2,v_2$ 连通，所以 $G - e_1 - e_3$ 中 $u_3,v_3$ 连通。

发现 $dis_{G-e_1-e_3}(u_3,v_3) \le |P| = dis_{G-e_1-e_2}(u_2,v_2)$，因为你能得到 $P \setminus \{e_3\} \cup \{e_2\}$的路径，所以你的最短路不会比 $|P|$ 大。

由于 $e_3$ 不是最短路的必经边，所以 $dis_{G - e_1 - e_3}(u_1,v_1) =dis_{G - e_1}(u_1,v_1) < dis_{G- e_1 - e_2}(u_1,v_1)$。

所以：选 $e_1,e_3$ 严格优于 $e_1,e_2$。

证毕！
